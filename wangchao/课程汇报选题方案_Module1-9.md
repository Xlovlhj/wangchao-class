## Module 1：傅里叶变换 → 机械臂关节振动故障诊断

### 课程知识点

- 傅里叶级数：$v(t) = \sum_{n=-\infty}^{\infty} c_n e^{jn\omega_0 t}$
- 傅里叶变换：$V(f) = \int_{-\infty}^{\infty} v(t) e^{-j2\pi ft} dt$
- 时域与频域的等价性：一对幅度谱 + 相位谱唯一确定一个信号
- Parseval 定理：$P = \sum |c_n|^2$（功率 = 各谐波功率之和）
- 离散频谱（线谱）与带宽

### 机器人应用：机械臂关节减速器/电机的振动频谱分析

**核心原理**：

在机械臂关节处安装加速度计采集振动信号（时域波形），通过 FFT（快速傅里叶变换）将信号变换到频域：

$$v(t) \xrightarrow{\mathcal{F}} V(f)$$

- **正常状态**：频谱主要在基频 $f_0$ 及其低次谐波处有能量
- **齿轮磨损**：在啮合频率 $f_{\text{mesh}} = N \cdot f_{\text{rpm}}/60$ 处出现异常峰值
- **轴承故障**：在特征频率 $f_{\text{bearing}}$ 处产生边带调制

利用 Parseval 定理 $P = \sum_{n} |c_n|^2$ 量化各谐波携带的能量，设定阈值实现**非拆卸式故障预警**。

**应用价值**：工业机器人预测性维护是智能制造的热门方向，频谱分析相当于给机器人做"心电图"。

## Module 2：贝叶斯公式 → 机器人 SLAM 中的贝叶斯滤波

### 课程知识点

- 条件概率与贝叶斯公式：

$$P(B_i|A) = \frac{P(A|B_i) P(B_i)}{\sum_{j} P(A|B_j) P(B_j)} = \frac{P(A|B_i) P(B_i)}{P(A)}$$

- 全概率公式：$P(A) = \sum_i P(A|B_i)P(B_i)$
- 统计独立性
- 先验概率 vs 后验概率（由"果"推"因"）

### 机器人应用：卡尔曼滤波 / 粒子滤波在 SLAM 中的应用

**核心原理**：

机器人状态估计的数学本质就是**贝叶斯推断**：

$$P(\text{位置} | \text{传感器观测}) \propto P(\text{观测} | \text{位置}) \cdot P(\text{位置})$$

$$\text{后验} = \frac{\text{似然} \times \text{先验}}{\text{证据}}$$

- **预测步**（全概率公式）：根据上一时刻位置和运动指令 $u_t$，预测当前可能位置

$$P(x_t | z_{1:t-1}, u_{1:t}) = \int P(x_t | x_{t-1}, u_t) \cdot P(x_{t-1} | z_{1:t-1}, u_{1:t-1}) \, dx_{t-1}$$

- **更新步**（贝叶斯公式）：根据传感器观测 $z_t$，修正信念

$$P(x_t | z_{1:t}, u_{1:t}) = \eta \cdot P(z_t | x_t) \cdot P(x_t | z_{1:t-1}, u_{1:t})$$

**应用价值**：SLAM（同时定位与建图）是机器人领域最经典的核心问题，贝叶斯公式是其数学灵魂。从卡尔曼滤波（高斯假设）到粒子滤波（非参数化），都是贝叶斯框架的特例。

## Module 3：冲激响应与卷积 → 机器人关节电机系统辨识

### 课程知识点

- 线性系统的两个性质：齐次性 $a \cdot x \to a \cdot y$，可加性 $x_1+x_2 \to y_1+y_2$
- 叠加原理 = 齐次性 + 可加性
- 冲激响应 $h(t)$：输入 $\delta(t)$ 时的输出
- 卷积：$y(t) = \int_{-\infty}^{\infty} x(\tau) h(t-\tau) d\tau = x(t) * h(t)$
- 频率响应 $H(f) = \mathcal{F}\{h(t)\}$，频域关系 $Y(f) = X(f) \cdot H(f)$
- 正弦保真性：正弦波是唯一通过线性系统后波形不变的信号

### 机器人应用：机器人关节直流电机/伺服电机的系统辨识

**核心原理**：

系统辨识的目标是用输入-输出数据估计电机的传递函数 $H(s)$（或 $H(f)$）。

- **时域方法**：给电机输入近似冲激信号（短脉冲电压），测量转速响应 → 这就是 $h(t)$
- **频域方法**：输入扫频正弦信号，测量输出幅度和相位随频率变化 → 这就是 $H(f)$

获得 $H(f)$ 后：
- $|H(f)|$ 的 -3dB 点 → 系统带宽
- $|H(f)|$ 的峰值 → 谐振频率（需避开）
- 进而设计精确的 PID / 前馈控制器

## Module 4：PWM 脉冲宽度调制 → 机器人电机驱动控制

### 课程知识点

- 脉冲调制：PAM（调幅）、PWM（调宽）、PPM（调位）
- PWM 比 PAM 更抗噪声——噪声对脉冲边沿位置的影响远小于对幅度的影响
- 脉冲调制仍是**模拟**技术（幅度/宽度/位置连续变化）
- 奈奎斯特准则：脉冲速率 ≥ $2f_{\max}$

### 机器人应用：PWM 控制直流电机与舵机

**核心原理**：

PWM 通过改变方波的占空比 $D$ 来调节等效输出电压：

$$V_{\text{avg}} = D \cdot V_{cc}, \quad D = \frac{t_{\text{on}}}{T}$$

- **直流电机调速**：占空比 0-100% → 转速线性变化
- **舵机角度控制**：标准舵机信号周期 20ms（50Hz），1-2ms 脉宽对应 0°-180°
- **高级扩展**：结合 FOC（磁场定向控制）+ SVPWM（空间矢量 PWM）实现无刷电机精密控制

**应用价值**：这是机器人所有关节运动的最底层驱动技术——从 Arduino 的 `analogWrite()` 到工业伺服驱动器，都离不开 PWM。

## Module 5：奈奎斯特采样定理 → 机器人 IMU 数据采集与抗混叠

### 课程知识点

- 采样：$x[n] = x(nT_s)$，$f_s = 1/T_s$
- 奈奎斯特采样定理：$f_s \geq 2f_{\max}$（无失真重建的充分条件）
- 采样后频谱：$X_s(f) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(f - kf_s)$
- 混叠（Aliasing）：$f_s < 2f_{\max}$ 时，高频分量折叠到低频
- 抗混叠滤波器：采样前先做模拟低通滤波

### 机器人应用：IMU（惯性测量单元）的采样率选择

**核心原理**：

IMU 测量机器人的角速度和线加速度，机械臂运动频率范围通常在 0-50Hz。

- 若采样率不足（如 $f_s < 100\text{Hz}$），高频振动分量会通过**频谱周期延拓**混叠到低频段
- 混叠导致姿态估计（如 Madgwick/Mahony 滤波器）产生漂移
- **解决方案**：
  1. 硬件上：在 ADC 前加模拟低通抗混叠滤波器（截止频率 $f_c \leq f_s/2$）
  2. 软件上：适当过采样（如 $f_s = 4-5 \times f_{\max}$）

**数学关键**：

$$X_s(f) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(f - kf_s)$$

当 $f_s < 2f_{\max}$，相邻周期的频谱重叠 → 混叠 → 不可逆失真。

## Module 6：量化误差 → 机器人编码器分辨率与定位精度

### 课程知识点

- 量化：将连续幅度映射到有限个离散值
- 量化误差 $e_q = x_q - x$，在线性量化中 $e_q \sim U(-\Delta/2, \Delta/2)$
- 量化噪声功率：$\sigma_e^2 = \Delta^2 / 12$
- SQNR = $6.02n + 1.76$ dB（$n$ 为量化位数）
- 量化使 PDF 从连续变为离散（冲激函数序列）

### 机器人应用：关节编码器分辨率对末端定位精度的影响

**核心原理**：

光电编码器将连续角度量化为有限脉冲数：
- 1024 线编码器 → $\Delta = 360°/1024 \approx 0.352°$
- 量化误差 $\sigma_e^2 = \Delta^2/12 \approx 0.0103 \text{ deg}^2$

量化误差经机械臂正向运动学传播：
- 关节角度误差 $\sigma_\theta$ → 通过雅可比矩阵 $J$ 传播 → 末端位置误差：

$$\Sigma_{\text{末端}} = J \, \Sigma_{\theta} \, J^T$$

**工程意义**：要达到末端 ±0.1mm 的定位精度，可反推需要多少线的编码器 → 直接指导硬件选型。

## Module 7：贝叶斯决策理论 → 机器人障碍物检测与分类

### 课程知识点

- 二元假设检验：$H_0$（发 0）vs $H_1$（发 1）
- 两类错误：虚警 $P(e|0)$、漏检 $P(e|1)$
- 最大后验概率（MAP）准则：选后验概率更大的假设
- 似然比检验：$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0)}{P(H_1)}$
- BER = $Q(\frac{\mu_1 - \mu_0}{2\sigma})$（等概率、最优阈值）

### 机器人应用：基于激光雷达/深度相机的障碍物二分类

**核心原理**：

给定激光雷达距离读数 $r$，判断前方是"障碍物"还是"空地"：

- $H_0$：空地 → $P(r|H_0)$（距离远，方差大）
- $H_1$：障碍物 → $P(r|H_1)$（距离近，方差小）

**贝叶斯决策规则（MAP 准则）**：

$$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0)}{P(H_1)}$$

**代价敏感扩展**——引入代价矩阵：

| | 判为空地 | 判为障碍 |
|---|:---:|:---:|
| 实际空地 | $C_{00}=0$ | $C_{01}$（虚警：无故绕行） |
| 实际障碍 | $C_{10}$（漏检：碰撞！） | $C_{11}=0$ |

碰撞代价 $C_{10} \gg C_{01}$（虚警）→ 最小风险贝叶斯决策 → 阈值偏向"宁可错杀不可放过"：

$$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0) \cdot C_{10}}{P(H_1) \cdot C_{01}}$$

## Module 8：交叉熵 / KL 散度 → 机器人深度学习抓取

### 课程知识点

- 香农信息量：$h(x) = -\log_2 p(x)$
- 熵（期望信息量）：$H(X) = -\sum p(x) \log_2 p(x)$，$0 \leq H(X) \leq \log_2 I$
- 条件熵 + 链式法则：$H(X,Y) = H(X) + H(Y|X)$
- 交叉熵：$H(P,Q) = -\sum p(x) \log q(x)$
- KL 散度：$D_{KL}(P\|Q) = \sum p(x) \log \frac{p(x)}{q(x)} = H(P,Q) - H(P)$
- Gibbs 不等式：$D_{KL}(P\|Q) \geq 0$，$P=Q$ 时取等号
- 互信息：$I(X;Y) = H(X) - H(X|Y) = D_{KL}(P(x,y) \| P(x)P(y))$

### 机器人应用：视觉抓取质量评估网络的训练

**核心原理**：

构建一个卷积神经网络（CNN），输入物体图像，输出每个像素位置"可抓取"的概率 $q$（预测分布）。

训练时的**交叉熵损失函数**：

$$L = -\frac{1}{N}\sum_{i=1}^{N} \left[ p_i \log q_i + (1-p_i) \log(1-q_i) \right]$$

其中：
- $p_i$：真实标签（抓取成功 = 1，失败 = 0），真实分布 $P$
- $q_i$：网络预测概率，预测分布 $Q$

**为什么最小化交叉熵有效？**

$$D_{KL}(P\|Q) = \underbrace{H(P,Q)}_{\text{交叉熵}} - \underbrace{H(P)}_{\text{真实熵（常数）}}$$

由于 $H(P)$ 在训练中是固定的，最小化交叉熵 $H(P,Q)$ 等价于最小化 KL 散度 $D_{KL}(P\|Q)$——即让预测分布 $Q$ 逼近真实分布 $P$。

## Module 9：汉明码 → 极端环境下机器人遥操作可靠通信

### 课程知识点

- $(n,k)$ 线性分组码：$k$ 个信源比特 → $n$ 个发送比特（$n>k$，添加校验位）
- 汉明 $(7,4)$ 码：$k=4, n=7$，$d_{\min}=3$
- 最小汉明距离 $d_{\min}$：任意两个码字间的最少不同比特数
- 纠错能力：可纠正 $\lfloor (d_{\min}-1)/2 \rfloor$ 个错误，可检测 $d_{\min}-1$ 个错误
- 伴随式译码：$\mathbf{s} = \mathbf{r} H^T$，$\mathbf{s}$ 指示错误位置
- 信源编码定理：$H(X) \leq L < H(X)+1$
- 码率：$R = k/n$

### 机器人应用：水下机器人 / 太空机器人遥操作可靠通信

**核心原理**：

- **水下声学通信**：误码率 BER 可达 $10^{-2} \sim 10^{-3}$，直接发送控制指令极易出错
- **太空远距离通信**：信号微弱，单比特错误可能导致机械臂误动作

**汉明 (7,4) 码方案**：

1. **发送端编码**：每 4 个控制比特 $\mathbf{s} = [s_1, s_2, s_3, s_4]$ 编码为 7 比特 $\mathbf{t}$

$$\mathbf{t} = [s_1, s_2, s_3, s_4, t_5, t_6, t_7]$$

其中校验位 $t_5, t_6, t_7$ 使三个"圆"内异或为 0。

2. **接收端译码**：计算伴随式 $\mathbf{s} = \mathbf{r}H^T$
   - $\mathbf{s} = [0,0,0]$ → 无误码
   - $\mathbf{s} \neq [0,0,0]$ → 根据 $\mathbf{s}$ 的值定位错误比特并翻转

3. **代价**：码率 $R = 4/7 \approx 57\%$，即以约 43% 的带宽开销换取**单比特纠错能力**
