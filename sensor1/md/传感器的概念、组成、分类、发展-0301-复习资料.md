## 第一部分：知识梳理

### 第1章 传感器概述

#### 1.1 传感器的定义与基本组成

传感器是一种能感受被测量并按一定规律将其转换为可用输出信号（通常为电信号）的器件或装置。

**传感器的基本组成：**
- **敏感元件**：直接感受被测量并输出与被测量成确定关系的物理量
- **转换元件**：将敏感元件输出的非电物理量转换为电信号
- **信号调理电路**：将转换元件输出的电信号进行放大、滤波、线性化等处理
- **辅助电源**：为传感器提供工作能量

**⭐ 重点：** 传感器的核心功能是"感受"与"转换"——将被测非电量转换为可用电信号。

#### 1.2 传感器的分类

按输入量（被测量）分类：
- 温度传感器、压力传感器、位移传感器、加速度传感器、湿度传感器等

按输出信号形式分类：
- 模拟传感器（输出连续信号）
- 数字传感器（输出离散数字信号）

按工作原理分类：
- 电阻式、电容式、电感式、压电式、光电式、热电式等

### 第2章 智能传感器概述

#### 2.1 智能传感器的定义与特点

智能传感器是内置微处理器（MCU）、具备信息处理能力的传感器。

**核心能力：**
- 能独立完成信号采集、滤波、运算、通信
- 具备自诊断、自校准、自补偿等智能功能
- 可直接通过总线（I²C、SPI、CAN 等）与上位机或网络通信

**⭐ 重点：** 智能传感器 = 传统传感器 + 微处理器 + 智能算法，区别于传统传感器的关键在于"可编程、可通信、可自检"。

#### 2.2 典型智能传感器

| 传感器型号 | 类型 | 特点 |
|-----------|------|------|
| ADXL345 | 三轴加速度智能传感器 | 集成 MEMS 结构、A/D 转换与 MCU，输出数字加速度值 |
| BMP280 | 智能气压传感器 | 带内部温度补偿算法，输出精确气压与高度信息 |

### 第3章 超智能传感器分类

#### 3.1 边缘传感器模块

在靠近数据源的位置进行部分或全部数据处理、分析和初步决策，减少数据传输至云端的延迟，降低带宽与功耗。

**系统流程：**
1. 物理量检测（温度、压力、振动等）
2. 信号调理 / 模数转换
3. 边缘处理器（本地 MCU / FPGA / AI 加速器）进行数据滤波、特征提取、初步判断
4. 判断结果：直接触发执行或通过通信节点上传

**⭐ 重点：** 边缘传感的核心价值在于"本地决策"——减少云端依赖，提高实时性。

#### 3.2 视觉检测传感器

使用图像/视频传感器（如事件相机、深度相机），结合智能算法（图像处理、深度学习）完成检测、识别、跟踪、分类等任务。

**系统流程：** 摄像头获取帧 → 本地预处理（去噪、增强、ROI 提取）→ 相机标定 → 特征提取 + 模型推理

#### 3.3 健康穿戴传感器

直接贴敷、穿戴于人体或衣物上的智能传感阵列，实现"零延迟"连续监测。结合边缘计算进行数据初步处理、变化检测、异常预警。

**系统流程：** 穿戴传感器采集生理/活动数据（PPG、ECG、温度、加速度）→ 本地设备/手机进行预处理、特征提取、异常判断

#### 3.4 车载与自动驾驶传感器

将多模态感知技术（视觉、雷达、激光、声波、惯性等）与 AI 边缘计算模块相结合的系统级传感装置。

**系统流程：** 传感器阵列激活（雷达、相机、IMU）→ 同步采集环境数据 → 识别车辆/行人/障碍物 → 控制执行（转向/制动/加速），持续闭环更新

### 第4章 智能传感器与机器人感知

#### 4.1 感存算一体化概念

**核心内涵：**
- **"感"**：感受或响应被测量的过程
- **"算"**：可控/可调/可访问的物理过程，是输入有效信息增加的过程
- **"存"**：器件状态的短时或长时保持性

| 层次 | 含义 |
|------|------|
| 广义感存算一体化 | 在一个**系统**中实现感、存、算功能的融合 |
| 狭义感存算一体化 | 在**同一个器件**中实现感、存、算的功能 |

**⭐ 重点：** 狭义的器件级感存算一体化是当前的前沿方向。

#### 4.2 感存算一体化的主要特征和优势

1. 显著提升传感边缘端的智能化水平和系统整体运算效率
2. 从根本上解决传统智能传感系统中传感端、存储端及处理端存在的接口瓶颈问题，避免大量数据搬移产生的能耗和时间延迟
3. 在模拟域利用物理硬件自身特性及相应物理规律直接实现感、存、算功能，具有**运算速度快、功耗低**的显著优势
4. 通过数据分级处理、存储及高并行度计算，有效增加系统可靠性、鲁棒性与响应速度

#### 4.3 感存算一体化架构分类

| 架构类型 | 含义 |
|---------|------|
| 感 + 存算一体 | 感知与存储+计算分离（存储与计算融合） |
| 感存 + 算一体 | 感知+存储融合（与计算分离） |
| 感算 + 存一体 | 感知+计算融合（与存储分离） |
| **器件级感存算一体** | 三者完全融合于同一器件（终极目标） |

#### 4.4 智能传感器在机器人中的应用

**工业机器人：**
- 常用传感器：光电编码器、陀螺仪、加速度计、压力传感器
- 功能：位置/速度/力精确控制，检测温度/湿度/压力等环境变化

**服务机器人：**
- 常用传感器：激光雷达、深度相机、麦克风、温度传感器
- 功能：自主导航、物体识别、语音识别、人体生理参数检测

**军用机器人：**
- 应用场景：无人机、无人驾驶坦克
- 功能：目标识别、导航定位、武器控制、战场环境检测

**⭐ 重点：** 三类机器人的传感器需求各有侧重——工业重精度，服务重交互，军用重环境感知。

### 第5章 传感器的动静态指标

#### 5.1 概述

传感器的特性主要指输出与输入之间的关系，根据输入信号性质分为：

| 特性类型 | 适用场景 | 说明 |
|---------|---------|------|
| 静态特性 | 输入为静态（常量）或缓慢变化的信号 | 输出-输入关系不含时间变量 |
| 动态特性 | 被测量随时间较快变化 | 输出-输入关系为动态特性 |

**一般数学模型 —— 静态特性多项式：**

$$Y = a_0 + a_1 X + a_2 X^2 + \cdots + a_n X^n$$

其中：
- $a_0$ — 零位输出（若 $a_0=0$，静态特性通过原点）
- $a_1$ — 线性灵敏度，常用 $K$ 表示
- $a_2, a_3, \ldots, a_n$ — 非线性项待定常数

#### 5.2 静态特性的四种典型情况

| 类型 | 方程 | 特点 |
|------|------|------|
| 理想线性 | $Y = a_1 X$ | 完全线性 |
| X 奇次项非线性 | $Y = a_1 X + a_3 X^3 + a_5 X^5 + \cdots$ | 原点附近近似线性 |
| X 偶次项非线性 | $Y = a_1 X + a_2 X^2 + a_4 X^4 + \cdots$ | 非线性明显 |
| X 奇偶次项非线性 | $Y = a_1 X + a_2 X^2 + a_3 X^3 + \cdots$ | 一般非线性 |

**⭐ 重点：**
- 只有第1种是理想线性，其余均为非线性
- X 奇次项非线性在原点附近近似线性（对称性）
- 实际应用中常通过**差动测量**消除偶次项，减少非线性误差

**传感器理想线性特性的优点：**
- 简化理论分析和设计计算
- 方便标定和数据处理
- 显示仪表刻度均匀
- 避免非线性补偿环节

#### 5.3 七大静态性能指标

##### 5.3.1 线性度（非线性误差）$\delta_L$

$$\delta_L = \pm \frac{\Delta Y_{max}}{Y_{FS}} \times 100\%$$

- $\Delta Y_{max}$：校准曲线与拟合直线间的最大偏差
- $Y_{FS} = Y_{max} - Y_0$：满量程输出

**产生原因：** 传感器实际输入-输出特性含有高次项 $y = a_0 + a_1x + a_2x^2 + \cdots + a_nx^n$

**拟合方法：**
| 方法 | 说明 |
|------|------|
| 端基法 | 零点平均值与满量程平均值连线 |
| 最小二乘法 | 使 $\sum \Delta_i^2$ 最小，精度最高 |
| 理论拟合 | 基于理论公式 |
| 过零旋转拟合 | 绕零点旋转拟合 |
| 端点连线拟合 | 直接连接两端点 |
| 端点连线平移拟合 | 端点连线平移 |

**⭐ 重点：** 最小二乘法拟合精度最高；差动测量可消除偶次项误差、提高灵敏度一倍。

##### 5.3.2 灵敏度 $K$

$$K = \frac{\Delta Y}{\Delta X}$$

表征传感器对输入量变化的反应能力。线性传感器 $K$ 为常数，非线性传感器 $K$ 随输入变化。

##### 5.3.3 精确度 $A$

$$A = \frac{\Delta A}{Y_{FS}} \times 100\%$$

- $\Delta A$：测量范围内允许的最大绝对误差
- $Y_{FS}$：满量程输出

我国工业仪表精度等级：0.005, 0.02, 0.05, 0.1, 0.2, 0.35, 0.4, 0.5, 1.0, 1.5, 2.5, 4.0

##### 5.3.4 迟滞 $\delta_H$

$$\delta_H = \pm \frac{\Delta H_{max}}{Y_{FS}} \times 100\%$$

或

$$\delta_H = \pm \frac{\Delta H_{max}}{2Y_{FS}} \times 100\%$$

**产生原因：** 弹性敏感元件弹性滞后、运动部件摩擦、传动机构间隙、紧固件松动等。迟滞误差又称回差或变差。

##### 5.3.5 重复性 $\delta_k$

$$\delta_k = \pm \frac{2\sigma\ (\text{或}\ 3\sigma)}{Y_{FS}} \times 100\%$$

贝塞尔公式：

$$\sigma = \sqrt{\frac{\sum_{i=1}^n (Y_i - \bar{Y})^2}{n-1}}$$

**⭐ 重点：** 重复性反映偶然误差的大小，不表示与真值的差别。重复性好 ≠ 准确性高。

##### 5.3.6 零点漂移

$$\text{零漂} = \frac{\Delta Y_0}{Y_{FS}} \times 100\%$$

传感器无输入（或输入不变）时，输出随时间偏离零值（或原指示值）。

##### 5.3.7 温漂

$$\text{温漂} = \frac{\Delta_{max}}{Y_{FS} \cdot \Delta T} \times 100\%$$

温度每变化 1℃ 时输出最大偏差与满量程的百分比。

### 第6章 传感器的动态特性

#### 6.1 动态特性微分方程

传感器的动态输入-输出关系可用常系数微分方程描述：

$$a_n \frac{d^n Y}{dt^n} + a_{n-1} \frac{d^{n-1} Y}{dt^{n-1}} + \cdots + a_1 \frac{dY}{dt} + a_0 Y = b_m \frac{d^m X}{dt^m} + b_{m-1} \frac{d^{m-1} X}{dt^{m-1}} + \cdots + b_1 \frac{dX}{dt} + b_0 X$$

绝大多数传感器可用零阶、一阶或二阶微分方程描述。

#### 6.2 零阶传感器

**微分方程：** $a_0 Y = b_0 X$  →  $Y = KX$（$K = b_0/a_0$）

**示例：** 线性电位器 — $U_{SC} = \frac{U_{SR}}{L}x = Kx$

输出电压与位移成正比，对任何频率输入均无时间滞后。

#### 6.3 一阶传感器

**微分方程：** $a_1 \frac{dY}{dt} + a_0 Y = b_0 X$

**算子形式：** $(\tau D + 1)Y = KX$

- $K = b_0 / a_0$ — 静态灵敏度
- $\tau = a_1 / a_0$ — 时间常数

**示例：** 不带保护套管的热电偶测温

**⭐ 重点：** 时间常数 $\tau$ 是决定一阶传感器响应速度的重要参数。

#### 6.4 二阶传感器

**微分方程：** $a_2 \frac{d^2 Y}{dt^2} + a_1 \frac{dY}{dt} + a_0 Y = b_0 X$

**算子形式：** $\left(\frac{D^2}{\omega_0^2} + \frac{2\xi}{\omega_0}D + 1\right)Y = KX$

三个特征量：
- $K = b_0/a_0$ — 静态灵敏度
- $\omega_0 = \sqrt{a_0/a_2}$ — 无阻尼固有频率
- $\xi = a_1/(2\sqrt{a_0a_2})$ — 阻尼比

**示例：** 带保护套管的热电偶测温系统

#### 6.5 时域动态性能指标

| 指标 | 符号 | 定义 |
|------|------|------|
| 时间常数 | $\tau$ | 一阶传感器输出上升到稳态值 63.2% 所需时间 |
| 延迟时间 | $t_d$ | 输出达到稳态值 50% 所需时间 |
| 上升时间 | $t_r$ | 输出达到稳态值 90% 所需时间 |
| 峰值时间 | $t_p$ | 输出响应曲线达到第一个峰值所需时间 |
| 超调量 | $\sigma$ | 输出超过稳态值的最大值 |
| 衰减比 | $d$ | 衰减振荡的第一个峰值与第二个峰值之比 |

#### 6.6 频率响应特性指标

| 指标 | 定义 |
|------|------|
| 通频带 $\omega_{0.707}$ | 幅值衰减 3 dB 时所对应的频率范围 |
| 工作频带 $\omega_{0.95}$ | 幅值误差 ±5% 内的频率范围 |
| 时间常数 $\tau$ | $\tau$ 越小，频带越宽 |
| 固有频率 $\omega_n$ | 二阶传感器动态特性的表征 |
| 相位误差 | 实际输出与理想无失真输出间的相位差值 |
| 跟随角 $\Phi_{0.707}$ | $\omega = \omega_{0.707}$ 时相频特性上的相角 |

#### 6.7 各阶传感器的阶跃响应

**零阶：** $Y(t) = KX(t)$，阶跃响应与输入成正比。

**一阶：** $Y(t) = 1 - e^{-t/\tau}$

- 当 $t = \tau$ 时，$Y(t) = 0.63$（时间常数 $\tau$ 的物理意义）

**二阶（按 $\xi$ 分类）：**

| 阻尼状态 | $\xi$ 值 | 响应特征 |
|---------|---------|---------|
| 欠阻尼 | $\xi < 1$ | 出现过冲（超过稳态值），有振荡 |
| 临界阻尼 | $\xi = 1$ | 无超调，最快无振荡响应 |
| 过阻尼 | $\xi > 1$ | 无超调，响应较慢 |

**⭐ 重点：**
- 工程中 $\xi$ 一般取 **0.7** 左右，兼顾短的上升时间和小的过冲量
- $\xi = 0.7$ 时：$t_r = 2/\omega_0$，$t_s = 3/\omega_0$（±5% 稳定时间）
- 频域-时域关系：$f_n t_r = 0.35 \sim 0.45$（$\sigma\% < 5\%$ 用 0.35，$\sigma\% > 5\%$ 用 0.45）

## 第二部分：习题精讲

### 习题1：精度等级与允许误差

**题目：**
一台精度等级为 0.5 级、量程范围为 600～1200 ℃ 的温度传感器。问该传感器的最大允许绝对误差是多少？检验时某点的最大绝对误差为 4 ℃，问该传感器是否合格？

**📚 前置知识：**

- **精度等级公式**：$A = \frac{\Delta A}{Y_{FS}} \times 100\%$，其中 $\Delta A$ 为允许的最大绝对误差，$Y_{FS}$ 为满量程输出
- **满量程** $Y_{FS} = Y_{max} - Y_0$，即量程上限减去量程下限
- 精度等级 0.5 级表示 $A = 0.5\%$

**🔍 详细解答：**

**步骤一**：计算满量程 $Y_{FS}$

$$Y_{FS} = Y_{max} - Y_0 = 1200 - 600 = 600\ ℃$$

**步骤二**：已知精度等级 $A = 0.5\%$，由精度等级定义式反推最大允许绝对误差 $\Delta A$：

$$\Delta A = A \times Y_{FS} = 0.5\% \times 600 = \frac{0.5}{100} \times 600 = 3\ ℃$$

**步骤三**：判断是否合格

检验时实际最大绝对误差为 4 ℃ > 允许最大绝对误差 3 ℃，因此**该传感器不合格**。

**💡 易错点：**
- 满量程 $Y_{FS}$ 是 **量程上限减去下限之差**（600 ℃），不是 1200 ℃
- 精度等级 0.5 表示 0.5%，不是 5%
- 判断标准：实际误差 ≤ 允许误差 → 合格

### 习题2：切线法拟合直线与线性度

**题目：**
已知某传感器的静态特性方程为 $Y = 1 + X + X^2$，试在区间 $0 \leq X \leq 1$ 内用直线对其进行拟合，求出相应的线性度误差。

**📚 前置知识：**

- **线性度公式**：$\delta_L = \pm \frac{\Delta Y_{max}}{Y_{FS}} \times 100\%$
- **切线法拟合**：在指定点作切线作为拟合直线，切线斜率 = 该点的一阶导数值
- 拟合直线的一般形式：$Y = a_0 + KX$
- 最大偏差 $\Delta Y_{max}$ = 实际曲线值 − 拟合直线值，取区间内最大者

**🔍 详细解答：**

**步骤一**：在 $X = 0$ 处作切线，确定拟合直线参数

已知 $Y = 1 + X + X^2$

- $a_0 = Y(0) = 1 + 0 + 0 = 1$
- $K = \frac{dY}{dX}\big|_{X=0} = 1 + 2X\big|_{X=0} = 1$

**步骤二**：拟合直线方程为

$$Y_{fit} = 1 + X$$

**步骤三**：计算各点偏差值

$$\Delta = Y_{real} - Y_{fit} = (1 + X + X^2) - (1 + X) = X^2$$

在区间 $0 \leq X \leq 1$ 内，最大偏差出现在 $X = 1$ 处：$\Delta_{max} = 1^2 = 1$

**步骤四**：计算满量程

$$Y_{FS} = Y_{real}(1) - Y_{real}(0) = (1 + 1 + 1) - (1 + 0 + 0) = 2$$

**步骤五**：计算线性度误差

$$\delta_L = \pm \frac{\Delta_{max}}{Y_{FS}} \times 100\% = \pm \frac{1}{2} \times 100\% = \pm 50\%$$

**💡 易错点：**
- 切线拟合的 $a_0$ 是曲线在 $X=0$ 处的值，$K$ 是曲线在该点的导数
- 不要忘记满量程 $Y_{FS}$ 是输出范围，不是输入范围
- 最大偏差注意取绝对值

### 习题3：一阶动态系统阶跃响应

**题目：**
用一个具有一阶动态特性的测量仪表（$\tau = 0.35\ s$），测量阶跃信号，输入由 $T_1 = 25$ 单位跳变到 $T_2 = 240$ 单位，求当 $t = 0.35\ s,\ 0.7\ s,\ 2\ s$ 时的仪表示值分别为多少？

**📚 前置知识：**

- **一阶系统阶跃响应公式**：$Y(t) = T_1 + (T_2 - T_1)(1 - e^{-t/\tau})$
- 此公式的物理意义：初始值 + 变化幅度 × 一阶响应比例
- $\tau$ 为时间常数，$t = \tau$ 时输出达到总变化的 63.2%

**🔍 详细解答：**

**步骤一**：确定已知量
- 时间常数 $\tau = 0.35\ s$
- 初始值 $T_1 = 25$
- 终值 $T_2 = 240$
- 总变化量 $\Delta T = T_2 - T_1 = 240 - 25 = 215$

**步骤二**：代入一阶响应公式

$$Y(t) = 25 + 215 \times (1 - e^{-t/0.35})$$

**步骤三**：分别计算三个时刻

**① $t = 0.35\ s = 1\tau$：**
$$Y(0.35) = 25 + 215 \times (1 - e^{-1}) = 25 + 215 \times (1 - 0.368) = 25 + 215 \times 0.632 \approx 160.9$$

**② $t = 0.7\ s = 2\tau$：**
$$Y(0.7) = 25 + 215 \times (1 - e^{-2}) = 25 + 215 \times (1 - 0.135) = 25 + 215 \times 0.865 \approx 210.9$$

**③ $t = 2\ s$：**
$$Y(2) = 25 + 215 \times (1 - e^{-2/0.35}) = 25 + 215 \times (1 - e^{-5.714})$$

因 $e^{-5.714} \approx 0.0033$，故 $1 - e^{-5.714} \approx 0.9967$

$$Y(2) \approx 25 + 215 \times 0.9967 \approx 239.3$$

**💡 易错点：**
- 不要忘记加上初始值 $T_1 = 25$，输出是从 $T_1$ 开始变化，不是从 0 开始
- 总变化幅度是 $T_2 - T_1$，不是 $T_2$
- $t = 1\tau$ 时输出到达总变化的约 63.2%，$t = 2\tau$ 时约 86.5%，$t = 5\tau$ 时基本稳定
- 验证：$t = 2\ s \approx 5.7\tau$，输出已趋近终值 240，结果 239.3 合理

### 一、核心公式汇总

| 指标 | 公式 | 备注 |
|------|------|------|
| 静态特性多项式 | $Y = a_0 + a_1X + a_2X^2 + \cdots + a_nX^n$ | $a_0=0$ 时过原点 |
| 线性度 | $\delta_L = \pm \frac{\Delta Y_{max}}{Y_{FS}} \times 100\%$ | $Y_{FS}=Y_{max}-Y_0$ |
| 灵敏度 | $K = \frac{\Delta Y}{\Delta X}$ | 线性时 $K$ 为常数 |
| 精确度 | $A = \frac{\Delta A}{Y_{FS}} \times 100\%$ | 由精度等级确定 |
| 迟滞 | $\delta_H = \pm \frac{\Delta H_{max}}{Y_{FS}} \times 100\%$ | 正反行程最大偏差 |
| 重复性 | $\delta_k = \pm \frac{2\sigma}{Y_{FS}} \times 100\%$ | $\sigma = \sqrt{\frac{\sum(Y_i-\bar{Y})^2}{n-1}}$ |
| 零漂 | $\text{零漂} = \frac{\Delta Y_0}{Y_{FS}} \times 100\%$ | 无输入时偏离 |
| 温漂 | $\text{温漂} = \frac{\Delta_{max}}{Y_{FS} \cdot \Delta T} \times 100\%$ | 每1℃偏差 |
| 一阶响应 | $Y(t) = Y_0 + (Y_\infty - Y_0)(1-e^{-t/\tau})$ | $\tau$ 越小响应越快 |
| 频时乘积 | $f_n \cdot t_r = 0.35 \sim 0.45$ | $\sigma<5\%$ 取 0.35 |

### 二、零阶/一阶/二阶传感器对比

| 特性 | 零阶 | 一阶 | 二阶 |
|------|------|------|------|
| 微分方程 | $a_0Y = b_0X$ | $a_1Y' + a_0Y = b_0X$ | $a_2Y'' + a_1Y' + a_0Y = b_0X$ |
| 特征参数 | $K = b_0/a_0$ | $K, \tau = a_1/a_0$ | $K, \omega_0, \xi$ |
| 阶跃响应 | 与输入成正比 | 指数趋近稳态 | 振荡/单调趋近 |
| 典型器件 | 线性电位器 | 裸热电偶 | 带套管热电偶 |
| 关键参数 | — | $\tau$（时间常数） | $\xi$（阻尼比）取 0.7 最优 |

### 三、二阶传感器阻尼比对照表

| $\xi$ 值 | 状态 | 响应特点 | 阶跃响应 |
|----------|------|---------|---------|
| $\xi = 0$ | 无阻尼 | 等幅振荡 | 不收敛 |
| $0 < \xi < 1$ | 欠阻尼 | 衰减振荡，有超调 | 有超调 |
| $\xi = 1$ | 临界阻尼 | 无超调，响应较快 | 单调趋近 |
| $\xi > 1$ | 过阻尼 | 无超调，响应慢 | 单调趋近 |
| **$\xi \approx 0.7$** | **工程最佳** | **兼顾快速与低超调** | **最佳实用** |
