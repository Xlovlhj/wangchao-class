## 1. 概率与分布

### 1.1 为什么需要概率论？

PPT 第 3 页给出了通信工程中概率论的必要性：

- **确定信号无法传递信息**——如果接收方完全知道将要收到什么，那就没有任何"新知识"被传递
- **不可预测性（随机性）是信息承载信号的本质属性**
- 两种随机信号扮演相反的角色：
  - **信息信号**：产生信息（增加接收方的知识）
  - **噪声**：破坏信息（减少接收方的知识）
- 干扰（来自非目标信息源的信号）也可视为一种噪声
- 因此，**描述信息信号和噪声必须使用概率论**

---

### 1.2 概率的基本概念

#### 随机试验与样本空间

- **随机试验（Random Experiment）**：结果无法预先确定但所有可能结果已知的试验
- **样本空间 $S$**：随机试验所有可能结果的集合
- **事件 $A$**：样本空间的子集

#### 概率的公理化定义

概率 $P(A)$ 满足三条公理：

1. **非负性**：$P(A) \geq 0$
2. **规范性**：$P(S) = 1$
3. **可列可加性**：若 $A_1, A_2, \ldots$ 两两互不相容，则 $P\left(\bigcup_i A_i\right) = \sum_i P(A_i)$

#### 古典概型（等可能概型）

当样本空间有限且每个基本事件等可能时：

$$P(A) = \frac{|A|}{|S|} = \frac{\text{事件 }A\text{ 包含的基本事件数}}{\text{样本空间中基本事件总数}}$$

---

### 1.3 互斥事件

若 $A \cap B = \emptyset$，则称 $A$ 与 $B$ **互斥（互不相容）**。

对互斥事件，加法定理简化为：

$$P(A \cup B) = P(A) + P(B)$$

一般情况（容斥原理）：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

---

### 1.4 组合数学基础

从 $n$ 个不同元素中取 $k$ 个：

- **排列**（有序）：$P(n, k) = \frac{n!}{(n-k)!}$
- **组合**（无序）：$C(n, k) = \binom{n}{k} = \frac{n!}{k!(n-k)!}$

---

### 1.5 条件概率与联合概率

#### 条件概率

已知事件 $B$ 发生的条件下，事件 $A$ 发生的概率：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

#### 乘法公式

$$P(A \cap B) = P(A|B) \cdot P(B) = P(B|A) \cdot P(A)$$

#### 全概率公式

若 $\{B_1, B_2, \ldots, B_n\}$ 是样本空间的一个**划分**（互斥且完备），则：

$$P(A) = \sum_{i=1}^{n} P(A|B_i) P(B_i)$$

#### 贝叶斯公式

$$P(B_i|A) = \frac{P(A|B_i) P(B_i)}{\sum_{j=1}^{n} P(A|B_j) P(B_j)} = \frac{P(A|B_i) P(B_i)}{P(A)}$$

> 🔑 **贝叶斯公式的意义**：由"果"推"因"——已知结果 $A$ 发生了，反推各个原因 $B_i$ 的概率。

---

### 1.6 统计独立性

若事件 $A$ 和 $B$ 满足：

$$P(A \cap B) = P(A) \cdot P(B)$$

则称 $A$ 与 $B$ **统计独立**。

等价条件：$P(A|B) = P(A)$ 或 $P(B|A) = P(B)$。

直观理解：知道 $B$ 是否发生，不影响对 $A$ 发生概率的判断。

---

### 1.7 随机变量及其分布

#### 随机变量

**随机变量（Random Variable）** 是将样本空间中的每个结果映射为一个实数的函数。

- **离散随机变量**：取值有限或可列无限
- **连续随机变量**：取值充满某个区间

#### 累积分布函数（CDF）

$$F_X(x) = P(X \leq x)$$

CDF 的性质：
- 单调不减：$x_1 < x_2 \Rightarrow F(x_1) \leq F(x_2)$
- $\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$
- 右连续

**离散随机变量的 CDF**：阶梯状（stepped）
**连续随机变量的 CDF**：光滑连续

#### 概率密度函数（PDF）

$$f_X(x) = \frac{d}{dx} F_X(x)$$

PDF 的性质：
- $f_X(x) \geq 0$
- $\int_{-\infty}^{\infty} f_X(x) dx = 1$
- $P(a < X \leq b) = \int_a^b f_X(x) dx = F(b) - F(a)$

#### 离散随机变量的概率质量函数（PMF）

$$p_X(x_k) = P(X = x_k)$$

离散变量的 PDF 可表示为一系列冲激函数的加权和：

$$f_X(x) = \sum_k p_X(x_k) \delta(x - x_k)$$

> 📌 **混合随机变量**：既包含离散部分又包含连续部分（PPT 第 16 页提到）。

## 2. 统计量

### 2.1 矩（Moments）

$n$ 阶原点矩：

$$m_n = E[X^n] = \int_{-\infty}^{\infty} x^n f_X(x) dx$$

最重要的原点矩——**均值（期望）**（$n=1$）：

$$\mu_X = E[X] = m_1 = \int_{-\infty}^{\infty} x f_X(x) dx$$

---

### 2.2 中心矩（Central Moments）

$n$ 阶中心矩：

$$\mu_n = E[(X - \mu_X)^n] = \int_{-\infty}^{\infty} (x - \mu_X)^n f_X(x) dx$$

最重要的中心矩——**方差**（$n=2$）：

$$\sigma_X^2 = \text{Var}(X) = E[(X - \mu_X)^2] = E[X^2] - (E[X])^2$$

- **标准差**：$\sigma_X = \sqrt{\text{Var}(X)}$
- 方差衡量随机变量围绕均值的**离散程度**

---

### 2.3 百分位数（Percentiles）

**中位数（Median）**：$P(X \leq \text{median}) = 0.5$

**$p$ 分位数**：满足 $F(x_p) = p$ 的值 $x_p$。

---

### 2.4 众数（Mode）

概率密度函数（或概率质量函数）取**最大值**的点。

- 可以有**多个**众数（多峰分布）
- 对对称单峰分布：均值 = 中位数 = 众数

---

## 3. 联合分布与边缘分布

### 3.1 联合概率密度函数

两个随机变量 $X$ 和 $Y$ 的**联合 PDF** 满足：

$$P(a < X \leq b, c < Y \leq d) = \int_a^b \int_c^d f_{XY}(x, y) \, dy \, dx$$

联合 PDF 的性质：
- $f_{XY}(x, y) \geq 0$
- $\int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f_{XY}(x, y) \, dx \, dy = 1$

---

### 3.2 边缘概率密度函数

从联合 PDF 中通过积分"消除"另一个变量得到：

$$f_X(x) = \int_{-\infty}^{\infty} f_{XY}(x, y) \, dy$$

$$f_Y(y) = \int_{-\infty}^{\infty} f_{XY}(x, y) \, dx$$

> 📌 直观理解：联合 PDF 描述两个变量的"全景图"；边缘 PDF 只关注其中一个变量，"投影"掉了另一个维度。

---

## 4. 相关与协方差

### 4.1 相关（Correlation）

两个随机变量 $X$ 和 $Y$ 的**相关**定义为它们乘积的期望：

$$R_{XY} = E[XY] = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} xy \, f_{XY}(x, y) \, dx \, dy$$

---

### 4.2 协方差（Covariance）

$$\text{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - \mu_X \mu_Y$$

协方差的意义：
- $\text{Cov}(X, Y) > 0$：$X$ 和 $Y$ **正相关**（$X$ 大时 $Y$ 也倾向于大）
- $\text{Cov}(X, Y) < 0$：$X$ 和 $Y$ **负相关**（$X$ 大时 $Y$ 倾向于小）
- $\text{Cov}(X, Y) = 0$：$X$ 和 $Y$ **不相关**

> ⚠️ **独立 ⇒ 不相关**，但**不相关 ⇏ 独立**（不相关只保证没有线性关系）。

---

### 4.3 不相关性（Uncorrelatedness）

若 $\text{Cov}(X, Y) = 0$，即 $E[XY] = E[X]E[Y]$，则 $X$ 与 $Y$ **不相关**。

---

### 4.4 归一化相关系数

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

性质：
- $-1 \leq \rho_{XY} \leq 1$
- $\rho_{XY} = \pm 1$：$X$ 和 $Y$ **完全线性相关**（$Y = aX + b$）
- $\rho_{XY} = 0$：不相关

---

## 5. 中心极限定理

### 5.1 随机变量的加法

设 $Z = X_1 + X_2 + \cdots + X_N$，其中 $X_i$ 为独立随机变量。

均值和方差：
$$\mu_Z = \sum_{i=1}^{N} \mu_{X_i}$$
$$\sigma_Z^2 = \sum_{i=1}^{N} \sigma_{X_i}^2$$

（独立条件下，方差可以直接相加。）

---

### 5.2 中心极限定理（Central Limit Theorem, CLT）

> 设 $X_1, X_2, \ldots, X_N$ 是 **独立同分布（i.i.d.）** 的随机变量，均值为 $\mu$，方差为 $\sigma^2$。当 $N$ 足够大时，其和（或均值）近似服从**正态（高斯）分布**：

$$\sum_{i=1}^{N} X_i \xrightarrow{d} \mathcal{N}(N\mu, N\sigma^2)$$

$$\frac{1}{N} \sum_{i=1}^{N} X_i \xrightarrow{d} \mathcal{N}\left(\mu, \frac{\sigma^2}{N}\right)$$

> 🔑 **中心极限定理的伟大之处**：无论原始 $X_i$ 是什么分布（只要方差有限），大量独立随机变量之和总是趋于高斯分布。这解释了为什么高斯噪声在自然界中如此普遍——它是无数微小独立扰动叠加的结果。

---

### 5.3 高斯随机变量的加法

高斯随机变量有一个特殊性质：**独立高斯变量的线性组合仍然是高斯变量**。

若 $X \sim \mathcal{N}(\mu_X, \sigma_X^2)$ 和 $Y \sim \mathcal{N}(\mu_Y, \sigma_Y^2)$ 独立，则：

$$Z = aX + bY \sim \mathcal{N}(a\mu_X + b\mu_Y, a^2\sigma_X^2 + b^2\sigma_Y^2)$$

---

## 6. 自相关与功率谱密度

### 6.1 随机信号的自相关函数

对于**平稳随机过程** $X(t)$，自相关函数定义为：

$$R_X(\tau) = E[X(t) X(t + \tau)]$$

> 📌 回忆 Module 1：确定性信号的自相关是时间积分平均。随机信号的自相关是**统计平均（期望）**。

**性质**：
- $R_X(0) = E[X^2(t)]$（平均功率）
- $R_X(-\tau) = R_X(\tau)$（偶对称，对实信号）
- $|R_X(\tau)| \leq R_X(0)$

---

### 6.2 功率谱密度（Power Spectral Density, PSD）

**Wiener-Khinchin 定理**（对随机信号）：

$$S_X(f) = \int_{-\infty}^{\infty} R_X(\tau) e^{-j2\pi f \tau} d\tau = \mathcal{F}\{R_X(\tau)\}$$

$$R_X(\tau) = \int_{-\infty}^{\infty} S_X(f) e^{j2\pi f \tau} df = \mathcal{F}^{-1}\{S_X(f)\}$$

> 🔑 自相关函数与功率谱密度构成傅里叶变换对——这是连接随机信号**时域统计特性**和**频域能量分布**的核心桥梁。

---

## 7. 课程总结

PPT 第 42 页的精炼总结：

- **随机变量**：如果其在指定未来时刻的具体值无法被预测，则称为随机变量。其可能未来值的信息通常来自**概率模型**。
- **PDF 是 CDF 的导数**：$f_X(x) = \frac{d}{dx}F_X(x)$
- **矩、中心矩和众数**是随机变量的**统计量**。
- **联合 PDF**：给出两个或多个随机变量在指定区间内**同时**取特定值的概率。
- **相关**：两个随机变量的**均值乘积** $E[XY]$。
- **自相关函数和双边功率谱密度**构成**傅里叶变换对**。

## 习题一：骰子概率

> **对应 PPT 第 6 页 Exercise**

---

### 前置知识

**Q1：古典概型的计算公式？**

当所有基本事件等可能时：

$$P(A) = \frac{\text{有利结果数}}{\text{总结果数}}$$

**Q2：什么是"对立事件"？**

事件 $A$ 的对立事件 $\bar{A}$（也叫补事件）：$A$ 不发生。

$$P(\bar{A}) = 1 - P(A)$$

这在计算"至少……"类问题中非常有用。

**Q3：独立事件的概率乘法？**

若 $A_1, A_2, \ldots, A_n$ 相互独立：

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2) \cdots P(A_n)$$

---

### 习题讲解

**题目**：掷一个骰子一次。求以下概率：
- (i) 骰子显示 3
- (ii) 骰子显示 6
- (iii) 骰子显示大于 2 的数
- (iv) 骰子不显示 5

**解答**：

(i) $P(\text{显示 }3) = \dfrac{1}{6}$

（6 个面等可能，只有 1 个是 3。）

(ii) $P(\text{显示 }6) = \dfrac{1}{6}$

（同上，每个面概率相同。）

(iii) 大于 2 的面为 $\{3, 4, 5, 6\}$，共 4 个。

$$P(\text{大于 }2) = \frac{4}{6} = \frac{2}{3}$$

(iv) 使用对立事件：

$$P(\text{不显示 }5) = 1 - P(\text{显示 }5) = 1 - \frac{1}{6} = \frac{5}{6}$$

---

### Bonus：Quiz 解析

> **Quiz**：你会以均匀赔率下注"掷一个骰子 4 次，至少出现一次 6"吗？"掷两个骰子 24 次，至少出现一次双 6"呢？

这是一道经典的**概率论历史题**（de Méré 悖论）。

**第一问**：掷 4 次至少一个 6

$$P(\text{至少一个 6}) = 1 - P(\text{4 次都没有 6}) = 1 - \left(\frac{5}{6}\right)^4$$

$$= 1 - \frac{625}{1296} \approx 0.5177 > 0.5$$

**值得下注！**（胜率略高于 50%。）

**第二问**：掷 24 次至少一次双 6

$$P(\text{至少一次双 6}) = 1 - \left(\frac{35}{36}\right)^{24}$$

$$= 1 - 0.5086 \approx 0.4914 < 0.5$$

**不值得下注！**（胜率略低于 50%。）

> 🔑 历史上赌徒 de Méré 凭经验发现第一种情况有利可图，第二种却亏钱，他百思不得其解，于是请教 Pascal，由此催生了概率论的发展。

## 习题二：扑克牌组合概率

> **对应 PPT 第 8 页 Exercise**

---

### 前置知识

**Q1：组合数公式？**

$$C(n, k) = \binom{n}{k} = \frac{n!}{k!(n-k)!}$$

**Q2：扑克牌的基本结构？**

一副标准扑克牌：52 张，4 种花色（♠ ♥ ♦ ♣），每种花色 13 张（A, 2, 3, ..., 10, J, Q, K）。

**Q3：分步计数的乘法原理？**

若一个任务可分为若干步骤，第 $i$ 步有 $n_i$ 种方式，则总方式数为 $\prod n_i$。

**Q4：超几何分布？**

从 $N$ 个对象中不放回地抽取 $n$ 个，$K$ 个"成功"对象恰好被抽中 $k$ 个的概率：

$$P(X = k) = \frac{\binom{K}{k} \binom{N-K}{n-k}}{\binom{N}{n}}$$

---

### 习题讲解

**题目**：从一副洗好的 52 张扑克牌顶部发 4 张牌，求 4 张牌花色全相同的概率。

**解答**：

**思路**：考虑有利情况数和总情况数。

**总情况数**：从 52 张中选 4 张：$\binom{52}{4}$

**有利情况**：4 张同花色

- 选一种花色：$\binom{4}{1} = 4$ 种
- 从该花色的 13 张中选 4 张：$\binom{13}{4}$ 种

$$P(\text{同花色}) = \frac{\binom{4}{1} \cdot \binom{13}{4}}{\binom{52}{4}}$$

计算：

$$\binom{13}{4} = \frac{13 \times 12 \times 11 \times 10}{4 \times 3 \times 2 \times 1} = 715$$

$$\binom{52}{4} = \frac{52 \times 51 \times 50 \times 49}{4 \times 3 \times 2 \times 1} = 270725$$

$$P = \frac{4 \times 715}{270725} = \frac{2860}{270725} \approx 0.01056 \approx 1.056\%$$

---

### Bonus：Quiz 解析

> **Quiz**：在扑克中，"四条"（four of a kind）为什么能打败"葫芦"（full house）？

- **四条**（4 张同值 + 1 张杂牌）：先从 13 个面值中选 1 个（四条），再从剩余 48 张中选 1 张（杂牌）。组合数 $\approx 13 \times 48 = 624$。
- **葫芦**（3 张同值 + 2 张另一同值）：先从 13 个面值中选 1 个做三条（$\binom{4}{3}$），再从 12 个面值选 1 个做对子（$\binom{4}{2}$）。组合数 $\approx 13 \times 4 \times 12 \times 6 = 3744$。

> 🔑 四条（624 种）比葫芦（3744 种）**更稀有**，所以四条更大——扑克牌的大小由概率决定，越稀有的牌型越大！

## 习题三：贝叶斯定理——疾病检测

> **对应 PPT 第 10 页 Exercise**

---

### 前置知识

**Q1：贝叶斯公式是什么？**

$$P(B|A) = \frac{P(A|B) \cdot P(B)}{P(A)}$$

**Q2：什么是先验概率和后验概率？**

- **先验概率 $P(B)$**：在获得新证据（测试结果）之前对事件 $B$ 的判断
- **后验概率 $P(B|A)$**：获得新证据后更新的判断
- **似然 $P(A|B)$**：在 $B$ 为真时观察到证据 $A$ 的概率

**Q3：全概率公式的作用？**

用于计算分母 $P(A)$——"证据"出现的总概率：

$$P(A) = P(A|B)P(B) + P(A|\bar{B})P(\bar{B})$$

---

### 习题讲解

**题目**：

- Jo 做了一种疾病检测
- 95% 的**真患者**得到阳性结果（灵敏度 = 95%）
- 95% 的**非患者**得到阴性结果（特异度 = 95%）
- Jo 这个年龄段和背景的人中，1% 患有该病（先验概率）
- Jo 的检测结果是**阳性**
- **问：Jo 真正患病的概率是多少？**

**解答**：

设：
- $D$：患病事件，$P(D) = 0.01$
- $+$：检测阳性事件
- $P(+|D) = 0.95$（真阳性率 = 灵敏度）
- $P(-|\bar{D}) = 0.95$，所以 $P(+|\bar{D}) = 0.05$（假阳性率）

**用贝叶斯公式**：

$$P(D|+) = \frac{P(+|D) \cdot P(D)}{P(+|D)P(D) + P(+|\bar{D})P(\bar{D})}$$

$$= \frac{0.95 \times 0.01}{0.95 \times 0.01 + 0.05 \times 0.99}$$

$$= \frac{0.0095}{0.0095 + 0.0495} = \frac{0.0095}{0.059} \approx 0.161$$

$$P(D|+) \approx 16.1\%$$

> 🔑 **非常反直觉！** 检测 95% 准确，阳性结果，但真正患病的概率只有约 **16%**！原因：疾病本身非常罕见（先验只有 1%），假阳性的人数远多于真阳性。这被称为**基础率谬误（Base Rate Fallacy）**——忽略先验概率会导致严重误判。

## 习题四：统计独立性

> **对应 PPT 第 12 页 Exercise**

---

### 前置知识

**Q1：独立性判断条件？**

$A$ 与 $B$ 独立当且仅当：
$$P(A \cap B) = P(A) \cdot P(B)$$

或等价地，$P(A|B) = P(A)$（当 $P(B) > 0$）。

**Q2：多个事件的独立性？**

$A, B, C$ **两两独立**不保证**相互独立**。相互独立要求对任意子集都满足乘积条件。

**Q3：独立与不相关的区别（前瞻）？**

- **独立**：$f_{XY}(x,y) = f_X(x) f_Y(y)$（最强条件，无任何依赖）
- **不相关**：$E[XY] = E[X]E[Y]$（较弱条件，仅无线性依赖）

---

### 习题讲解

**典型题**：掷两个骰子，$A$ = "第一个骰子是偶数"，$B$ = "第二个骰子是奇数"。判断 $A$ 与 $B$ 是否独立。

**解答**：

$$P(A) = \frac{3}{6} = \frac{1}{2}$$

$$P(B) = \frac{3}{6} = \frac{1}{2}$$

$$P(A \cap B) = P(\text{第一个偶数，第二个奇数})$$

两个骰子结果独立：

$$P(A \cap B) = \frac{3}{6} \times \frac{3}{6} = \frac{1}{4}$$

验证：$P(A \cap B) = \frac{1}{4} = \frac{1}{2} \times \frac{1}{2} = P(A) \cdot P(B)$

✅ $A$ 和 $B$ 是独立的（直观上也显然，两个骰子互不影响）。

---

**典型题（进阶）**：从一副牌中抽一张，

- $A$ = "抽到 K"
- $B$ = "抽到红桃"

判断 $A$ 与 $B$ 是否独立。

$P(A) = \frac{4}{52} = \frac{1}{13}$

$P(B) = \frac{13}{52} = \frac{1}{4}$

$P(A \cap B) = P(\text{红桃 K}) = \frac{1}{52}$

验证：$P(A)P(B) = \frac{1}{13} \times \frac{1}{4} = \frac{1}{52} = P(A \cap B)$

✅ 是独立的（花色和面值是独立属性）。

## 习题五：CDF 与 PDF

> **对应 PPT 第 17 页 Exercise**

---

### 前置知识

**Q1：CDF 和 PDF 的关系？**

$$F_X(x) = \int_{-\infty}^{x} f_X(t) dt$$

$$f_X(x) = \frac{d}{dx}F_X(x)$$

**Q2：如何从 PDF 求概率？**

$$P(a < X \leq b) = F(b) - F(a) = \int_a^b f_X(x) dx$$

**Q3：均匀分布的特征？**

$X \sim U(a, b)$：

$$f_X(x) = \begin{cases} \dfrac{1}{b-a}, & a \leq x \leq b \\ 0, & \text{其他} \end{cases}$$

$$F_X(x) = \begin{cases} 0, & x < a \\ \dfrac{x-a}{b-a}, & a \leq x \leq b \\ 1, & x > b \end{cases}$$

---

### 习题讲解

**典型题**：设随机变量 $X$ 的 PDF 为 $f_X(x) = \begin{cases} 2x, & 0 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$

(1) 验证这是有效的 PDF  
(2) 求 CDF $F_X(x)$  
(3) 求 $P(0.25 < X \leq 0.75)$  
(4) 求 $E[X]$ 和 $\text{Var}(X)$

**解答**：

**(1) 验证 PDF：**

$$\int_0^1 2x \, dx = [x^2]_0^1 = 1 \quad \checkmark$$

且 $f_X(x) \geq 0$ 对所有 $x$ 成立。✅

**(2) 求 CDF：**

$$F_X(x) = \int_0^x 2t \, dt = x^2, \quad 0 \leq x \leq 1$$

$$F_X(x) = \begin{cases} 0, & x < 0 \\ x^2, & 0 \leq x \leq 1 \\ 1, & x > 1 \end{cases}$$

**(3) 求概率：**

$$P(0.25 < X \leq 0.75) = F(0.75) - F(0.25) = (0.75)^2 - (0.25)^2 = 0.5625 - 0.0625 = 0.5$$

**(4) 求均值和方差：**

$$E[X] = \int_0^1 x \cdot 2x \, dx = \int_0^1 2x^2 dx = \left[\frac{2}{3}x^3\right]_0^1 = \frac{2}{3}$$

$$E[X^2] = \int_0^1 x^2 \cdot 2x \, dx = \int_0^1 2x^3 dx = \left[\frac{1}{2}x^4\right]_0^1 = \frac{1}{2}$$

$$\text{Var}(X) = E[X^2] - (E[X])^2 = \frac{1}{2} - \frac{4}{9} = \frac{9 - 8}{18} = \frac{1}{18}$$

## 习题六：中心极限定理应用

> **对应 PPT 第 37 页 Exercise**

---

### 前置知识

**Q1：中心极限定理怎么用？**

当 $n$ 足够大（通常 $n \geq 30$），无论原始分布如何，独立同分布随机变量之和近似服从正态分布。

**Q2：标准化公式？**

$$Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)$$

$$P(X \leq x) \approx \Phi\left(\frac{x - \mu}{\sigma}\right)$$

其中 $\Phi(\cdot)$ 是标准正态分布的 CDF。

**Q3：高斯分布（正态分布）的 PDF？**

$$f_X(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

记号：$X \sim \mathcal{N}(\mu, \sigma^2)$

---

### 习题讲解

**典型题**：某电子元件寿命均值为 100 小时，标准差为 15 小时。现随机取 36 个元件，求其平均寿命超过 105 小时的概率。

**解答**：

设各元件寿命为 $X_i$（独立同分布），$\mu = 100$，$\sigma = 15$，$n = 36$。

样本均值：$\bar{X} = \frac{1}{36} \sum_{i=1}^{36} X_i$

由 CLT：

$$\bar{X} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right) = \mathcal{N}\left(100, \frac{225}{36}\right) = \mathcal{N}(100, 6.25)$$

标准误差：$\sigma_{\bar{X}} = \frac{15}{\sqrt{36}} = 2.5$

标准化：

$$Z = \frac{\bar{X} - 100}{2.5} \sim \mathcal{N}(0, 1)$$

$$P(\bar{X} > 105) = P\left(Z > \frac{105 - 100}{2.5}\right) = P(Z > 2)$$

查标准正态分布表：$\Phi(2) = 0.9772$

$$P(Z > 2) = 1 - 0.9772 = 0.0228 \approx 2.28\%$$

---

**典型题（高斯变量的线性组合）**：

设 $X \sim \mathcal{N}(10, 4)$ 和 $Y \sim \mathcal{N}(5, 9)$ 独立，求 $Z = X - Y$ 的分布。

$$E[Z] = 10 - 5 = 5$$
$$\text{Var}(Z) = 4 + 9 = 13$$

$$Z \sim \mathcal{N}(5, 13)$$

> 🔑 独立高斯变量的任何线性组合仍是高斯变量——这是高斯分布独有的"再生性质"。

## 习题七：自相关与功率谱密度

> **对应 PPT 第 41 页 Exercise**

---

### 前置知识

**Q1：平稳随机过程的自相关？**

$$R_X(\tau) = E[X(t) X(t + \tau)]$$

对于**宽平稳（WSS）**过程，自相关只取决于时间差 $\tau$。

**Q2：Wiener-Khinchin 定理？**

$$S_X(f) = \mathcal{F}\{R_X(\tau)\} = \int_{-\infty}^{\infty} R_X(\tau) e^{-j2\pi f\tau} d\tau$$

**Q3：常见随机过程——白噪声？**

白噪声的自相关：$R(\tau) = \frac{N_0}{2} \delta(\tau)$

功率谱密度：$S(f) = \frac{N_0}{2}$（所有频率上功率相同）

> 白噪声的"白"类比白光——包含所有频率分量，且各频率能量相同。

**Q4：自相关在 $\tau = 0$ 处的值？**

$R(0) = E[X^2(t)]$ = 平均功率 = $\int_{-\infty}^{\infty} S_X(f) df$

---

### 习题讲解

**典型题1**：已知平稳随机过程的功率谱密度为：

$$S_X(f) = \begin{cases} A, & |f| \leq B \\ 0, & |f| > B \end{cases}$$

（理想低通带限白噪声）

(1) 求自相关函数 $R_X(\tau)$  
(2) 求平均功率

**解答**：

**(1)** 由 Wiener-Khinchin 定理，对 $S_X(f)$ 求逆傅里叶变换：

$$R_X(\tau) = \int_{-B}^{B} A e^{j2\pi f\tau} df = A \left[\frac{e^{j2\pi f\tau}}{j2\pi\tau}\right]_{-B}^{B}$$

$$= A \cdot \frac{e^{j2\pi B\tau} - e^{-j2\pi B\tau}}{j2\pi\tau} = 2AB \cdot \frac{\sin(2\pi B\tau)}{2\pi B\tau} = 2AB \cdot \text{sinc}(2B\tau)$$

**(2)** 平均功率：

$$P = R_X(0) = 2AB \cdot \text{sinc}(0) = 2AB$$

或用频域计算：$P = \int_{-B}^{B} A \, df = 2AB$ ✅

---

**典型题2**：已知自相关 $R_X(\tau) = \sigma^2 e^{-\alpha |\tau|}$，求功率谱密度。

$$S_X(f) = \int_{-\infty}^{\infty} \sigma^2 e^{-\alpha |\tau|} e^{-j2\pi f\tau} d\tau$$

$$= \sigma^2 \left[\int_{-\infty}^{0} e^{\alpha\tau} e^{-j2\pi f\tau} d\tau + \int_{0}^{\infty} e^{-\alpha\tau} e^{-j2\pi f\tau} d\tau\right]$$

$$= \sigma^2 \left[\frac{1}{\alpha - j2\pi f} + \frac{1}{\alpha + j2\pi f}\right] = \frac{2\alpha\sigma^2}{\alpha^2 + (2\pi f)^2}$$

这是**洛伦兹型**频谱——低频功率大，高频衰减。

## 📋 核心公式速查表

| 概念 | 公式 | 说明 |
|------|------|------|
| 条件概率 | $P(A\|B) = \frac{P(A \cap B)}{P(B)}$ | $B$ 发生下 $A$ 的概率 |
| 贝叶斯公式 | $P(B\|A) = \frac{P(A\|B)P(B)}{P(A)}$ | 由果推因 |
| 全概率 | $P(A) = \sum P(A\|B_i)P(B_i)$ | $\{B_i\}$ 是划分 |
| 独立性 | $P(A \cap B) = P(A)P(B)$ | 互不影响 |
| CDF | $F_X(x) = P(X \leq x)$ | 累积概率 |
| PDF | $f_X(x) = dF_X(x)/dx$ | 概率密度 |
| 期望 | $E[X] = \int x f_X(x) dx$ | 均值 |
| 方差 | $\text{Var}(X) = E[(X-\mu)^2]$ | 离散程度 |
| 协方差 | $\text{Cov}(X,Y) = E[XY] - E[X]E[Y]$ | 线性相关度 |
| 相关系数 | $\rho = \text{Cov}(X,Y)/(\sigma_X \sigma_Y)$ | $[-1, 1]$ |
| CLT | $\sum X_i \xrightarrow{d} \mathcal{N}(n\mu, n\sigma^2)$ | $n$ 大时趋于正态 |
| 自相关 | $R_X(\tau) = E[X(t)X(t+\tau)]$ | 随机过程 |
| PSD | $S_X(f) = \mathcal{F}\{R_X(\tau)\}$ | Wiener-Khinchin |
