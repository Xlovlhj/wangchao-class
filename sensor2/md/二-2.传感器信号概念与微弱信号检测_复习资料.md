## 第一部分：知识梳理

### 第1章 信号的基本概念

#### 1.1 信号的分类

**⭐ 重点：两大分类体系**

**（1）确定性信号与随机信号**

| 类型 | 定义 | 特点 |
|------|------|------|
| **确定性信号** | 能用明确的数学关系表达的信号 | 可预测，可精确描述 |
| **随机信号** | 不能明确用数学关系表达，只能通过统计观察描述 | 分平稳随机信号和非平稳随机信号 |
| — 平稳随机信号 | 统计特性不随时间推移而变化 | 与时间无关 |
| — 非平稳随机信号 | 不满足平稳性要求 | 统计特性随时间变化 |

**（2）连续信号与离散信号**

| | 时间连续 | 时间离散 |
|------|:------:|:------:|
| **幅值连续** | 连续信号 | 离散信号（采样信号） |
| **幅值离散** | 量化信号 | 数字信号 |

#### 1.2 信号的描述方法

**⭐ 重点：时域与频域**

| 描述方法 | 核心 | 分析内容 |
|----------|------|----------|
| **时域描述** | 反映信号幅值随时间变化的关系 | 时间变量函数或序列，系统时间响应特性 |
| **频域描述** | 以频率作为独立变量 | 从频率分布角度研究信号结构及各种频率成分的幅值和相位关系 |

### 第2章 微弱信号检测概述

#### 2.1 基本概念

**微弱信号**：相对背景噪声而言，信号幅度的绝对值很小、**信噪比很低（远小于1）**的信号。

**微弱信号检测的任务：**
- 采用电子学、信息论、计算机及物理学、数学的方法
- 分析噪声产生的原因和规律
- 研究被测信号的特点与相关性
- 对被噪声淹没的微弱有用信号进行**提取和测量**

**目的：** 从噪声中提取有用信号，提高检测系统输入输出信号的**信噪比**。

#### 2.2 噪声

**噪声定义：** 对有用信号的某种不期望的扰动，包括非被测信号引起的噪声和来自于被测对象、传感器、测量系统内部的噪声。噪声是一种**连续型随机变量**。

**⭐ 重点：噪声的分类体系**

```
噪声
├── 自然噪声（自然界外部噪声）
│   ├── 天体噪声（太阳、银河系电磁辐射）
│   └── 空间噪声（大气噪声、雷电噪声等）
├── 人为噪声（人类活动外部干扰）
│   ├── 点火噪声（汽车火花塞等）
│   ├── 电机噪声（电刷火花、交变磁场）
│   └── 感应噪声（电力线、工业设备交变电磁场）
└── 电路噪声（电路元件内部噪声）
    ├── 热噪声 — 导体中电子热运动引起，所有电阻类元件都存在，属白噪声
    ├── 散粒噪声 — 载流子通过PN结/真空管势垒时的离散性导致电流起伏，属白噪声
    └── 闪烁噪声（1/f噪声）— 半导体晶格缺陷/杂质引起，低频段影响显著
```

#### 2.3 噪声的概率分布

**⭐ 重点：噪声统计特征量**

| 统计量 | 公式 | 含义 |
|--------|------|------|
| **区间概率** | $P(n_1<n<n_2)=\int_{n_1}^{n_2} p(n)dn$ | 噪声落在区间内的概率 |
| **均值（数学期望）** | $E[n]=\int_{-\infty}^{\infty} np(n)dn$ | 噪声的直流分量/中心位置（电子噪声通常为0） |
| **方差** | $D[n]=\int_{-\infty}^{\infty}(n-E[n])^2 p(n)dn = E[n^2]-E^2[n]$ | 噪声偏离均值的程度，衡量功率波动强度 |
| **均方值（时域）** | $E[n^2]=\lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} n^2(t)dt$ | 噪声平均功率（1Ω负载时=噪声功率），计算SNR的关键 |

> 当噪声均值为0时，方差 = 平均功率 $E[n^2]$。

#### 2.4 噪声的相关函数

**自相关函数：** 描述信号在两个不同时刻 $t$ 和 $t-\tau$ 的相似程度。
$$R_{xx}(\tau) = \lim_{T\to\infty} \frac{1}{2T}\int_{-T}^{T} x(t)x(t-\tau)dt$$

**互相关函数：** 描述两个不同信号之间的相似程度。
$$R_{xy}(\tau) = \lim_{T\to\infty} \frac{1}{2T}\int_{-T}^{T} x(t)y(t-\tau)dt$$

### 第3章 微弱信号检测方法

#### 3.1 相关检测法

**核心思想：** 利用信号**周期性**和噪声**随机性**的特点，通过自相关或互相关函数值的计算，从噪声中检测出微弱信号。

**⭐ 重点：自相关检测 vs 互相关检测**

##### （1）自相关检测

| 相关项 | 特性 |
|--------|------|
| $R_{ss}(\tau)$ — 信号自相关 | 若 $s(t)$ 是周期信号，$R_{ss}(\tau)$ 具有相同周期，不随 $\tau$ 增大而消失 |
| $R_{sn}(\tau)$ — 信号与噪声互相关 | 信号与噪声独立，长时间积分后趋近于0 |
| $R_{ns}(\tau)$ — 噪声与信号互相关 | 同上，趋近于0 |
| $R_{nn}(\tau)$ — 噪声自相关 | 白噪声仅在 $\tau=0$ 处有峰值，随 $\tau$ 增大快速衰减为0 |

**优点：**
- 能在极低信噪比下检测微弱周期信号
- 实现简单（仅需延时、乘法、积分）

**局限：**
- 丢失信号**相位信息**，只能检测频率/周期
- 对**非周期信号无效**

##### （2）互相关检测

| 相关项 | 特性 |
|--------|------|
| $R_{sy}(\tau)$ — 信号与参考信号互相关 | 当 $y(t)$ 与 $s(t)$ 同步（频率/相位匹配）时出现明显峰值 |
| $R_{ny}(\tau)$ — 噪声与参考信号互相关 | 噪声与参考信号独立，长时间积分趋近于0 |

**⭐ 互相关检测核心优势：**

| 优势 | 说明 |
|------|------|
| **噪声抑制更强** | 自相关中 $R_{nn}(\tau)$ 在 $\tau=0$ 处有峰值会干扰；互相关中 $R_{ny}(\tau)$ 几乎全程为0 |
| **可恢复相位信息** | 峰值位置 $\tau$ 反映时间差/相位差，可测时延、多普勒频移 |

**典型应用：** 雷达/声呐测距、通信系统同步、生物医学信号检测。

#### 3.2 锁相放大器（Lock-in Amplifier）

**⭐ 重点：锁相放大器核心概念**

> 锁相放大器是利用**互相关原理**设计的同步相干检测仪，具有极强的抑制噪声能力。

**三大部分：**

| 模块 | 功能 |
|------|------|
| **信号通道** | 前置放大器（低噪声放大）→ 有源滤波器（带通滤波）→ AC 放大器（提升信噪比） |
| **参考通道** | 触发电路 → 倍频电路 → 相移电路 → 方波驱动（生成同步参考方波） |
| **相关器（核心）** | 乘法器（互相关运算）+ 积分器（低通滤波，输出直流信号） |

**⭐ 三大核心特点（抑制噪声的基本出发点）：**

| 特点 | 说明 |
|------|------|
| **(1) 调制放大** | 将直流或慢变信号频谱迁移到调制频率 $\omega_m$ 处再放大，**避开 1/f 噪声** |
| **(2) 相敏检测** | 利用相关器实现解调，同时检测频率和相位，噪声与信号**同频又同相概率极小** |
| **(3) 窄带低通滤波** | 低通滤波器频带可做得极窄，带宽不受调制频率影响，稳定性高 |

**性能指标：** 等效噪声带宽可达 0.0004Hz，增益可高达 $10^{11}$ 以上，**0.1nV 的微弱信号可放大到 10V 以上**。

**⭐ 实测对比（1kHz 正弦波 + 0.1Vrms 白噪声）：**

| 信号电平 | 信噪比 | 毫伏表结果 | 锁相放大器结果 | 说明 |
|:------:|:------:|:------:|:------:|------|
| 1Vrms | 噪声=10%信号 | 1Vrms | 0.999Vrms | 两者都准确 |
| 100mVrms | 噪声=100%信号 | 140mVrms | 99mVrms | 毫伏表严重偏高 |
| 1mVrms | 噪声=100倍信号 | 105mVrms | 1.01mVrms | 毫伏表完全被噪声淹没 |
| 0.1mVrms | 噪声=1000倍信号 | 105mVrms | 0.107mVrms | 锁相放大器仍以7%误差检出 |

> **结论：** 锁相放大器能在比目的信号强 **1000 倍**的噪声中几乎准确无误地检测出信号。

**发展历程：** 模拟锁相放大器(ALIA) → 数字锁相放大器(DLIA)（基于单片机 / DSP / PC 系统级模块化）。

#### 3.3 同步积累法

**核心思想：** 基于信号的**稳定性**和噪声的**随机性**。信号多次重复时，每个周期信号受到的干扰不同，对畸变信号多次对照即可识别出信号原形。重复次数越多，信噪比越高。

**工作原理：**
- 信号通路被分配器轮流接到不同积累器
- 分配器工作周期与信号重复周期相同
- 每次信号到来的时间区间恰好接**同一个积累器**（同步积累）
- 重复次数足够多即可提取微弱信号

**⭐ 对比：**

| 特性 | 同步积累器 | 锁相放大器 |
|------|:--------:|:--------:|
| 适用信号类型 | 周期性窄脉冲信号 | 正弦/余弦等连续周期信号 |
| 核心机制 | 多周期同步累加 | 乘法+积分的互相关运算 |
| 信噪比提升 | 随积累次数提升 | 随积分时间常数提升 |
| 应用场景 | 雷达脉冲检测、脉冲式传感器 | 光谱分析、连续波传感器、阻抗测量 |

---

#### 3.4 同步积分器

- 采用对信号和噪声多次累积平均的方法提取已知频率的信号
- **特别适用于方波信号**
- 信号只有两个状态，只需两个同步积累器（积分电容 $C_1$、$C_2$）
- 同步开关由与输入方波同频的时钟控制，轮流将电流切换到两个电容
- 信号在每个电容上持续累加，噪声因正负随机而相互抵消

---

#### 3.5 取样积分器

利用对信号**逐点多次采样、积分求平均值**的方法。

**关键前提：** 采样周期必须与信号周期相同，每次采样点在信号波形上位置固定。

**工作过程：**
1. 前置放大 → 同步开关 S（仅在目标位置导通）
2. 积分电容 C 存储多次采样结果（积分平均）
3. 输出缓冲放大得到平滑信号
4. 参考信号经延时 $t_0$ 后生成同步取样脉冲

> 信号稳定，每次采样值不变；噪声随机，积分平均后相互抵消趋近于 0。

---

#### 3.6 数字多点平均器

**⭐ 重点：数字化多通道同步积累器**

取样间隔控制器控制 N（如 1024）个开关顺序打开，对信号波形上 N 个点顺序取样，结果存入 N 个电容器中，积累完成后依次输出，恢复信号波形。

**信号通路：** 预处理（放大、滤波）→ S/H（采样保持）→ ADC → 累加 → 存储 → DAC/输出

**信噪比提升原理：**
- 信号部分：每次采样真实值相同，m 次累加后幅度线性增长
- 噪声部分：随机正负抵消，累加后幅度仅按 $\sqrt{m}$ 倍增长
- 信噪比提升 $\sqrt{m}$ 倍

**适用条件：**
1. 信号必须是周期性重复信号
2. 同步信号必须与测试信号同频、同相
3. 取样点数 i 及扫描次数 m 必须足够大
4. 硬件有足够的取样速率

### 第4章 传感器抗干扰技术

#### 4.1 干扰形成三要素

**⭐ 重点：干扰三要素**

```
干扰源 (Source) ──→ 传播途径 (Path) ──→ 敏感设备 (Susceptible)
```

> **抗干扰设计的核心思路：破坏这三个要素中的至少一个。**

#### 4.2 干扰的分类

**（1）按来源分**

| 类型 | 来源 | 举例 |
|------|------|------|
| **外部干扰** | 与系统结构无关，由使用条件和外界环境决定 | 雷电、静电、空间电磁辐射、电机、开关电源、变频器 |
| **内部干扰** | 系统内部元器件、信道、负载、电源引起 | — |

**（2）内部干扰三种类型**

| 类型 | 说明 |
|------|------|
| **信号通道干扰** | 共模干扰、静电耦合干扰、传导耦合干扰 |
| **电源电路干扰** | 过压、欠压、浪涌、下陷、尖峰等 |
| **数字电路干扰** | 高速开关状态形成较大干扰 |

#### 4.3 干扰的引入方式

**⭐ 重点：四种耦合方式**

| 方式 | 机理 |
|------|------|
| **静电耦合** | 干扰经杂散电容耦合到电路 |
| **电磁耦合** | 干扰经互感耦合到电路 |
| **公共阻抗耦合** | 电流经两个以上电路间公共阻抗耦合 |
| **辐射电磁干扰和漏电流耦合** | 强电磁辐射 + 绝缘不良引起的耦合 |

**⭐ 重点：串模干扰 vs 共模干扰**

| | **串模干扰 (Normal-Mode)** | **共模干扰 (Common-Mode)** |
|------|:--------:|:--------:|
| 定义 | 干扰信号与有用信号**串联叠加**，表现为两信号线间电压差 | 干扰同时出现在两根信号线（或信号线与参考地），幅度相位基本相同 |
| 来源 | 长距离传输线拾取的外部电磁信号、信号源电路内部固有噪声 | 设备间地电位差、空间电磁场感应耦合 |
| 特点 | 直接叠加在被测信号上，抑制难度较大 | 利用差分传输和高CMRR运放可有效抑制 |

#### 4.4 硬件抗干扰技术

**⭐ 重点：四大硬件抗干扰技术**

##### （1）接地技术

| 接地方式 | 原理 | 适用 |
|----------|------|------|
| **单点接地** | 所有接地点连接到一个唯一接地点 | 低频电路（<1MHz），避免地环路干扰 |
| **多点接地** | 各接地点就近连接到低阻抗接地平面 | 高频电路（>10MHz） |

**关键原则：**
- **数模地分离**：模拟地(AGND)和数字地(DGND)必须分开走线，最终在 ADC 处单点汇合
- **屏蔽层接地规范**：屏蔽层采用**单端接地**（通常在接收端），避免多点接地形成地环路

##### （2）屏蔽技术

| 类型 | 原理 | 材料 | 应用 |
|------|------|------|------|
| **静电屏蔽** | 导电良好金属封闭容器 + 接地 | 金属 | 电源变压器屏蔽层、信号屏蔽线 |
| **电磁屏蔽** | 高频电磁场在金属屏蔽层产生涡流效应，生成反向磁场 | 低阻金属（铜） | 传感器金属外壳、屏蔽线缆铜编织网 |
| **低频磁屏蔽** | 高导磁率材料为磁力线提供低磁阻通路 | 坡莫合金、硅钢片 | 霍尔传感器、磁通门等 |

##### （3）滤波技术

| 滤波类型 | 目的 | 实现 |
|----------|------|------|
| **电源滤波** | 滤除电源线高频噪声与低频纹波 | π型LC滤波器粗滤 + 0.1μF去耦电容 + 100~1000μF电解电容 |
| **RC低通滤波** | 处理变化缓慢的模拟信号 | 电阻+电容，结构简单 |
| **有源滤波** | 既能滤波又能放大 | 运算放大器构建 |
| **抗混叠滤波** | ADC前的"守门人"，防高频噪声混叠 | **强制使用** |

##### （4）隔离技术

| 方式 | 原理 | 应用 |
|------|------|------|
| **光电耦合器** | 电→光→电转换，切断电信号通路 | 隔离数字控制与反馈信号 |
| **隔离放大器** | 电磁或光电手段，放大同时实现电气隔离 | 工业传感器长距离传输 |
| **隔离电源模块** | 高频变压器能量传输，无直接电气连接 | 为敏感传感器单独供电 |

#### 4.5 软件抗干扰技术

**⭐ 重点：软件抗干扰方法**

| 方法 | 原理 | 适用 |
|------|------|------|
| **算术平均滤波** | 连续采集 N 个数据，计算算术平均值 | 抑制随机噪声，温度、液位等缓变信号 |
| **中值滤波** | 连续采集 N 个数据，排序取中间值 | 滤除偶然脉冲干扰（毛刺），振动、压力 |
| **滑动平均滤波** | 固定长度队列，先进先出，实时更新平均值 | 保持实时性，抑制周期性干扰 |
| **卡尔曼滤波** | "预测-校正"循环，动态调整权重 | 无人机姿态、自动驾驶、机器人位姿追踪 |
| **数据有效性校验** | 设置合理上下限，超限舍弃 | 防错误数据影响 |
| **看门狗定时器** | 程序跑飞未喂狗 → 触发系统复位 | **系统最后一道防线** |
| **软件陷阱** | 专门的出错处理程序 | 让弹飞的程序安定下来 |

#### 4.6 综合接地要点

| 接地类型 | 要点 |
|----------|------|
| 保护接地 vs 工作接地 | 两种类型 |
| 交流地 vs 信号地 | **不能共用** |
| 浮地与接地 | 根据场景选择 |
| 数字地 | TTL、CMOS 等数字逻辑电路的零电位 |
| 模拟地 | 三线采样双层屏蔽浮地技术提高抗共模干扰能力 |
| 信号地（传感器地） | 以 5Ω 接地电阻一点入地，**不浮空** |
| 屏蔽地 | 电场屏蔽接大地；电磁场屏蔽用低阻金属接大地；磁路屏蔽用高磁材料 |
| 功率地 | 电流大，线径粗，与小信号地线分开 |

#### 4.7 应用案例

**⭐ 重点：两个典型场景**

**（1）心电监护仪 (ECG)：**

| 层级 | 措施 |
|------|------|
| 硬件 | 高CMRR仪表放大器（>100dB）→ 右腿驱动（RLD，衰减共模噪声20-40dB）→ 屏蔽电极电缆 + 前端低通滤波 |
| 软件 | 工频陷波（切除50/60Hz）→ 小波变换（基线漂移校正 + 肌电噪声分离） |

**（2）工业自动化（港口起重机 + 汽车CAN总线）：**

| 层级 | 措施 |
|------|------|
| 硬件 | 屏蔽双绞线/光纤传输、TVS管抗浪涌、独立信号接地、共模电感 |
| 软件 | 中位值平均滤波、CRC循环冗余校验、CAN协议原生帧校验与自动重传 |

## 第二部分：习题精讲

### 习题1：试比较自相关检测和互相关检测的优缺点。

**📚 前置知识：**
- 自相关函数：$R_{xx}(\tau)$
- 互相关函数：$R_{xy}(\tau)$
- 信号周期性与噪声随机性的利用

**🔍 详细解答：**

| 对比维度 | 自相关检测 | 互相关检测 |
|----------|:--------:|:--------:|
| 信号适用范围 | 仅适用**周期信号** | 适用周期信号，需已知参考信号 |
| 相位信息 | **丢失**相位信息 | **保留**相位信息（可测时延） |
| 噪声抑制 | $R_{nn}(\tau)$ 在 $\tau=0$ 处有峰值干扰 | $R_{ny}(\tau)\approx0$，抑制更强 |
| 实现复杂度 | 简单（延时+乘法+积分） | 较复杂（需同步参考信号） |
| 检测信噪比 | 受限于 $R_{nn}$ 的残余 | 可实现**更低**检测信噪比 |

> **结论：** 互相关检测噪声抑制更强、可保留相位信息；但需要同步参考信号。

**💡 易错点：** 自相关在 $\tau=0$ 处噪声自相关有峰值，这是互相关优于自相关的关键原因。

### 习题2：简述锁相放大器的三大抑制噪声特点。

**📚 前置知识：**
- 锁相放大器结构（信号通道、参考通道、相关器）
- 1/f 噪声特性
- 相敏检测原理

**🔍 详细解答：**

| 特点 | 原理 | 效果 |
|------|------|------|
| **(1) 调制放大** | 将直流/慢变信号频谱迁移到调制频率 $\omega_m$ 处再放大 | **避开 1/f 噪声**不利影响 |
| **(2) 相敏检测** | 互相关器同时检测频率和相位，解调信号 | 噪声与信号同频又同相的概率极小 |
| **(3) 窄带低通滤波** | 低通滤波器频带极窄，带宽不受调制频率影响 | 稳定性高，等效噪声带宽可达 0.0004Hz |

> **综合效果：** 增益 $10^{11}$ 以上，能从比信号强 **1000 倍**的噪声中检测信号。

### 习题3：比较取样积分器和数字多点平均器的异同。

**📚 前置知识：**
- 取样积分器：逐点采样+积分平均
- 数字多点平均器：多点数字化同步积累

**🔍 详细解答：**

| 对比项 | 取样积分器 | 数字多点平均器 |
|--------|:--------:|:--------:|
| 采样方式 | 单个采样保持器，逐点扫描 | N 个通道同步多点采样 |
| 实现方式 | 模拟（电容积分） | 数字化（ADC+累加器+存储） |
| 测量速度 | 慢（一次一个点） | 快（一次扫描采 N 个点） |
| 信噪比提升 | 随扫描次数 $m$ 提升 $\sqrt{m}$ 倍 | 随平均次数 $m$ 提升 $\sqrt{m}$ 倍 |
| 灵活性 | 较低 | 高（可调采样间隔和扫描次数） |

### 习题4：串模干扰和共模干扰的区别是什么？各应如何抑制？

**📚 前置知识：**
- 串模干扰：干扰与信号串联叠加
- 共模干扰：干扰同时出现在两信号线上
- CMRR 概念

**🔍 详细解答：**

| | 串模干扰 | 共模干扰 |
|------|:------:|:------:|
| 表现形式 | 两信号线间电压差 | 两信号线（相对地）同时出现、幅度相位相同 |
| 来源 | 长距离传输线拾取的电磁信号、信号源内部噪声 | 设备间地电位差、空间电磁场感应 |
| 抑制难度 | 较大 | 相对容易 |
| 抑制方法 | 屏蔽、滤波、信号处理 | 差分传输、高CMRR仪表放大器、隔离技术 |

**💡 易错点：** 共模干扰利用差分放大即可有效抑制，不要误将共模当串模处理。

### 习题5：简述接地技术中的数模地分离原则及屏蔽层接地规范。

**📚 前置知识：**
- 模拟地(AGND)和数字地(DGND)
- 单端接地 vs 多点接地
- 地环路干扰

**🔍 详细解答：**

**数模地分离原则：**
- 模拟地(AGND)和数字地(DGND)必须**分开独立走线**
- 最终在**电源端或 ADC 处**单点汇合
- 目的：防止数字电路的高频开关噪声通过地线耦合到模拟电路

**屏蔽层接地规范：**
- 屏蔽层应采用**单端接地**（通常在接收端）
- 避免**多点接地**形成地环路，引入额外噪声
- 屏蔽层外面要有绝缘层，防止与其他地线接触

**💡 易错点：** 屏蔽层多点接地会形成地环流干扰，这是常见错误做法。

## 第三部分：考点速记

### 核心公式汇总

| 公式 | 含义 |
|------|------|
| $P(n_1<n<n_2)=\int_{n_1}^{n_2} p(n)dn$ | 噪声区间概率 |
| $D[n]=\int (n-E[n])^2 p(n)dn = E[n^2]-E^2[n]$ | 噪声方差 |
| $R_{xx}(\tau)=\lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} x(t)x(t-\tau)dt$ | 自相关函数 |
| $R_{xy}(\tau)=\lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} x(t)y(t-\tau)dt$ | 互相关函数 |
| $E[n^2]=\lim\limits_{T\to\infty}\frac{1}{2T}\int_{-T}^{T} n^2(t)dt$ | 噪声均方值（平均功率） |

### 微弱信号检测方法对比

| 方法 | 核心技术 | 适用信号 | 信噪比提升 |
|------|----------|----------|:--------:|
| **自相关检测** | $R_{xx}$ 延时+乘法+积分 | 周期信号 | 随积分时间 |
| **互相关检测** | $R_{xy}$ + 同步参考信号 | 周期信号（需参考） | **更强** |
| **锁相放大器** | 调制+相敏检测+窄带LPF | 连续周期信号 | 可从1000倍噪声中检测 |
| **同步积累器** | 多周期同步累加 | 周期性窄脉冲 | 随积累次数 $m$ 提升 $\sqrt{m}$ 倍 |
| **同步积分器** | 双电容同步积分 | 方波信号 | 随积累次数 |
| **取样积分器** | 逐点采样+积分平均 | 周期脉冲信号 | 随扫描次数 |
| **数字多点平均器** | 多点数字化同步积累 | 周期信号 | 随平均次数 $m$ 提升 $\sqrt{m}$ 倍 |

### 常见易错点

1. ❌ 自相关检测优于互相关检测 → ✅ 互相关噪声抑制更强（无 $R_{nn}$ 残余），且保留相位信息
2. ❌ 锁相放大器使用直流放大 → ✅ 使用**调制+交流放大**，避开 1/f 噪声
3. ❌ 共模干扰和串模干扰一样难处理 → ✅ 共模干扰可由差分放大+高CMRR有效抑制
4. ❌ 屏蔽层两端都接地效果好 → ✅ 屏蔽层应**单端接地**，多点接地产生地环流
5. ❌ 模拟地和数字地可以共用 → ✅ 必须**分开走线**，仅在 ADC/电源端单点汇合
6. ❌ 白噪声的自相关函数在所有 $\tau$ 处都有值 → ✅ 白噪声自相关仅在 $\tau=0$ 处有峰值
7. ❌ 数字多点平均器信噪比提升与平均次数 m 成正比 → ✅ 信号幅度 $\propto m$，噪声幅度 $\propto \sqrt{m}$，信噪比提升 $\sqrt{m}$ 倍
8. ❌ 干扰三要素破坏任意一个即可 → ✅ 正确，核心思路就是破坏三要素中的至少一个
