## 场景概述

> **场景**：一条智能分拣流水线上，一台 6 自由度机械臂需要完成以下任务——
> 1. 接收远程控制指令
> 2. 用摄像头识别传送带上的物体类别
> 3. 精确抓取目标物体并放置到指定位置
> 4. 在运行过程中自我监测健康状态
>
> 这个看似简单的任务，从底层到上层贯穿了我们课程 Module 1-9 的几乎所有核心知识点。

## 阶段一：底层驱动与感知（Module 4 → 6 → 5）

> 机械臂要动起来，首先要解决三个最基础的问题：怎么驱动电机？怎么知道自己转了多远？怎么感知运动姿态？

### Step 1 — Module 4：PWM 脉冲宽度调制 → 电机驱动

**问题**：如何让电机按指令精确转动？

**知识点**：
- 脉冲调制有三种：PAM（调幅）、**PWM（调宽）**、PPM（调位）
- PWM 通过改变方波占空比 $D = t_{\text{on}} / T$ 调节等效电压
- 等效电压：$V_{\text{avg}} = D \cdot V_{cc}$

**在系统中的作用**：
- 机械臂 6 个关节各有一个直流伺服电机
- 微控制器输出 PWM 波 → 经 H 桥功率放大 → 驱动电机转动
- 占空比 $D$ = 0% → 停转；$D$ = 100% → 全速

> 🔗 **为什么用 PWM 而不是 PAM？** 课程讲过：噪声对脉冲边沿位置的影响远小于对幅度的影响 → PWM 比 PAM 更抗噪。

---

### Step 2 — Module 6：量化误差 → 编码器位置反馈

**问题**：电机转了，但怎么知道自己转了多少角度？

**知识点**：
- 量化：将连续幅度映射到有限个离散值
- 量化步长 $\Delta = \frac{V_{\max} - V_{\min}}{L}$
- 量化误差 $e_q \sim U(-\Delta/2, \Delta/2)$
- 量化噪声功率：$\sigma_e^2 = \Delta^2 / 12$

**在系统中的作用**：
- 关节处安装光电编码器（如 1024 线），将连续角度量化为脉冲
- $\Delta = 360°/1024 \approx 0.352°$，$\sigma_e^2 = 0.0103 \text{ deg}^2$
- 量化误差 → 经运动学 Jacobian 矩阵 $J$ 传播 → 末端定位误差：

$$\Sigma_{\text{末端}} = J \, \Sigma_{\theta} \, J^T$$

- **工程意义**：要达到 ±0.1mm 末端精度，可反推需要多少线编码器

---

### Step 3 — Module 5：奈奎斯特采样 → IMU 姿态数据采集

**问题**：除了知道关节角度，还需要感知机械臂整体的加速度和角速度，如何正确采集这些信号？

**知识点**：
- 采样：$x[n] = x(nT_s)$，采样频率 $f_s = 1/T_s$
- **奈奎斯特采样定理**：$f_s \geq 2f_{\max}$ 才能无失真重建
- 混叠原理：$f_s < 2f_{\max}$ 时高频分量折叠到低频
- 采样后频谱：$X_s(f) = \frac{1}{T_s}\sum_{k=-\infty}^{\infty} X(f - kf_s)$

**在系统中的作用**：
- IMU（惯性测量单元）以 $f_s = 200\text{Hz}$ 采样加速度和角速度
- 机械臂运动频率约 0-50Hz，满足 $200 > 2 \times 50 = 100$ ✓
- 采样前加模拟低通抗混叠滤波器（截止频率 $f_c = 100\text{Hz}$）
- 若忘记加抗混叠 → 高频振动（如电机 PWM 噪声 ≈ 20kHz）会混叠进低频段 → 姿态估计漂移

## 阶段二：系统建模与健康监测（Module 3 → 1）

> 有了驱动和感知，下一步是：建立电机的数学模型 + 实时监测系统健康状况。

### Step 4 — Module 3：冲激响应与卷积 → 电机系统辨识

**问题**：知道输入电压和输出转速，如何建立电机的精确数学模型？

**知识点**：
- 冲激响应 $h(t)$：输入 $\delta(t)$ 时的输出，**完全刻画**线性系统
- 卷积：$y(t) = x(t) * h(t) = \int x(\tau) h(t-\tau) d\tau$
- 频域关系：$Y(f) = X(f) \cdot H(f)$（时域卷积 = 频域乘法）
- **正弦保真性**：正弦波是通过线性系统后唯一波形不变的信号

**在系统中的作用**：
- **时域方法**：给电机一个短脉冲电压（近似 $\delta(t)$），测量转速响应 → 获得 $h(t)$
- **频域方法**：输入扫频正弦波，测量 $|H(f)|$ 和 $\angle H(f)$
- 获得 $H(f)$ 后 → 分析带宽（-3dB 点）→ 谐振点（需避开）→ 设计 PID 控制器

> 🔗 **为什么用正弦波测试？** 课程讲过"正弦保真性"——正弦波经过系统后只是幅度和相位变了，形状不变，所以可直接读出 $|H(f)|$。

---

### Step 5 — Module 1：傅里叶变换 → 关节振动频谱监测

**问题**：机械臂长时间运行，如何提前发现关节磨损/故障？

**知识点**：
- 傅里叶级数：$v(t) = \sum_{n=-\infty}^{\infty} c_n e^{jn\omega_0 t}$
- 傅里叶变换：$V(f) = \int_{-\infty}^{\infty} v(t) e^{-j2\pi ft} dt$
- **时域 ⇄ 频域完全等价**，不丢失任何信息
- Parseval 定理：$P = \sum |c_n|^2$（总功率 = 各谐波功率之和）

**在系统中的作用**：
- 在关节处安装加速度计 → 采集振动时域信号 $v(t)$
- FFT → 频域幅度谱 $|V(f)|$
- **正常状态**：能量集中在基频和低次谐波
- **齿轮磨损**：啮合频率 $f_{\text{mesh}}$ 处出现异常峰值
- **轴承故障**：特征频率处产生边带调制
- Parseval 定理量化振动能量 → 设定阈值 → 非拆卸式故障预警

> 🔗 这就是"给机器人做心电图"——从时域看不出来的故障特征，在频域一目了然。

## 阶段三：状态估计与决策（Module 2 → 7）

> 有了物理层的驱动和建模，现在进入信息层：如何融合多传感器数据估计当前状态？如何根据观测做决策？

### Step 6 — Module 2：贝叶斯公式 → 多传感器融合状态估计

**问题**：编码器、IMU、摄像头给出了不同的信息（有的噪声大、有的噪声小），如何融合这些信息得到最优的状态估计？

**知识点**：
- 贝叶斯公式：$P(B_i|A) = \frac{P(A|B_i) P(B_i)}{P(A)}$（由"果"推"因"）
- 全概率公式：$P(A) = \sum_i P(A|B_i)P(B_i)$
- 先验 → 似然 → 后验的更新逻辑

**在系统中的作用**：
- 机器人的状态（位置、速度、姿态）是"因"，传感器读数是"果"
- **贝叶斯框架**：

$$P(\text{状态} | \text{观测}) = \frac{P(\text{观测} | \text{状态}) \cdot P(\text{状态})}{P(\text{观测})}$$

$$\text{后验概率} \propto \text{似然} \times \text{先验}$$

- **预测步**（全概率公式）：$P(x_t | z_{1:t-1}) = \int P(x_t | x_{t-1}) \cdot P(x_{t-1} | z_{1:t-1}) dx_{t-1}$
- **更新步**（贝叶斯公式）：根据新传感器数据 $z_t$ 修正信念
- 实现为**卡尔曼滤波器**：融合 IMU（快但漂移）+ 编码器（准但慢）+ 视觉（偶尔更新）

### Step 7 — Module 7：贝叶斯决策理论 → 物体检测二分类

**问题**：摄像头看到传送带上有一个物体，需要判断"这是目标物体"还是"不是目标物体"，且**漏检的代价远大于虚警的代价**。

**知识点**：
- 二元假设检验：$H_0$（不是目标）vs $H_1$（是目标）
- 两类错误：虚警 $P(e|H_0)$ vs **漏检** $P(e|H_1)$
- MAP 准则：$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0)}{P(H_1)}$
- BER = $Q(\frac{\mu_1 - \mu_0}{2\sigma})$

**在系统中的作用**：
- 提取物体特征向量 $r$（颜色、形状、大小等）
- 建立两类条件概率：$P(r|H_0)$ 和 $P(r|H_1)$
- **代价敏感扩展**：

|  | 判为"不是目标" | 判为"是目标" |
|---|:---:|:---:|
| 实际不是目标 | $C_{00}=0$ | $C_{01}$（虚警：浪费一次抓取） |
| 实际是目标 | $C_{10}$（**漏检：放走目标！**） | $C_{11}=0$ |

- 碰撞代价 $C_{10} \gg C_{01}$ → 阈值向"宁可错抓不可放过"偏移

$$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0) \cdot C_{10}}{P(H_1) \cdot C_{01}}$$

## 阶段四：智能识别与可靠通信（Module 8 → 9）

> 从简单的二分类升级到多类别物体识别 + 保证远程指令传输万无一失。

### Step 8 — Module 8：交叉熵 / KL 散度 → 深度学习物体识别

**问题**：传送带上有多种物体（螺丝、螺母、垫圈、齿轮……），需要对每个物体进行**多类别识别**。

**知识点**：
- 香农信息量：$h(x) = -\log_2 p(x)$
- 熵：$H(X) = -\sum p(x) \log_2 p(x)$（$0 \leq H \leq \log_2 I$）
- 交叉熵：$H(P,Q) = -\sum_x p(x) \log q(x)$
- KL 散度：$D_{KL}(P\|Q) = \sum p(x) \log \frac{p(x)}{q(x)} = H(P,Q) - H(P)$
- Gibbs 不等式：$D_{KL}(P\|Q) \geq 0$，$P=Q$ 时取等号

**在系统中的作用**：
- 用 CNN（卷积神经网络）识别物体类别
- 网络输出 $\mathbf{q} = [q_1, q_2, \ldots, q_C]$（C 个类别的预测概率分布）
- 真实标签 $\mathbf{p}$ 是 one-hot 向量（如 $[1,0,0,0]$ 表示"螺丝"）
- **交叉熵损失函数**：

$$L = -\sum_{c=1}^{C} p_c \log q_c$$

- 训练时最小化 $L$ = 最小化 $D_{KL}(P\|Q)$ → 让预测分布逼近真实分布
- 部署到分拣系统 → 实时识别物体类别 → 传给机械臂执行分拣

> 🔗 **熵在这条链中的意义**：$H(X)$ 是物体类别的"固有不确定性"；交叉熵 $H(P,Q)$ 衡量"真实标签 vs 预测标签"的差异；$D_{KL}$ 就是差异的精确度量。

### Step 9 — Module 9：汉明码 → 远程控制指令的可靠传输

**问题**：分拣系统部署在嘈杂的工业环境中（或水下/太空等极端场景），无线信道误码率高，控制指令"抓取"如果被误传为"释放"后果不堪设想。

**知识点**：
- $(n,k)$ 线性分组码：$k$ 个信源比特 $\to$ $n$ 个传输比特（$n > k$）
- 汉明 $(7,4)$ 码：$d_{\min} = 3$，可纠 1 个比特错误
- 码率 $R = k/n = 4/7 \approx 57\%$
- 伴随式译码：$\mathbf{s} = \mathbf{r}H^T$，$\mathbf{s} \neq \mathbf{0}$ → 定位并纠正错误
- 信源编码定理：熵 $H(X)$ 是无损压缩的理论下界

**在系统中的作用**：
- 每 4 位控制命令（如"0011"=抓取，"0101"=释放）编码为 7 位汉明码字
- 接收端计算伴随式 $\mathbf{s}$：
  - $\mathbf{s} = [0,0,0]$ → 无误，执行指令
  - $\mathbf{s} = [1,0,1]$ → 第 5 位出错 → 翻转后执行
- **代价**：带宽效率降至 57%，但换取了单比特纠错能力
- 对安全性要求极高的场景（太空机械臂、手术机器人），这是"生命的保障"
