## 第一部分：知识梳理

### 第1章 传感器网络的体系结构

#### 1.1 无线传感器网络的概念

**⭐ 重点：WSN 定义**

**无线传感器网络（Wireless Sensor Networks, WSN）**是一种分布式传感网络，其末梢是可以感知和检查外部世界的传感器。WSN 中的传感器通过**无线方式**通信，形成的一个**多跳自组织网络**。

#### 1.2 WSN 的网络通信协议

无线传感器网络的协议体系结构由三部分组成：

| 组成部分 | 包含内容 |
|----------|----------|
| **分层的网络通信协议** | 物理层 → 数据链路层(MAC) → 网络层 → 传输层 → 应用层 |
| **应用支撑平台** | 时间同步、定位、传输控制、路由、拓扑控制、服务质量 |
| **网络管理平台** | 安全、移动、能量、网络管理接口 |

**⭐ 重点：WSN 协议栈五层结构**

| 层次 | 功能 | 对应技术 |
|------|------|----------|
| **物理层** | 信号传输 | 声、光、电、磁 |
| **数据链路层** | 介质访问控制 | MAC 协议 |
| **网络层** | 路由选择 | 路由协议 |
| **传输层** | 可靠传输 | 传输控制 |
| **应用层** | 用户应用 | 时间同步、定位等 |

> 对比传统 OSI 七层模型：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层。WSN 简化了会话层和表示层。

#### 1.3 传感器网络的组成

无线传感器网络系统由以下部分组成：
- **传感器节点**：感知数据并通过无线通信传输
- **汇聚节点（网关）**：收集并转发数据
- **管理节点**：对网络进行管理和控制
- **互联网/卫星通信**：远距离数据传输

#### 1.4 传感器网络的拓扑结构

**⭐ 重点：五种拓扑结构**

| 类型 | 特点 |
|------|------|
| **集中式** | 网关或路由做中心，星型结构 |
| **分布式** | 自组网，无中心节点 |
| **平面网络结构** | 所有节点地位平等，功能相同 |
| **分级网络结构** | 节点分簇，簇头负责数据汇聚转发 |
| **混合网络结构** | 平面 + 分级结合 |
| **Mesh 网络结构** | 多跳互联，任意节点间可通信，自愈性强 |

### 第2章 传感器网络的节点构成

#### 2.1 传感器节点结构

**⭐ 重点：五大组成部分**

| 组件 | 功能 | 说明 |
|------|------|------|
| **传感器** | 感受被测量并转换成可用信号 | 按物理量/工作原理/输出信号分类 |
| **外存储器** | 断电后仍能保存数据 | WSN 一般使用**闪存**（小尺寸、大存储能力） |
| **微控制器** | 核心计算和控制单元 | 单芯片微型计算机 |
| **收发器** | 无线信号的发送与接收 | 工作在 ISM 频段 |
| **能源** | 提供能量 | 电池 + 能量采集（Energy Harvest） |

#### 2.2 传感器的三种分类方式

| 分类依据 | 类型 |
|----------|------|
| 按物理量 | 位移、力、速度、加速度、温度、流量等 |
| 按工作原理 | 电阻、电容、电感、电压、霍尔、光电、光栅、热电偶等 |
| 按输出信号性质 | 开关型、模拟型、数字型（脉冲或代码） |

> 发展方向：**能量有限**是传感器节点的核心约束。

#### 2.3 微控制器的替代方案

**⭐ 重点：MCU vs DSP vs FPGA vs ASIC**

| 维度 | MCU（微控制器） | DSP | FPGA | ASIC |
|------|:----------:|:---:|:----:|:----:|
| 核心定位 | **通用控制** | 专用信号运算 | 可编程硬件 | 定制化专用芯片 |
| 处理方式 | 串行/分时复用 | 串行/流水线 | **真正并行** | 硬件固化并行 |
| 开发难度 | **极低**（C语言） | 中等（C/汇编） | 高（Verilog/VHDL） | 极高（全流程） |
| 灵活性 | 高（软件可改） | 高（软件可改） | **极高**（硬件可重配） | 无（流片后不可改） |
| 成本（量产） | **低** | 中 | 中高 | **极低**（大规模） |
| 功耗 | **低** | 中 | 中高 | **极低** |
| 适合场景 | 通用控制、低功耗 | 实时信号处理 | 高速并行、原型验证 | 大规模量产 |

#### 2.4 收发器与 ISM 频段

**⭐ 重点：ISM 频段**

| 频率范围 | 说明 |
|----------|------|
| 902~928 MHz | 北美 ISM 频段（LoRa、Zigbee 北美版） |
| **2.4~2.5 GHz** | **全球通用免授权频段，应用最广泛**（WiFi、蓝牙、Zigbee） |
| 5.725~5.875 GHz | 5GHz ISM 子频段，用于高速无线通信 |

#### 2.5 能源获取（Energy Harvest）

**⭐ 重点：六种能量来源**

| 能量类型 | 获取方式 |
|----------|----------|
| **热能** | 从温度梯度中获取（热电元件），如人体与环境温差 |
| **机械能** | 压电元件受力、磁铁移动、水波机械能转换 |
| **光能** | 光电效应/热电效应转换 |
| **声能** | 传声器/水听器转换 |
| **电磁（远场）** | 广播电台电磁场 → 直流电 |
| **磁（近场）** | 变压器和近距离可变磁场发射器 |

### 第3章 主流的传感器网络通信技术

#### 3.1 主流技术总览

**⭐ 重点：七种通信技术对比**

| 技术 | 通信距离 | 速率 | 功耗 | 核心优势 | 适合场景 |
|------|:------:|:---:|:---:|------|------|
| **NFC** | ≤10cm | 低 | 极低 | 安全、便捷 | 支付、门禁 |
| **蓝牙 BLE** | 10-100m | 中 | 低 | 手机直连、低功耗 | 可穿戴、智能家居 |
| **ZigBee** | 100m+（组网） | 低 | **极低** | 自组网、高可靠 | 工业传感器、智能家居 |
| **WiFi** | 100m | **高** | 中 | 高速、直连互联网 | 摄像头、智能家居 |
| **LoRa** | 1-20km | 低 | 极低 | 远距离、穿透性好 | 无线抄表、农业 |
| **CAT.1** | 广域（蜂窝） | 中 | 低 | 广覆盖、低成本 | 工业 DTU、智能电表 |
| **5G** | 广域（蜂窝） | **极高** | 中 | 低时延、大连接 | 工业互联网、自动驾驶 |
| **卫星互联网** | 全球 | 中 | 中 | 无死角覆盖 | 远洋、偏远地区 |
| **Matter** | 跨协议 | 依载体 | 依载体 | **互联互通** | 智能家居生态 |

#### 3.2 ZigBee 技术

**⭐ 重点：ZigBee 六大特点**

| 特点 | 说明 |
|------|------|
| **低功耗** | 2 节 5 号电池支持节点工作半年到两年 |
| **低成本** | 免协议专利费，芯片约 2 美元 |
| **短距离** | 10-100m（增加 RF 功率可达 1-3km） |
| **短时延** | 睡眠到工作 15ms，连入网络 30ms |
| **高容量** | 主节点管理 254 子节点，最大 65000 节点 |
| **高安全** | 三级安全模式，AES-128 加密算法 |

**频段与速率：**

| 频段 | 区域 | 最高速率 |
|------|------|:------:|
| 2.4GHz | 全球 | 250 kbit/s |
| 868MHz | 欧洲 | 20 kbit/s |
| 915MHz | 北美 | 40 kbit/s |

**协议栈（五层）：** 物理层(PHY) → 媒体访问控制层(MAC) → 传输层(DLL) → 网络层(NWK) → 应用层(APL)

- 物理层和 MAC 层遵循 **IEEE 802.15.4** 标准
- 网络层和应用层由 **ZigBee 联盟**制定

**应用领域：** 智能家居/楼宇自动化、自动抄表、道路照明、智慧医疗（实时监测血压、体温）、农业控制（土壤湿度、pH值）。

#### 3.3 WiFi 技术

**⭐ 重点：WiFi 各代标准**

| 标准 | 年份 | 别名 | 频率 | 最大速率 | 调制技术 |
|------|:---:|------|------|:------:|------|
| 802.11b | 1999 | — | 2.4GHz | 11Mbps | DSSS |
| 802.11a | 1999 | — | 5GHz | 54Mbps | OFDM |
| 802.11g | 2003 | — | 2.4GHz | 54Mbps | OFDM/DSSS |
| 802.11n | 2009 | **WiFi 4** | 2.4/5GHz | 1.2Gbps | MIMO-OFDM |
| 802.11ac | 2014 | **WiFi 5** | 5GHz | 3.5Gbps | MIMO-OFDM |
| 802.11ax | 2020 | **WiFi 6/6E** | 5/6GHz | 9.6Gbps | MIMO-OFDMA |
| 802.11be | 2022 | **WiFi 7** | 2.4/5/6GHz | **30Gbps** | MIMO-OFDMA |

**关键技术进步：**
- 802.11n（WiFi 4）：引入 **MIMO**（多输入多输出）
- 802.11ax（WiFi 6）：新增高密部署特性
- WiFi 6E：增加 **6GHz** 频段
- WiFi 7：支持 320MHz 频宽、4K QAM、增强 MU-MIMO

#### 3.4 蓝牙技术

**⭐ 重点：蓝牙版本演进**

| 版本 | 年份 | 核心特性 |
|------|:---:|------|
| 蓝牙 1.0 | 1999 | 首个正式版本，替代 RS232 |
| 蓝牙 2.0+EDR | 2004 | 速率提升至 2.1Mbps |
| 蓝牙 3.0+HS | 2009 | 借用 WiFi 技术，速率达 24Mbps |
| **蓝牙 4.0** | 2010 | 引入 **BLE**（低功耗蓝牙），功耗仅 0.01-0.5W |
| 蓝牙 4.2 | 2014 | 支持 **6LoWPAN**，易于接入互联网 |
| 蓝牙 5.0 | 2016 | 提升速率，支持室内辅助定位 |
| 蓝牙 Mesh | 2017 | 全面支持 **Mesh 网状网络** |

**蓝牙技术特点：**
- 短距离通信（一般 10m 内）
- 分散式网络结构 + **跳频技术**
- 工作频段：2.4GHz
- 数据传输速率：1Mbps
- 低功耗、便于集成、支持多连接、成本低、可传输语音和视频

#### 3.5 LoRa 技术

**⭐ 重点：LoRa 核心特征**

LoRa（Long Range）是由法国 Cycleo 公司 2009 年推出的长距离、低功耗无线通信技术，基于**扩频调制技术**，属于**非授权频谱**的 LPWAN。

| 特征 | 参数 |
|------|------|
| 城市传输距离 | 可达 8 km |
| 郊区传输距离 | 可达 25 km |
| 接收电流 | 10 mA |
| 休眠电流 | < 200 nA |
| 电池寿命 | 长达 **5 年** |
| 灵敏度 | **-148 dBm** |

**网络结构：** Mesh 拓扑，由终端（LoRa 模块）、网关、Server 和云四部分组成。网关负责数据汇总，通过 TCP/IP 与服务器连接。

**⭐ LPWAN 阵营划分：**

| 频谱类型 | 代表技术 |
|----------|------|
| **授权频谱** | NB-IoT（"一哥"） |
| **非授权频谱** | LoRa（"一马当先"） |

#### 3.6 NB-IoT 技术

**⭐ 重点：NB-IoT 核心特征**

NB-IoT（窄带物联网）由华为、中兴等牵头，2016 年通过 **3GPP 标准**。占用仅 **180KHz** 即可部署，属于**授权频谱** LPWAN。

| 特征 | 参数 |
|------|------|
| 覆盖增益 | 20dB（相比 GSM/LTE） |
| 单扇区连接数 | 约 **5 万**终端 |
| 电池寿命 | 理论持续 **10 年** |
| 模组成本 | 5 美元以内 |

**三种部署方式：**
1. **带内部署**（In-band）：适用于 LTE 频段
2. **保护带部署**（Guard band）：适用于 LTE 频段
3. **独立部署**（Stand alone）：适用于重耕 GSM 频段

**系统架构：** 终端(UE) → 无线网侧(基站) → 核心网(EPC) → IoT 平台 → 应用服务器

#### 3.7 Z-Wave 技术

Z-Wave 是丹麦 Zen-Sys 公司推出的低成本、低功耗、短距离无线通信技术。

| 参数 | 数值 |
|------|------|
| 工作频段 | 868.42MHz（欧洲/中国），908.42MHz（美国） |
| 调制方式 | FSK(BFSK/GFSK) |
| 数据传输速率 | 9.6 Kbps |
| 室内覆盖 | 30m |
| 室外覆盖 | >100m |

**Z-Wave vs ZigBee 对比：**

| 对比项 | Z-Wave | ZigBee |
|--------|:-----:|:-----:|
| 覆盖范围（室内） | 30m | 10-100m |
| 唤醒时间 | 5s | 15s |
| 接收灵敏度 | -98dBm | -94dBm |
| 成本 | **1 美元** | 2 美元 |

**优点：** 双向传输、自我诊断修复、动态分配路由、868MHz 避免与 WiFi/蓝牙冲突、穿透能力强于 2.4GHz。

#### 3.8 主流技术横向对比总结

| 组网方式 | 技术 | 距离 | 频段 | 速率 | 领域 |
|----------|------|:---:|------|:---:|------|
| 基于无线路由器 | WiFi | 100m内 | 2.4/5/6GHz | 30Gbps | 室内外 |
| 基于 LoRa 网关 | LoRa | 1-20km | Sub-GHz | 0.3-50Kbps | 户外/蜂窝覆盖不到 |
| 节点+网关 | ZigBee | 10-100m | 2.4GHz | <250kbps | 小范围传感器 |
| 基于蜂窝 | NB-IoT | 数十公里 | 运营商频段 | <250kbps | 大面积传感器 |
| 蓝牙 Mesh | Bluetooth | 10m | 2.4GHz | 1Mbps | 室内外 |

### 第4章 传感器网络的关键技术

**⭐ 重点：六大关键技术**

| 关键技术 | 说明 |
|----------|------|
| **时间同步** | 分布式系统无全局时钟，需使各节点对时间的认知达到一致，是网络协议运行的基础 |
| **感知精度** | 观察者接收到的感知信息精度，受传感器精度、信息处理方法和通信协议影响 |
| **能源有效性** | 节点能量是效能瓶颈，需设计休眠机制降低能耗 + 能量挖掘技术补充能量 |
| **可扩展性** | 表现在传感器数量、覆盖区域、生命周期、时间同步、自组织管理等方面的可扩展极限 |
| **自组织管理** | 自动组网运行、自行配置维护、适时转发数据；包括节点管理、资源任务管理、数据管理等 |
| **容错性** | 节点失效/链路故障/数据丢失不可避免，需提高软硬件容错能力保证鲁棒性 |
| **安全性** | 信号干扰/非法窃听/恶意路由等威胁，需建立更高更强的安全机制 |

### 习题1：简述无线传感器网络（WSN）的定义及其协议栈的五层结构。

**📚 前置知识：**
- WSN 的概念：分布式传感网络，无线多跳自组织
- OSI 七层模型

**🔍 详细解答：**

**定义：** WSN 是一种分布式传感网络，末梢是可感知外部世界的传感器，通过**无线方式**通信，形成**多跳自组织网络**。

**五层协议栈：**

| 层次 | 功能 |
|------|------|
| **物理层** | 信号传输（声、光、电、磁） |
| **数据链路层（MAC）** | 介质访问控制 |
| **网络层** | 路由选择 |
| **传输层** | 可靠传输控制 |
| **应用层** | 时间同步、定位等应用服务 |

> 对比 OSI 七层模型（物理/数据链路/网络/传输/**会话/表示**/应用），WSN 简化了会话层和表示层。

### 习题3：对比 ZigBee 和 WiFi 的技术特点与适用场景。

**📚 前置知识：**
- ZigBee：IEEE 802.15.4，低功耗、低速率
- WiFi：IEEE 802.11 系列，高速率

**🔍 详细解答：**

| 对比维度 | ZigBee | WiFi |
|----------|:------:|:----:|
| 标准 | IEEE 802.15.4 | IEEE 802.11 |
| 功耗 | **极低**（电池工作半年~2年） | 中（数小时） |
| 速率 | <250kbps | 最高 30Gbps（WiFi 7） |
| 距离 | 10-100m | ~100m |
| 成本 | 芯片约 2 美元 | 较高 |
| 组网 | 星型/片型/网状，65000 节点 | 基于路由器 |

### 习题4：对比 NB-IoT 和 LoRa 的技术特点。

**📚 前置知识：**
- NB-IoT：授权频谱 LPWAN
- LoRa：非授权频谱 LPWAN
- LPWAN 定义：低功耗广域网络

**🔍 详细解答：**

| 对比维度 | NB-IoT | LoRa |
|----------|:------:|:----:|
| 频谱 | **授权频谱**（运营商频段） | **非授权频谱**（ISM 频段） |
| 标准 | 3GPP（2016） | Cycleo（2009） |
| 部署方式 | 基于现有蜂窝网络 | 自建网关 |
| 覆盖 | 20dB 增益，10 倍于传统蜂窝 | 城市 8km，郊区 25km |
| 连接数 | 单扇区约 5 万 | — |
| 电池寿命 | 理论 10 年 | 长达 5 年 |
| 模组成本 | <5 美元 | 极低 |

> **核心区别：** NB-IoT 需要运营商网络支持（授权频段），LoRa 可自建网络（非授权频段）。

### 常见易错点

1. ❌ ZigBee 速率高 → ✅ ZigBee 是**低速率**（<250kbps），WiFi 才是高速率
2. ❌ LoRa 是授权频谱技术 → ✅ LoRa 是**非授权频谱**，NB-IoT 是授权频谱
3. ❌ WiFi 6 就是最新标准 → ✅ WiFi 7（802.11be）已于 2022 年发布
4. ❌ 蓝牙 4.0 = BLE 是同一件事 → ✅ 蓝牙 4.0 包含传统蓝牙 + **BLE** + 高速蓝牙三种协议
5. ❌ WSN 协议栈就是 OSI 七层 → ✅ WSN 协议栈为**五层**，简化了会话层和表示层
6. ❌ NB-IoT 可自建网关部署 → ✅ NB-IoT 必须基于**运营商蜂窝网络**，LoRa 才可自建网关
7. ❌ ZigBee 是 WiFi 的一种 → ✅ ZigBee 基于 **IEEE 802.15.4**（WPAN），WiFi 基于 IEEE 802.11（WLAN）
8. ❌ MCU 成本高于 ASIC → ✅ **ASIC 大规模量产时成本最低**，MCU 开发成本低但量产成本不是最低
