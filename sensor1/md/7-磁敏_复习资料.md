## 第一部分：知识梳理

### 第1章 磁敏传感器概述

磁敏传感器是基于**磁电转换原理**的传感器。虽然霍尔效应和磁阻效应在 19 世纪已被发现，但实用的磁敏传感器产生于半导体材料发现之后。

**发展历程：**
- 1960 年代初：西门子公司研制第一个实用磁敏元件
- 1966 年：铁磁性薄膜磁阻元件问世
- 1968/1971 年：索尼研制锗、硅磁敏二极管
- 1974 年：韦冈德发明双稳态磁性元件

### 第2章 霍尔元件

#### 2.1 霍尔效应

**⭐ 重点：霍尔效应原理**

在与磁场垂直的半导体薄片上通以电流 $I$，载流子（电子）受到**洛仑兹力**作用向一侧偏转，使该侧形成电子积累，另一侧形成正电荷积累，在横向形成**霍尔电场** $E_H$。当电子所受电场力 $f_E$ 与洛仑兹力 $f_L$ 相等时，达到动态平衡，此时建立的电场称为霍尔电场，相应的电势称为**霍尔电势** $U_H$。

**推导过程：**

电子受到的洛仑兹力：
$$f_L = -evB$$

霍尔电场作用于电子的力：
$$f_E = (-e)(-E_H) = e\frac{U_H}{b}$$

达到动态平衡时 $f_L + f_E = 0$：
$$vB = \frac{U_H}{b}$$

电流强度 $I = -nevbd$，代入得：
$$U_H = -\frac{IB}{ned}$$

对 P 型半导体：
$$U_H = \frac{IB}{ped}$$

> 根据霍尔电势的**正负**可以判别材料的类型。

#### 2.2 霍尔系数和灵敏度

**⭐ 重点：霍尔系数与灵敏度公式**

**霍尔系数**（反映霍尔效应强弱）：
$$R_H = \frac{1}{ne}$$
$$U_H = -R_H\frac{IB}{d}$$

由电阻率公式 $\rho = 1/ne\mu$，得：
$$R_H = \rho\mu$$

其中 $\mu$ 为载流子迁移率。电子迁移率大于空穴迁移率，故霍尔元件多采用 **N 型半导体**材料。

**灵敏度**（单位磁感应强度和单位控制电流下的霍尔电势）：
$$K_H = -\frac{R_H}{d} = -\frac{1}{ned}$$
$$U_H = K_H I B$$

单位：$\text{mV}/(\text{mA}\cdot\text{T})$。

**关键结论：**
| 要点 | 说明 |
|------|------|
| 金属不宜制作霍尔元件 | 电子浓度太高，霍尔系数/灵敏度太小 |
| 厚度 $d$ 越小灵敏度越高 | 但不能太小（会导致输入输出电阻增加） |
| 控制电流反向 | 输出电势方向随之变化 |
| 磁场方向反向 | 输出电势方向随之变化 |
| 电流和磁场**同时反向** | 霍尔电势方向**不变** |

#### 2.3 磁场有角度时

当磁感应强度 $B$ 与霍尔片法线 $n$ 成角度 $\theta$ 时：

$$U_H = K_H I B \cos\theta$$

> 有效磁场是法线方向的分量 $B\cos\theta$。

#### 2.4 基本测量电路

控制电流由电源 $E$ 供给，$R$ 为调整电阻，霍尔输出端接负载 $R_L$（可为电阻、放大器输入电阻或表头内阻）。

#### 2.5 电磁特性

**⭐ 重点：两条特性曲线**

**(1) $U_H$-$I$ 特性（磁场恒定）**

$U_H$ 与 $I$ 呈**线性关系**。直线斜率称为**控制电流灵敏度**：
$$K_I = \left(\frac{U_H}{I}\right)_{B=\text{const}} = K_H \cdot B$$

- 灵敏度 $K_H$ 大的元件，控制电流灵敏度一般也大
- 霍尔电势建立时间极短（约 $10^{-12}$s），控制电流可用高频交流（几千兆赫兹）
- 噪声系数较小（如锑化铟约 7.66dB）

**(2) $U_H$-$B$ 特性（控制电流恒定）**

开路霍尔输出随磁场增加**不完全线性**：
- 锑化铟的线性度**不如**锗
- 锗沿 (100) 晶面切割的线性度优于 (111) 晶面

### 第3章 霍尔元件误差分析及补偿

#### 3.1 元件几何尺寸及电极焊点的影响

实际霍尔片长宽比 $L/b$ 有限，存在霍尔电场被控制电流极**短路**的影响：

$$U_H = K_H I B \cdot f_H(L/b)$$

其中 $f_H(L/b)$ 为**形状系数**。

霍尔电极有一定宽度 $l$，对灵敏度和线性度有影响。理想要求：控制电流电极**面接触**，霍尔电极**点接触**。

#### 3.2 不等位电势 $U_0$ 及其补偿

**⭐ 重点：不等位电势是零位误差的主要因素**

制作时无法保证霍尔电极焊在同一等位面上。即使 $B=0$，控制电流 $I$ 流过时，霍尔电势极上仍有电势存在，称为**不等位电势 $U_0$**。

**等效电桥模型**：四个桥臂电阻 $r_1$、$r_2$、$r_3$、$r_4$。若两电极在同一等位面：$r_1=r_2=r_3=r_4$，电桥平衡 $U_0=0$；不在同一等位面时电桥失衡。

> 一般采用**补偿网络**进行补偿。

#### 3.3 寄生直流电势

由于电极不能做到完全欧姆接触，出现**整流效应**。不加磁场通入交流控制电流时，输出除交流不等位电势外还有**直流分量**。其大小与工作电流有关——电流减小，直流电势迅速减小。

#### 3.4 感应电势

霍尔元件在交变磁场中工作时，即使不加控制电流，引线布局不合理也会产生附加感应电势。其大小正比于：
- 磁场变化频率
- 磁感应强度幅值
- 霍尔电势极引线构成的感应面积

**补偿方法：** 合理布线 + 在磁路气隙中安置辅助霍尔元件（自身补偿法）。

#### 3.5 温度误差及其补偿

**⭐ 重点**

霍尔元件对温度变化十分敏感（半导体材料的电阻率、迁移率和载流子浓度均随温度变化）。

**补偿方法：** 在控制电流极并联补偿电阻 $r_0$。温度升高时元件内阻增大 → 通过元件电流减小 → 通过 $r_0$ 电流增加 → 利用内阻温度特性和补偿电阻**自动调节**电流大小。

### 第4章 霍尔传感器应用

**⭐ 重点：霍尔元件的三类用途**

| 条件 | 输出关系 | 应用 |
|------|----------|------|
| 控制电流 $I$ 恒定 | $U_H \propto B$ | 测量恒定/交变磁场（高斯计等） |
| 磁感应强度 $B$ 恒定 | $U_H \propto I$ | 测量交/直流电流表、电压表 |
| $I$ 和 $B$ 均变化 | $U_H \propto I \cdot B$ | 乘法器、功率计 |

**(1) 转速测量：** 旋转体上粘贴永磁体，霍尔元件置于永磁体附近。旋转时每个永磁体通过产生一个脉冲 → 计数脉冲 → 计算转速。

**(2) 压力/压差测量：** 弹性元件感受压力转换为位移 → 带动霍尔元件在均匀梯度磁场中移动 → 霍尔电势变化 → 完成压力到电量的转换。

### 第5章 磁敏电阻

#### 5.1 磁阻效应

**⭐ 重点：磁阻效应定义**

载流导体置于外磁场中，除产生霍尔效应外，电阻也随磁场变化。原因是载流子受洛仑兹力偏转 → 散射概率增大 → 迁移率下降 → 电阻增加。**磁阻效应是伴随霍尔效应同时发生的物理效应。**

**弱磁场范围（温度恒定）：**

$$\rho_B = \rho_0(1 + 0.273\mu^2 B^2)$$

电阻率相对变化：
$$\frac{\Delta\rho}{\rho_0} = 0.273\mu^2 B^2 = k(\mu B)^2$$

> 磁场一定时，**迁移率越高**的材料磁阻效应越明显。

#### 5.2 磁敏电阻结构与原理

常用锑化铟（InSb）薄片制成：

| 状态 | 载流子路径 | 电阻 |
|------|------------|:----:|
| 未加磁场 | 从 a 端直接流向 b 端 | 较小 |
| 加垂直磁场 | 受洛仑兹力偏转，路径变长 | **增大** |

**提高灵敏度方法：**

**(1) 栅状结构** — 在 InSb 薄片上光刻栅状铟短路条，等效多个 $W/l$ 值大的电阻串联 → 提高零磁场电阻率 + 灵敏度。

**(2) 科比诺（Corbino）圆盘** — 中心和边缘各有一个电极，圆盘形磁阻最大，大多数磁阻元件做成此结构。

### 第6章 磁敏二极管和磁敏三极管

**概述：** 在霍尔元件和磁敏电阻之后发展起来的新型磁电转换元件。特点：磁灵敏度高（比霍尔元件高**数百甚至数千倍**）、能识别磁场极性、体积小、电路简单。

#### 6.1 磁敏二极管

**结构：** P$^+$-I-N$^+$ 型。在高纯度锗两端制成 P 区和 N 区，I 区一侧设高复合 **r 区**，另一侧保持光滑无复合表面。

**⭐ 重点：工作原理**

| 磁场情况 | 载流子运动 | I 区载流子密度 | 电流 | 电阻 |
|----------|------------|:------------:|:----:|:----:|
| **无磁场** | 大部分空穴经 I 区进入 N 区，大部分电子经 I 区进入 P 区 | 正常 | 正常 | 正常 |
| **H$^+$（正向磁场）** | 电子和空穴向 r 区偏移 → 快速复合 | 减小 | **减小** | **增加** |
| **H$^-$（反向磁场）** | 载流子向 r 区对面偏移 → 停留变长、复合减少 | 增加 | **增大** | **减小** |

> r 区和其他部分复合能力之差越大，灵敏度越高。磁敏二极管**反向偏置**时仅流过微小电流，几乎与磁场无关。

#### 6.2 磁敏三极管

**结构：** NPN 型，在弱 P 型近本征半导体上形成发射结、基极结、集电结三个结。长基区侧面制有高复合 r 区，分为输运基区和复合基区。

**⭐ 重点：工作原理**

基区宽度大于载流子有效扩散长度 → 电流放大系数 $\beta = I_c/I_b < 1$。

| 磁场情况 | 载流子偏转方向 | 集电极电流 $I_c$ |
|----------|---------------|:-------------:|
| 无磁场 | — | 正常（小于 $I_b$） |
| **H$^+$** | 向发射结一侧偏转 | **明显下降** |
| **H$^-$** | 向集电结一侧偏转 | **增大** |

#### 6.3 应用

磁敏管适合检测**微弱磁场**变化（约 0.1T），如：
- **漏磁探伤仪**：钢棒被磁化后，缺陷处产生泄漏磁通 → 磁敏管探头检测 → 根据信号有无判定缺陷
- 地磁探测仪

## 第二部分：习题精讲

### 习题1：推导霍尔电势 $U_H$ 的表达式，并说明影响霍尔电势大小的因素。

**📚 前置知识：**
- 洛仑兹力公式：$f_L = -evB$
- 电场力公式：$f_E = eE$
- 电流微观表达式：$I = -nevbd$
- 动态平衡条件

**🔍 详细解答：**

**第一步：** 电子受洛仑兹力 $f_L = -evB$ 向一侧偏转。

**第二步：** 形成霍尔电场 $E_H$，电子受电场力 $f_E = e\frac{U_H}{b}$。

**第三步：** 动态平衡时 $f_L + f_E = 0$，得 $vB = \frac{U_H}{b}$。

**第四步：** 由 $I = -nevbd$，得 $v = -\frac{I}{nebd}$，代入得：

$$U_H = -\frac{IB}{ned} = R_H\frac{IB}{d} = K_H I B$$

**影响因素：**
- 控制电流 $I$：$U_H \propto I$
- 磁感应强度 $B$：$U_H \propto B$
- 元件厚度 $d$：$d$ 越小 $U_H$ 越大
- 载流子浓度 $n$：$n$ 越小 $U_H$ 越大（金属 $n$ 太高不适用）
- 磁场与法线夹角 $\theta$：$U_H = K_H I B \cos\theta$

**💡 易错点：** $d$ 越小灵敏度越高，但 $d$ 不能无限减小（会导致输入输出电阻过大）。

### 习题2：简述不等位电势产生的原因及补偿方法。

**📚 前置知识：**
- 理想霍尔元件结构：霍尔电极在同一等位面上
- 等效电桥模型

**🔍 详细解答：**

**产生原因：** 制作霍尔元件时无法保证将两个霍尔电极焊在**同一等位面**上。当控制电流 $I$ 流过元件时，即使 $B=0$，霍尔电势极上仍有电势存在。

**等效电桥分析：** 四个桥臂电阻 $r_1\sim r_4$，电极在同一等位面时 $r_1=r_2=r_3=r_4$，电桥平衡 $U_0=0$；不在同一等位面时（如 $r_3$ 增大 $r_4$ 减小）电桥失衡，$U_0 \neq 0$。

**补偿方法：** 采用**补偿网络**（电阻网络）进行补偿，调节补偿电阻使不等位电势归零。

**💡 易错点：** 不等位电势是**零位误差**的主要因素，产生在 $B=0$ 时，与被测量无关。

### 习题3：磁阻效应的物理机制是什么？写出弱磁场下的磁阻效应表达式。

**📚 前置知识：**
- 载流子散射与迁移率的关系
- 洛仑兹力对载流子运动路径的影响

**🔍 详细解答：**

**物理机制：** 运动的载流子在磁场中受到洛仑兹力作用发生偏转 → 载流子散射概率增大 → 迁移率 $\mu$ 下降 → 电阻增加。磁阻效应是**伴随霍尔效应同时发生**的物理效应。

**弱磁场表达式（温度恒定）：**

$$\rho_B = \rho_0(1 + 0.273\mu^2 B^2)$$

电阻率相对变化：
$$\frac{\Delta\rho}{\rho_0} = 0.273\mu^2 B^2 = k(\mu B)^2$$

- 磁场一定时，迁移率 $\mu$ 越高的材料，磁阻效应越明显
- 常用材料：锑化铟（InSb）

### 习题4：比较磁敏二极管在无磁场、H$^+$ 磁场、H$^-$ 磁场三种情况下的工作状态。

**📚 前置知识：**
- 磁敏二极管 P$^+$-I-N$^+$ 结构
- r 区（高复合区）的作用
- 洛仑兹力对载流子偏转方向的影响

**🔍 详细解答：**

| 状态 | 载流子偏转 | 复合情况 | I 区载流子密度 | 电流 | 电阻 |
|:----:|------------|----------|:------------:|:----:|:----:|
| 无磁场 | 无偏转 | 正常 | 正常 | 正常 | 正常 |
| **H$^+$** | 向 r 区偏移 | 快速复合 | **减小** | **减小** | **增大** |
| **H$^-$** | 向 r 区对面偏移 | 复合减少 | **增加** | **增大** | **减小** |

**正反馈机制：**
- H$^+$：电流减小 → 结电压减小 → 载流子注入减少 → I 区电阻进一步增加
- H$^-$：电流增大 → 结电压增加 → 载流子注入增加 → I 区电阻进一步减小

> r 区与其他区域复合能力之差越大，磁敏二极管灵敏度越高。

**💡 易错点：** 磁敏二极管**反向偏置**时仅流过微小电流，几乎与磁场无关。

### 习题5：磁敏三极管中为什么 $\beta = I_c/I_b < 1$？

**📚 前置知识：**
- NPN 型磁敏三极管结构（发射结、基极结、集电结）
- 基区宽度与载流子扩散长度的关系

**🔍 详细解答：**

磁敏三极管的**基区宽度大于载流子有效扩散长度**，因此注入载流子除少部分输运到集电极 c 外，大部分通过 e→i→b 形成基极电流。这导致**基极电流大于集电极电流**，所以电流放大系数 $\beta = I_c/I_b < 1$。

这与普通三极管 $\beta \gg 1$ 完全不同，是磁敏三极管的特殊结构决定的。

| 磁场方向 | 集电极电流变化 |
|:--------:|:------------:|
| H$^+$ | 载流子向发射结偏转 → $I_c$ **明显下降** |
| H$^-$ | 载流子向集电结偏转 → $I_c$ **增大** |

### 核心公式汇总

| 公式 | 含义 |
|------|------|
| $f_L = -evB$ | 洛仑兹力 |

| $U_H = \dfrac{IB}{ped}$ | 霍尔电势（P 型） |

| $R_H = 1/ne = \rho\mu$ | 霍尔系数 |

| $\rho_B = \rho_0(1 + 0.273\mu^2 B^2)$ | 磁阻效应（弱磁场） |
| $\Delta\rho/\rho_0 = 0.273\mu^2 B^2$ | 电阻率相对变化 |
| $K_I = K_H \cdot B$ | 控制电流灵敏度 |

| 参数 | 说明 |
|------|------|
| 灵敏度单位 | $\text{mV}/(\text{mA}\cdot\text{T})$ |
| 霍尔电势建立时间 | 约 $10^{-12}$s |
| 适用频率 | 可达几千兆赫兹 |
| 材料类型 | N 型半导体（电子迁移率 > 空穴迁移率） |
| 金属不适用原因 | 电子浓度太高，灵敏度太小 |

### 五种误差及补偿方法

| 误差类型 | 产生原因 | 补偿方法 |
|----------|----------|----------|
| 不等位电势 | 霍尔电极不在同一等位面 | 补偿网络 |
| 寄生直流电势 | 电极非欧姆接触，整流效应 | 减小工作电流 |

### 四种磁敏元件对比

| 元件 | 基础效应 | 灵敏度 | 特点 |
|------|----------|:----:|------|
| **霍尔元件** | 霍尔效应 | 中等 | 输出 $\propto I \cdot B$，应用最广 |
| **磁敏电阻** | 磁阻效应 | 中等 | 电阻随磁场变化，需高迁移率材料 |
| **磁敏二极管** | 霍尔效应 + 复合效应 | **高**（数百-数千倍） | P$^+$-I-N$^+$ 结构 + r 区，能辨极性 |
| **磁敏三极管** | 霍尔效应 + 复合效应 | **高** | $\beta<1$，$I_c$ 随磁场方向变化 |

### 常见易错点

1. ❌ 金属可制作霍尔元件 → ✅ 金属电子浓度太高，灵敏度太小，不适用
2. ❌ $d$ 越小越好，可无限减小 → ✅ $d$ 过小会导致输入输出电阻过大
3. ❌ 电流和磁场同时反向时霍尔电势也反向 → ✅ 同时反向时霍尔电势方向**不变**
4. ❌ 霍尔电势与磁场始终线性 → ✅ $U_H$-$B$ 特性**不完全线性**（锑化铟线性度不如锗）
5. ❌ 不等位电势由磁场引起 → ✅ 不等位电势产生于**$B=0$** 时，是零位误差
6. ❌ 磁敏三极管 $\beta > 1$ 像普通三极管 → ✅ 基区宽度大于扩散长度，$\beta < 1$
7. ❌ 磁敏二极管反向偏置也能测磁场 → ✅ 反向偏置时仅流过微小电流，**几乎与磁场无关**
8. ❌ 磁阻效应和霍尔效应互不相关 → ✅ 磁阻效应是**伴随霍尔效应同时发生**的
