## 第一部分：知识梳理

### 第1章 压电式传感器概述

#### 1.1 基本概念

压电传感器是典型的**有源传感器**，又称**自发电式传感器**或**电势式传感器**。

- **工作原理**：基于某些晶体受力后在其表面产生电荷的**压电效应**。以某些电介质的压电效应为基础，在外力作用下，在电介质的表面上产生电荷，从而实现非电量测量。
- **敏感元件**：压电传感元件是**力敏感元件**，能测量最终能变换为力的物理量，如力、压力、加速度等。

**⭐ 重点：压电传感器的核心特征**
| 项目 | 说明 |
|------|------|
| 类型 | 有源传感器（自发电式） |
| 基础效应 | 压电效应 |
| 敏感量 | 力（可间接测量压力、加速度等） |
| 适用场景 | 动态力学测量 |
| 不适用场景 | 静态量测量 |

#### 1.2 压电传感器的特点

- 体积小、重量轻、结构简单、灵敏度高、工作可靠
- **适合动态力学测量，不能测量静态量**
- 压电传感器是一个**机电转换元件**

#### 1.3 典型应用

拾音器、压电引信、燃气点火具等。

### 第2章 压电效应

#### 2.1 压电效应概念

**⭐ 重点：正压电效应与逆压电效应**

| 类型 | 定义 | 能量转换 |
|------|------|----------|
| **正压电效应** | 晶体沿一定方向受外力作用时，内部产生极化现象，在某两个表面产生符号相反的电荷；外力去掉后恢复不带电状态；作用力方向改变时，电荷极性也改变 | 机械能 → 电能 |
| **逆压电效应** | 在电介质极化方向施加电场时，电介质在一定方向产生机械变形或机械压力，外加电场撤去时变形或应力随之消失（又称**电致伸缩效应**） | 电能 → 机械能 |

> **核心结论：** 压电效应具有**可逆性**，可实现机械能与电能的相互转换。晶体结构材料受作用力产生的电荷量与该外力的大小**成正比**。

#### 2.2 石英晶体的压电效应

石英晶体是一个正六面体，用三根互相垂直的轴表示：

| 轴名称 | 符号 | 说明 |
|--------|------|------|
| **光轴** | Z—Z | 纵向轴 |
| **电轴** | X—X | 经过正六面体棱线，垂直于光轴 |
| **机械轴** | Y—Y | 与X轴和Z轴同时垂直（垂直于正六面体的棱面） |

**⭐ 重点：纵向压电效应与横向压电效应**

##### （1）纵向压电效应

沿**电轴（X—X方向）**受力时产生电荷的压电效应。

$$q_x = d_{11}F_x$$

- 当 $F_x = 0$ 时：正负电荷中心重合，电偶极矩矢量和等于零：$\vec{P}_1 + \vec{P}_2 + \vec{P}_3 = 0$
- 当 $F_x < 0$（受压）时：X轴正向出现**正电荷**，Y、Z轴方向不出现电荷
- 当 $F_x > 0$（受拉）时：X轴正向出现**负电荷**，Y、Z轴方向不出现电荷

##### （2）横向压电效应

沿**机械轴（Y—Y方向）**受力时产生电荷的压电效应。

$$q_y = d_{12}\frac{a}{b}F_y$$

- 电荷分布与X方向受力情况**相反**
- 当 $F_y < 0$（受压）：X正半轴产生**负电荷**，X负半轴产生**正电荷**
- 当 $F_y > 0$（受拉）：电荷分布如同X方向受压时

> **重要结论：** 沿光轴（Z—Z方向）受力**不产生**压电效应。

#### 2.3 晶体切片分析

从石英晶体上切下一片平行六面体——晶体切片，使晶面分别平行于X、Y、Z轴。

**沿X轴方向受力时：**

极化强度与应力成正比：

$$P_{xx} = d_{11}\sigma_{xx} = d_{11}\frac{F_x}{lb}$$

极化强度在数值上等于晶面上的电荷密度：

$$q_x = d_{11}F_x$$

极间电压：

$$U_x = \frac{q_x}{C_x} = \frac{d_{11}F_x}{C_x}$$

其中 $C_x$ 为电极面间电容（F）。

**沿Y轴方向受力时：**

$$q_y = d_{12}\frac{a}{b}F_y = -d_{11}\frac{a}{b}F_y$$

根据石英晶体轴对称条件：$d_{11} = -d_{12}$

极间电压：

$$U_y = \frac{q_y}{C_y}$$

**逆压电效应：**

晶体在X轴方向伸缩：$\Delta t = d_{11}U_x$

**⭐ 重点总结：**
1. 无论正或逆压电效应，作用力（或应变）与电荷（或电场强度）之间呈**线性关系**
2. 晶体在哪个方向上有正压电效应，则在此方向上**一定存在**逆压电效应
3. 石英晶体**不是在任何方向**都存在压电效应

### 第3章 压电材料

#### 3.1 压电材料概述

具有压电效应的材料称为**压电材料**，能实现机—电能量的相互转换。

自然界大多数晶体具有压电效应，但十分微弱。性能优良的压电材料包括：**石英晶体、钛酸钡、锆钛酸铅（PZT）**。

**⭐ 重点：压电材料的五项要求**
| 要求 | 说明 |
|------|------|
| ① 转换性能 | 具有较大压电常数 |
| ② 机械性能 | 机械强度高、刚度大，获得宽线性范围和高固有振动频率 |
| ③ 电性能 | 高电阻率和大介电常数，减弱分布电容影响，获得良好低频特性 |
| ④ 环境适应性 | 温度和湿度稳定性好，居里点高，工作温度范围宽 |
| ⑤ 时间稳定性 | 压电性能不随时间变化 |

#### 3.2 压电材料的分类

压电材料分为两大类：**压电晶体**和**压电陶瓷**。

**⭐ 重点：压电晶体 vs 压电陶瓷对比**

| 对比维度 | 压电晶体（石英） | 压电陶瓷（PZT/钛酸钡） |
|----------|:------------:|:------------------:|
| 来源 | 天然/人工晶体 | 人工制造多晶材料 |
| 压电系数 | 低（$d_{11}=2.3 \times 10^{-12}$ C/N） | 高（钛酸钡是石英的50倍） |
| 居里温度点 | 高 | 钛酸钡115°C，PZT 300°C |
| 机械强度 | 高 | 不如石英 |
| 绝缘性能 | 好 | 较好 |
| 价格 | 较贵 | 较低 |
| 适用场景 | 标准传感器/高精度传感器 | 通用传感器 |

#### 3.3 压电陶瓷的极化处理

- 压电陶瓷由无数细微单晶组成，内部晶粒有许多自发极化的**电畴**
- 无电场时，电畴杂乱分布，极化效应相互抵消 → 呈中性，**不具有压电性质**
- **必须进行极化处理**：在陶瓷上施加外电场，使电畴沿电场方向取向排列
- 自由电荷与陶瓷片内束缚电荷相互抵消，对外不表现极性

**⭐ 重点：** 未经极化处理的压电陶瓷不具有压电效应，这是常见考点。

#### 3.4 石英切片表示法

石英是各向异性晶体，不同方向切割的晶片物理性质（弹性、压电效应、温度特性等）相差很大。切型符号有两种：IRE标准符号表示法和习惯符号表示法。

### 第4章 压电式传感器测量电路

#### 4.1 压电等效原理

压电传感器可看作一个**电荷发生器**，同时也是一个**电容器**。

**等效电容：**

$$C_a = \frac{\varepsilon_r \varepsilon_0 A}{d}$$

**两极板间电压：**

$$U_a = \frac{q}{C_a} = \frac{d_{11}F}{\varepsilon_0 \varepsilon_r S} \cdot d$$

其中：
- $S$ — 极板面积（m²）
- $d$ — 晶体厚度（m）
- $\varepsilon_r$ — 相对介电常数（石英晶体为 4.58）
- $\varepsilon_0$ — 真空介电常数（$8.85 \times 10^{-12}$ F/m）

**⭐ 重点：两种等效电路**
| 等效形式 | 电路结构 | 适用场景 |
|----------|----------|----------|
| **电压源等效** | 电压源 $U_a$ 与电容 $C_a$ **串联** | 电压放大器 |
| **电荷源等效** | 电荷源 $q$ 与电容 $C_a$ **并联** | 电荷放大器 |

#### 4.2 压电传感器的关键限制

> **核心问题：** 只有当传感器内部信号电荷无"漏损"且外电路负载无穷大时，压电传感器受力后产生的电压或电荷才能长期保存。否则电路将以某时间常数按指数规律放电。

- 实际中，传感器内部不可能没有泄漏，外电路负载也不可能无穷大
- 只有外力以**较高频率**不断作用，传感器电荷才能得以补充
- **压电晶体不适合于静态测量**

**等效电路参数：**
- $C_a$ — 传感器固有电容
- $C_i$ — 前置放大器输入电容
- $C_c$ — 连线电容
- $R_a$ — 传感器漏电阻
- $R_i$ — 前置放大器输入电阻

为保证低频响应，压电传感器绝缘电阻应保持在 **$10^{13}\Omega$** 以上，前置放大器要有**相当高的输入阻抗**。

#### 4.3 前置放大器

**⭐ 重点：前置放大器的作用**
1. 把高输出阻抗变换为低输出阻抗
2. 放大传感器输出的微弱信号

| 放大器类型 | 输入-输出关系 | 特点 |
|------------|---------------|------|
| **电压放大器** | 输出电压与输入电压成正比 | 电路简单、价格便宜，但电缆长度影响大 |
| **电荷放大器** | 输出电压与输入电荷成正比 | 电缆长度不影响输出，精度高 |

##### 电压放大器特性

等效电阻：$R = R_a \parallel R_i$

等效电容：$C = C_c + C_i$

输入电压幅值：

$$U_{im} = \frac{d_{33}F_m \omega R}{\sqrt{1 + \omega^2 R^2 (C_a + C_c + C_i)^2}}$$

令 $\tau = R(C_a + C_c + C_i)$，$\omega_0 = 1/\tau$：

- 当 $\omega/\omega_0 \gg 1$（一般 $\omega/\omega_0 \geq 3$）时，$U_{im}$ 与频率无关 → **高频响应好**
- 当被测动态量变化缓慢而时间常数不大时 → **灵敏度下降**

电压灵敏度：

$$K_u = \frac{d_{33}}{C_a + C_c + C_i}$$

> 灵敏度与回路电容成反比，增加回路电容必然使 $K_u$ 下降。改变电缆长度会改变 $C_c$，必须**重新校正灵敏度**。

##### 电荷放大器特性

电荷放大器是一个具有**深度负反馈**的高增益放大器。

- 利用**密勒效应**：反馈电容 $C_F$ 等效到输入端时增大 $(1+A_0)$ 倍
- 当 $A_0$ 足够大时，传感器本身电容和电缆长短**不影响**电荷放大器的输出
- 输出电压仅取决于输入电荷 $q$ 及反馈参数 $C_F$

$$U_{SC} \approx -\frac{q}{C_F}$$

> 当 $A_0 > 10^4$ 时，误差 $\delta \leq 1\%$，对线性集成运算放大器来说不难达到。

#### 4.4 前置放大器应用限制

**⭐ 重点：电压放大器 vs 电荷放大器对比**

| 对比维度 | 电压放大器 | 电荷放大器 |
|----------|------------|------------|
| 电缆长度限制 | 不能太长（$C_c$ 增大会降低灵敏度） | 基本无影响 |
| 电路复杂度 | 简单、元件少 | 较复杂 |
| 价格 | 便宜 | 较贵 |
| 精度 | 受电缆影响大 | 高 |
| 解决方案 | 将放大器装入传感器组成一体化传感器 | — |

## 第二部分：习题精讲

### 习题1：简述压电效应，说明正压电效应和逆压电效应的区别。

**📚 前置知识：**
- 压电效应的定义：某些晶体在受力后表面产生电荷的现象
- 正压电效应：机械能 → 电能
- 逆压电效应：电能 → 机械能（电致伸缩效应）
- 压电效应的可逆性

**🔍 详细解答：**

**正压电效应：** 一些晶体结构的材料，当沿着一定方向受到外力作用时，内部产生极化现象，同时在某两个表面上产生符号相反的电荷；外力去掉后恢复不带电状态；作用力方向改变时，电荷极性也改变。**本质：机械能 → 电能。**

**逆压电效应：** 在电介质极化方向施加电场时，电介质在一定方向产生机械变形或机械压力，外加电场撤去时变形或应力随之消失（又称**电致伸缩效应**）。**本质：电能 → 机械能。**

| 区别 | 正压电效应 | 逆压电效应 |
|------|-----------|-----------|
| 输入 | 机械力 | 电场 |
| 输出 | 电荷/电压 | 机械变形/应力 |
| 能量转换 | 机械能→电能 | 电能→机械能 |

> 压电效应具有**可逆性**：晶体在哪个方向上有正压电效应，则在此方向上也一定存在逆压电效应。

### 习题2：石英晶体的三个轴分别是什么？沿各轴受力分别产生什么效应？

**📚 前置知识：**
- 石英晶体正六面体结构
- 三轴定义：光轴(Z)、电轴(X)、机械轴(Y)
- 纵向压电效应和横向压电效应的公式

**🔍 详细解答：**

| 轴名称 | 符号 | 位置说明 | 受力时效应 |
|--------|------|----------|------------|
| 光轴 | Z—Z | 纵向轴 | **不产生**压电效应 |
| 电轴 | X—X | 经过正六面体棱线，垂直于光轴 | 产生**纵向压电效应**：$q_x = d_{11}F_x$ |
| 机械轴 | Y—Y | 与X、Z轴同时垂直（垂直于棱面） | 产生**横向压电效应**：$q_y = d_{12}\frac{a}{b}F_y$ |

**电荷极性规律（以纵向压电效应为例）：**
- $F_x < 0$（受压）→ X轴正向出现**正电荷**
- $F_x > 0$（受拉）→ X轴正向出现**负电荷**

**横向压电效应的电荷分布与纵向相反。**

**💡 易错点：** 容易混淆光轴和电轴——光轴受力无压电效应，电轴受力才产生电荷。

### 习题3：压电传感器为什么不能用于静态测量？

**📚 前置知识：**
- 压电等效电路（电荷源/电压源 + 电容）
- 时间常数 $\tau = R(C_a + C_c + C_i)$
- RC电路的指数放电特性

**🔍 详细解答：**

1. 压电传感器等效为一个**电荷源与电容的并联电路**（或电压源与电容的串联电路）
2. 只有传感器内部信号电荷无"漏损"且外电路负载无穷大时，受力产生的电压/电荷才能长期保存
3. 实际中：传感器内部绝缘电阻不可能无穷大，外电路负载也不可能无穷大
4. 因此电路将以时间常数 $\tau$ 按**指数规律放电**
5. 对于静态信号（频率为零），电荷会逐渐泄漏，无法维持稳定输出
6. 只有外力以**较高频率**不断作用，传感器电荷才能得以补充

> **结论：** 压电晶体不适合于静态测量，适合**动态力学测量**。

**💡 易错点：** 不要混淆"不能测静态"与"灵敏度低"——根本原因是电荷泄漏，而非灵敏度问题。

### 习题4：推导压电传感器电压放大器的输入电压幅值 $U_{im}$，并分析其频率响应特性。

**📚 前置知识：**
- 压电传感器等效电路
- 复数阻抗计算
- 时间常数概念
- 截止频率 $\omega_0 = 1/\tau$

**🔍 详细解答：**

**第一步：确定等效参数**

等效电阻：$R = R_a \parallel R_i$

等效电容：$C = C_c + C_i$，总电容：$C_{total} = C_a + C_c + C_i$

**第二步：写出复数形式**

$$U_i = \frac{j\omega R}{1 + j\omega R(C_a + C_c + C_i)} \cdot d_{33}F$$

**第三步：求幅值**

$$U_{im} = \frac{d_{33}F_m \omega R}{\sqrt{1 + \omega^2 R^2 (C_a + C_c + C_i)^2}}$$

**第四步：频率特性分析**

令 $\tau = R(C_a + C_c + C_i)$，$\omega_0 = 1/\tau$：

- 当 $\omega/\omega_0 \gg 1$（一般 $\geq 3$）时：$U_{im}$ 与频率无关 → **高频响应好**
- 当 $\omega/\omega_0$ 较小时：灵敏度下降 → **低频响应差**

**结论：** 在测量回路时间常数一定条件下，压电传感器具有相当好的**高频响应特性**。要扩展低频端，需提高时间常数或采用高输入阻抗前置放大器。

### 习题5：比较电压放大器和电荷放大器的优缺点。

**📚 前置知识：**
- 电压放大器原理：$U_o \propto U_i$
- 电荷放大器原理：$U_o \propto q$，利用深度负反馈和密勒效应
- 电缆电容 $C_c$ 对两者的影响

**🔍 详细解答：**

| 对比维度 | 电压放大器 | 电荷放大器 |
|----------|------------|------------|
| 基本原理 | 输出电压 ∝ 输入电压 | 输出电压 ∝ 输入电荷 |
| 电缆电容影响 | **严重影响**灵敏度，需重新校正 | **基本无影响**（$A_0$ 很大时） |
| 灵敏度公式 | $K_u = d_{33}/(C_a+C_c+C_i)$ | $U_{SC} \approx -q/C_F$ |
| 电路复杂度 | 简单、元件少 | 较复杂（需高增益运放） |
| 价格 | 便宜、工作可靠 | 较高 |
| 适用场景 | 电缆短或一体化传感器 | 电缆长的场合 |

**改进方案：** 将放大器装入传感器组成**一体化传感器**，使引线极短（引线电容 ≈ 0），避免长电缆对灵敏度的影响。

### 习题6：压电陶瓷为什么必须经过极化处理才具有压电效应？

**📚 前置知识：**
- 压电陶瓷是多晶体材料
- 电畴概念
- 极化处理的作用

**🔍 详细解答：**

1. 压电陶瓷是人工制造的多晶压电材料，由无数细微单晶组成
2. 内部晶粒有许多自发极化的**电畴**
3. **无电场时**：电畴杂乱分布，极化效应相互抵消 → 原始压电陶瓷呈**中性**，不具有压电性质
4. **极化处理**：在陶瓷上施加外电场，使电畴沿电场方向取向排列
5. 自由电荷与陶瓷片内束缚电荷符号相反而数值相等，起屏蔽和抵消作用，陶瓷片对外不表现极性
6. 当外力作用于极化后的陶瓷时，电畴取向变化，对外输出电荷 —— 即表现出压电效应

> **结论：未经极化处理的压电陶瓷不具有压电效应。**

### 习题7：某电荷放大器，$C_a=1000\text{pF}$，$C_F=100\text{pF}$，$C_c=10^4\text{pF}$，要求误差 $\delta \leq 1\%$，求所需开环增益 $A_0$。

**📚 前置知识：**
- 电荷放大器输出公式与误差公式
- 密勒效应：$C' = (1+A_0)C_F$

**🔍 详细解答：**

由误差公式推导：

$$\delta = \frac{C_a + C_c}{(1+A_0)C_F} \leq 1\%$$

代入数值：

$$\frac{1000 + 10^4}{(1+A_0) \times 100} \leq 0.01$$

$$\frac{11000}{100(1+A_0)} \leq 0.01$$

$$\frac{110}{1+A_0} \leq 0.01$$

$$1 + A_0 \geq 11000$$

$$A_0 > 10^4$$

> **结论：** 需要 $A_0 > 10^4$，这对线性集成运算放大器来说不难达到。

### 常见易错点

1. ❌ 光轴受力产生压电效应 → ✅ 光轴（Z轴）受力**不产生**压电效应
2. ❌ 压电传感器灵敏度不够所以不能测静态 → ✅ 是**电荷泄漏**导致不能测静态
3. ❌ 压电陶瓷天然具有压电性 → ✅ 必须经过**极化处理**
4. ❌ $d_{11} = d_{12}$ → ✅ $d_{11} = -d_{12}$（轴对称条件）
5. ❌ 电荷放大器输出受电缆长度影响 → ✅ $U_{SC} \approx -q/C_F$，与电缆无关
6. ❌ 正压电效应只有一种 → ✅ 正压电效应分纵向和横向两种
