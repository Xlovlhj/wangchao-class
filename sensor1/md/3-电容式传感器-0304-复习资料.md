## 第一部分：知识梳理

### 第1章 电容式传感器的工作原理

#### 1.1 基本公式

平行板电容器的基本公式：

$$C = \frac{\varepsilon S}{d}$$

其中：
- $\varepsilon$ — 极板间介质的介电常数
- $S$ — 极板有效面积
- $d$ — 极板间距

传感器通过改变 $S$、$d$ 或 $\varepsilon$ 中的任意一个参数来实现电容变化，对应三种基本类型：
- **变面积型**：改变 $S$
- **变间隙型（变极距型）**：改变 $d$
- **变介电常数型**：改变 $\varepsilon$

### 第2章 测量电路

#### 2.1 等效电路

电容传感器的实际等效电路包含寄生参数：

| 元件 | 含义 |
|------|------|
| $C$ | 传感器电容 |
| $R_P$ | 并联电阻（电极间直流电阻+介质损耗等效电阻） |
| $R_S$ | 串联电阻（引线电阻+接线柱电阻+极板电阻） |
| $L$ | 串联电感（连线端间总电感） |

等效阻抗：
$$Z_C = \left(R_S + \frac{R_P}{1 + \omega^2 R_P^2 C^2}\right) - j\left(\frac{\omega R_P^2 C}{1 + \omega^2 R_P^2 C^2} - \omega L\right)$$

当 $R_P$ 很大时，等效电容简化为：

$$C_E = \frac{C}{1 - \omega^2 LC} = \frac{C}{1 - (f/f_0)^2}$$

其中 $f_0 = \dfrac{1}{2\pi\sqrt{LC}}$ 为电路谐振频率。

**⭐ 重点：** 当 $f < f_0$ 时，等效电容 $C_E$ 增加；标定和测量必须在同样条件下进行（线路长度等应一致）。

电容实际相对变化量：
$$\frac{\Delta C_E}{C_E} = \frac{\Delta C/C}{1 - \omega^2 LC}$$

---

#### 2.2 交流不平衡电桥（⭐ 核心重点）

##### 2.2.1 基本电路与输出公式

交流不平衡电桥是电容传感器最基本的测量电路。$Z_1$ 为传感器阻抗，$Z_2$、$Z_3$、$Z_4$ 为固定阻抗。

**输出电压（输出端开路）：**
$$U_{SC} = \frac{\beta A}{(1+A)^2}E = \beta K E$$

其中：
- $\beta = \dfrac{\Delta Z}{Z_1}$ — 传感器阻抗相对变化量
- $A = \dfrac{Z_1}{Z_2}$ — 桥臂比
- $K = \dfrac{A}{(1+A)^2}$ — 桥臂系数

对于电容传感器，$\beta \approx \dfrac{\Delta C}{C_1} \approx \dfrac{\Delta d}{d_1}$（可近似为实数）。

##### 2.2.2 桥臂比的复数表示

$$A = \frac{Z_1}{Z_2} = \frac{Z_1 e^{j\phi_1}}{Z_2 e^{j\phi_2}} = a e^{j\theta}$$

其中：$a = \dfrac{Z_1}{Z_2}$（模），$\theta = \phi_1 - \phi_2$（相角差）

桥臂系数 $K = k e^{j\gamma} = f(a,\theta)$，其中：

$$k = |K| = \frac{a}{1 + 2a\cos\theta + a^2}$$

$$\gamma = \arctan^{-1}\frac{(1-a^2)\sin\theta}{2a + (1+a^2)\cos\theta}$$

**⭐ 重点：** $k$ 和 $\gamma$ 均为 $a$、$\theta$ 的函数，$U_{SC} = \beta K E$ 的输出大小和相位均由此决定。

##### 2.2.3 电压灵敏度分析（超级重点）

| 条件 | $k$ 最大值 | 说明 |
|------|-----------|------|
| $a=1$，$\theta = 0°$ | $k = 0.25$ | 同类型阻抗，灵敏度最低 |
| $a=1$，$\theta = \pm 90°$ | $k = 0.5$ | 电容+电阻匹配，灵敏度翻倍 |
| $a=1$，$\theta = \pm 180°$ | $k \to \infty$ | 谐振电桥（纯L与纯C），实际做不到 |

**最大灵敏度条件：**
1. $|Z_1| = |Z_2|$（两桥臂初始阻抗模相等，即 $a=1$）
2. $\theta = \phi_1 - \phi_2$ 尽量大

**相位条件：**
- 当 $a=1$ 或 $\theta=0$ 时，$\gamma=0$，$U_{SC}$ 与 $E$ 同相位
- 一般 $\gamma \neq 0$，输出与电源间存在相移

##### 2.2.4 常用电桥形式及输出

| 电桥形式 | $a$ | $\theta$ | $k$ | $U_{SC}$ | 备注 |
|---------|-----|----------|-----|----------|------|
| 图(a) 四电阻 | 1 | 0° | 0.25 | $0.25\beta E$ | 基准 |
| 图(b) 四电容 | 1 | 0° | 0.25 | $0.25\beta E$ | 同图(a) |
| 图(c) 电容+电阻混搭 | 1 | 90° | 0.5 | $0.5\beta E$ | 灵敏度翻倍 |
| 图(d) 差动电容 | — | — | — | $\beta E$ | 差动式，再翻倍 |

**⭐ 重点：** 图(c)与图(b)元件相同但接法不同，灵敏度翻倍；差动式电容传感器可使输出再翻倍。

**补充说明：** 以上输出假设负载阻抗无穷大，实际负载会偏小。电桥输出为交流信号，需经交流放大→相敏检波→低通滤波才能得到反映极性的直流输出。

#### 2.3 二极管环形检波电路

**结构：** 振荡器 → 变压器 $T_P$ → 二极管环形检波（$D_1\sim D_4$）→ 稳幅放大器 $A_1$ → 比例放大器 $A_2$ + 电流转换

**工作原理：**
- $i_L = \omega C_L e$，$i_H = \omega C_H e$
- $e$ 正半周：$D_1$、$D_4$ 导通，$D_2$、$D_3$ 截止
- $e$ 负半周：$D_2$、$D_3$ 导通，$D_1$、$D_4$ 截止

**稳幅条件：** $I_C = i_L + i_H = \omega e(C_L + C_H)$，即 $\omega e = \dfrac{I_C}{C_L + C_H}$

**差动电流：** $i_L - i_H = \dfrac{C_L - C_H}{C_L + C_H} \cdot I_C$

**输出电流（变间隙型差动）：** $I = \dfrac{I_C R_S}{R_F} \cdot \dfrac{\Delta d}{d_0} + \dfrac{U_B}{R_F} - \beta\dfrac{U_0}{R_F}$

**特点：**
- 变面积或变间隙差动电容均能获得**线性输出**
- 量程和零点调整互不干扰
- 改变 $R_F$ 可调整输出起始电流

---

#### 2.4 差动脉冲宽度调制电路

**核心结构：** 差动电容 $C_1$、$C_2$ + 双稳态触发器 + 比较器 $A_1$、$A_2$ + 低通滤波

**工作原理：**
1. A 端高电位 → $R_1$ 对 $C_1$ 充电 → M 点达 $U_F$ → $A_1$ 触发翻转 → A↓B↑
2. B 端高电位 → $R_2$ 对 $C_2$ 充电 → N 点达 $U_F$ → $A_2$ 触发翻转 → A↑B↓
3. 循环往复，A、B 端各产生宽度受 $C_1$、$C_2$ 调制的方波

**输出直流电压：**
$$U_{SC} = U_1 \cdot \frac{C_1 - C_2}{C_1 + C_2}$$

当 $R_1 = R_2 = R$ 时：
$$T_1 = RC_1 \ln\frac{U_1}{U_1 - U_F},\quad T_2 = RC_2 \ln\frac{U_1}{U_1 - U_F}$$

$$U_{SC} = U_1 \cdot \frac{T_1 - T_2}{T_1 + T_2}$$

**变间隙型差动（$\Delta d$ 位移）：**
$$U_{SC} = \frac{\Delta d}{d_0} U_1$$

**变面积型差动（$\Delta S$ 变化）：**
$$U_{SC} = \frac{\Delta S}{S} U_1$$

**⭐ 特点：**
- 不需要附加解调器即可获得直流输出
- 输出为 100kHz～1MHz 矩形波，低通滤波即可
- 对电源要求低（只需稳定直流电源，不需稳频稳幅交流电源）
- 具有**线性输出特性**

---

#### 2.5 变压器电桥

差动电容 $C_1$、$C_2$ 与变压器副边构成电桥。当放大器输入阻抗 $Z_f \to \infty$ 时：

$$U_{SC} = \frac{C_1 - C_2}{C_1 + C_2} \cdot E$$

**⭐ 重点：** 输出与差动电容之差成正比，线性度好。

**应用示例——油量测量：**
- 无油时 $C_x = C_{x0}$，调平衡使 $E_1 C_{x0} = E_2 C_0$
- 油量变化 → $C_x$ 变化 → 电桥失衡 → 输出放大 → 电机转动 → 指针指示/电位器调整 $E$ → 恢复平衡

---

#### 2.6 调频电路

将电容传感器作为 LC 振荡器谐振回路的一部分，$C_x$ 变化 → 频率 $f$ 相应变化：

$$f = \frac{1}{2\pi\sqrt{L_0 C}}$$

通过测量频率变化间接测电容变化。

---

#### 2.7 运放式线路

利用运算放大器，从原理上解决单电容变间隙传感器的非线性问题：

$$\frac{\dot{U}_{SC}}{\dot{U}} = -\frac{Z_F}{Z_1} = -\frac{-j\frac{1}{\omega C_0}}{-j\frac{1}{\omega C_x}} = -\frac{C_x}{C_0}$$

代入 $C_x = \dfrac{\varepsilon S}{\delta}$：

$$U_{SC} = -U \cdot \frac{C_0}{\varepsilon S} \cdot \delta$$

**特点：**
- 输出电压 $U_{SC}$ 与极距 $\delta$ 成**线性关系**
- 理论上消除非线性，实际受 $Z_i \neq \infty$、$K \neq \infty$ 影响仍有小量非线性
- 需要高精度交流稳压源和高质量电容 $C_0$
- 特别适合结构上不能用差动电容的场合

### 第3章 误差分析

#### 3.1 电容电场的边缘效应

**问题：** 极板边缘电场不均匀 → 等效于并联附加电容 → 灵敏度下降、非线性增加

**解决方法：**
1. 增大初始电容（增大面积、减小间距）
2. **加装等位环**（最有效）：在极板 A 同一平面内加同心环面 G，A 与 G 保持等电位，将边缘效应拉出工作区

**⭐ 重点：** 加等位环是消除边缘效应的标准方法。

---

#### 3.2 寄生与分布电容的影响

**问题：** 传感器电容很小（几十 pF），寄生电容影响大；屏蔽电缆分布电容可达几百 pF/m

**解决方法：**
- 静电屏蔽 + 良好接地
- 增加初始电容值
- **驱动电缆技术**（核心方法）

##### 驱动电缆技术原理

双层屏蔽电缆：
- 内屏蔽线接 1:1 放大器的输出端
- 芯线接传感器 → 放大器输入端
- 1:1 放大器使芯线和内屏蔽线**等电位**
- 消除连线分布电容的影响

**对 1:1 放大器的要求：**
- 输入电容 = 0
- 输入阻抗 = ∞
- 相移 = 0

**⭐ 重点：** 技术上难以完全满足，适用于 $C_x$ 较大的传感器。

---

#### 3.3 温度对结构稳定性的影响

**温度误差来源：** 零件尺寸随温度变化 → 极板间隙 $\delta_0$ 变化

$$\delta_0 = a_0 - b_0 - g_0$$

温度变化后：
$$\delta_t = a_0(1+\alpha_a\Delta t) - b_0(1+\alpha_b\Delta t) - g_0(1+\alpha_g\Delta t)$$

$$\Delta\delta_t = (a_0\alpha_a - b_0\alpha_b - g_0\alpha_g) \cdot \Delta t$$

**消除条件：** $a_0\alpha_a - b_0\alpha_b - g_0\alpha_g = 0$

**减小温度误差的方法：**
- 减少热膨胀尺寸链的组成环节
- 选用热膨胀系数小、尺寸稳定的材料（石英、陶瓷、玻璃、镍铁合金）
- **采用差动对称结构**进行温度补偿

---

#### 3.4 温度对介质介电常数的影响

以同心圆柱式液位传感器为例：

$$\Delta C_t = \frac{2\pi H}{\ln(R_2/R_1)} \cdot \varepsilon_{t0}\alpha_t \Delta t$$

$\Delta C_t \propto H \cdot \Delta\varepsilon_t$，温度变化 → 介电常数变化 → 电容变化

---

#### 3.5 漏电阻的影响

**问题：** 容抗很高（尤其低频时），漏电阻与之接近 → 分路效应 → 灵敏度下降

**解决方法：**
- 选用绝缘性能好的材料（陶瓷、石英、聚四氟乙烯）
- 提高激励电源频率（降低对绝缘性能的要求）

---

### 第4章 电容式传感器的应用

#### 4.1 差压变送器

**二室结构：**
- 感压膜片为可动电极，与两个固定电极构成差动球-平面型电容 $C_L$ 和 $C_H$
- 固定球面电极在绝缘体（玻璃/陶瓷）上蒸镀金属膜制成
- 压力差 → 膜片挠曲 → $C_L$、$C_H$ 差动变化 → 转换为 4-20 mA 标准电流

**一室结构：**
- 中心轴连接两个测量膜片与可动平板电极
- 片簧将可动电极在圆周方向张紧
- 两电容经节流孔连通
- $p_H > p_L$ 时 → 膜片推动可动电极 → 差动电容变化

**特点：**
- 充灌硅油密封（温度系数小、稳定性高）
- 张紧式膜片（良好线性度）
- 输出 4-20 mA 标准电流信号
- 动态响应时间 0.2～15s
- 精度可达 0.25%

**⭐ 重点：** 差压变送器工作原理——压力差 → 膜片位移 → 差动电容变化 → 4-20mA 电流输出

#### 4.2 液位测量

**连续测量：**
- 导电容器壁作为一极，插入电极作为另一极
- 非导电容器壁需使用管式电极或附加反电极
- 物位变化 → 电容变化值 $\Delta C$ 与物位高度 $x$ 成**线性关系**

**限位器：**
- 电容测头在极限位置时电容发生突变（非连续变化）
- 70° 角倾斜安装可防止被测液粘附
- 平面电极用于搅拌器等不能内部插入探头的场合

**液位-压力：** $p = \rho g h$，差压变送器可配合用于液位测量

#### 4.3 加速度传感器

**MEMS 结构：**
- 底层多晶硅（固定下电极）、中间多晶硅（可动悬臂梁）、顶层多晶硅（固定上电极）
- 构成差动电容 $C_1$、$C_2$
- 振动 → 悬臂梁上下移动 → $C_1$、$C_2$ 差动变化

**特点：**
- 硅弹性滞后小、质量轻
- 频率响应可达 1kHz 以上
- 加速度范围可达 10g 以上
- 信号处理电路与传感单元封装在同一壳体内

**汽车应用：** 碰撞传感器 → 负加速度超过设定值 → 安全气囊充气

#### 4.4 接近开关

- 测量头为电容一极，被测物体为另一极
- 物体靠近 → 电容变化 → RC 振荡器起振 → 控制开关通断
- 可检测导电体、介质损耗较大的绝缘体、含水物体

## 第二部分：习题精讲

### 习题1：电容测微仪计算

**题目：**
一电容测微仪，其传感器为平行板电容器。固定极板的半径 $r = 4\ mm$，工作初始间隙 $d_0 = 0.3\ mm$，介质为空气，介电常数 $\varepsilon = 8.85 \times 10^{-12}\ F/m$。

（1）通过测量得到电容变化量为 $\Delta C = \pm 3 \times 10^{-3}\ pF$，则传感器与工件之间由初始间隙变化的距离 $\Delta d$ 为多少？

（2）如果测量电路放大倍数 $K = 100\ V/pF$，读数仪表的灵敏度 $S = 5\ 格/mV$，则此时仪表的指示值变化多少格？

**📚 前置知识：**

- 平行板电容公式：$C = \dfrac{\varepsilon S}{d}$
- 对间隙 $d$ 求微分：$\dfrac{\Delta C}{\Delta d} = -\varepsilon \dfrac{S}{d^2}$，即 $\Delta d = -\dfrac{d_0^2}{\varepsilon S} \cdot \Delta C$
- 极板面积：$S = \pi r^2$
- 仪表指示值 = $K \times S \times \Delta C$（注意单位换算：mV = $10^{-3}$V）

**🔍 详细解答：**

**（1）求位移变化量 $\Delta d$：**

步骤一：计算极板面积
$$S = \pi r^2 = \pi \times (0.004)^2 = \pi \times 1.6 \times 10^{-5}\ m^2$$

步骤二：由公式推导
$$C = \frac{\varepsilon S}{d}$$
$$\frac{dC}{dd} = -\frac{\varepsilon S}{d^2}$$
$$\Delta d = -\frac{d_0^2}{\varepsilon S} \cdot \Delta C$$

步骤三：代入数值（注意单位统一）
$$d_0 = 0.3\ mm = 0.3 \times 10^{-3}\ m$$
$$\Delta C = \pm 3 \times 10^{-3}\ pF = \pm 3 \times 10^{-15}\ F$$
$$\varepsilon = 8.85 \times 10^{-12}\ F/m$$

$$\Delta d = -\frac{(0.3 \times 10^{-3})^2}{8.85 \times 10^{-12} \times \pi \times (0.004)^2} \times (\pm 3 \times 10^{-15})$$
$$= -\frac{9 \times 10^{-8}}{8.85 \times 10^{-12} \times \pi \times 1.6 \times 10^{-5}} \times (\pm 3 \times 10^{-15})$$

计算得：$\Delta d = \pm 0.61\ \mu m$

**（2）求仪表示值变化：**

仪表指示值变化 $m = K \times S \times \Delta C$

代入：$m = 100\ V/pF \times 5\ 格/mV \times (\pm 3 \times 10^{-3}\ pF)$

注意单位：$5\ 格/mV = 5000\ 格/V$

$m = 100 \times 5000 \times (\pm 3 \times 10^{-3}) = \pm 1.5\ 格$

**💡 易错点：**
- 单位换算：pF = $10^{-12}$F，$\Delta C$ 单位是 pF 时需注意
- $\Delta d$ 公式中的负号表示电容增加时极距减小（反向关系）
- 仪表灵敏度 $S = 5\ 格/mV$，mV 与 V 差 $10^3$ 倍
- $r=4\ mm$ 要转换为 $0.004\ m$

### 习题2：交流不平衡电桥设计

**题目：**
已知一差动式电容传感器，其初始电容为 $C_1 = C_2 = 100\ pF$，交流信号源电压有效值 $U = 6\ V$，频率 $f = 100\ Hz$。

（1）在满足有最高电压输出灵敏度条件下，设计交流不平衡电桥电路，并画出电路原理图；
（2）计算另外两个桥臂的匹配电阻值；
（3）当传感器电容变化量为 $\pm 10\ pF$ 时，计算桥路输出电压。

**📚 前置知识：**

- 交流电桥最大灵敏度条件：$a = 1$（桥臂阻抗模相等）且 $\theta = \pm 90°$（相角差最大→$k=0.5$）
- 桥臂比 $A = Z_1/Z_2 = a e^{j\theta}$，$a = |Z_1|/|Z_2|$，$\theta = \phi_1 - \phi_2$
- 电容阻抗：$Z_C = \dfrac{1}{j\omega C} = -j\dfrac{1}{\omega C}$，$\phi_C = -90°$
- 电阻阻抗：$Z_R = R$，$\phi_R = 0°$
- 电阻与电容的相角差 $\theta = 0° - (-90°) = 90°$ ✓
- 输出电压：$U_{SC} = \dfrac{\beta A}{(1+A)^2}E = \beta K E$，最优时 $k=0.5$
- $\beta = \Delta C / C_1$

**🔍 详细解答：**

**（1）灵敏度条件分析：**

根据交流电桥电压灵敏度曲线，当桥臂比 $a = 1$、相角 $\theta = 90°$ 时，桥臂系数取最大值 $k_m = 0.5$。

差动电容传感器 $C_1$ 和 $C_2$ 的阻抗相位角均为 $-90°$。要使 $\theta = 90°$，需用电容与电阻组合：
- $Z_1$ = 电容 $C_1$（$\phi_1 = -90°$）
- $Z_2$ = 电阻 $R$（$\phi_2 = 0°$）
- 则 $\theta = \phi_1 - \phi_2 = -90° - 0° = -90°$，$|\theta| = 90°$ ✓

电路原理图：差动电容 $C_1$（$Z_1$）与电阻 $R$（$Z_2$）构成桥臂 a=1 的电桥，$C_2$ 作为另一桥臂。

**（2）匹配电阻计算：**

由 $a = |Z_1|/|Z_2| = 1$，即 $|Z_C| = R$：

$$|Z_C| = \frac{1}{\omega C} = \frac{1}{2\pi f C}$$

代入数值：

$$R = \frac{1}{2\pi \times 100 \times 100 \times 10^{-12}} = \frac{1}{2\pi \times 10^{-8}} = \frac{10^8}{2\pi} \approx 15.9\ k\Omega$$

**（3）桥路输出电压：**

$\beta = \dfrac{\Delta C}{C_1} = \dfrac{\pm 10}{100} = \pm 0.1$

代入 $a=1$、$\theta=90°$ 时 $k=0.5$：

$$U_{SC} = \beta k E = (\pm 0.1) \times 0.5 \times 6 = \pm 0.3\ V$$

**💡 易错点：**
- 电容阻抗的相角是 $-90°$（容性），电阻为 $0°$，两者之差为 $90°$ 满足最优条件
- $\theta = 90°$ 时 $k_{max}=0.5$，不是 $0.25$（$\theta=0°$ 时才是 0.25）
- $\beta$ 是阻抗相对变化量，对于电容传感器 $\beta \approx \Delta C/C$
- 差动式时输出可再翻倍

## 第三部分：考点速记

### 一、电容传感器核心公式

| 公式 | 含义 |
|------|------|
| $C = \dfrac{\varepsilon S}{d}$ | 平行板电容基本公式 |
| $C_E = \dfrac{C}{1-\omega^2 LC}$ | 等效电容（考虑寄生电感） |
| $f_0 = \dfrac{1}{2\pi\sqrt{LC}}$ | 电路谐振频率 |
| $\Delta d = -\dfrac{d_0^2}{\varepsilon S}\Delta C$ | 变间隙型位移-电容变化关系 |

### 二、交流不平衡电桥核心公式

| 公式 | 含义 |
|------|------|
| $U_{SC} = \dfrac{\beta A}{(1+A)^2}E = \beta K E$ | 电桥输出电压 |
| $A = \dfrac{Z_1}{Z_2} = a e^{j\theta}$ | 桥臂比（复数形式） |
| $k = \dfrac{a}{1+2a\cos\theta+a^2}$ | 桥臂系数的模 |
| $\beta \approx \dfrac{\Delta C}{C} \approx \dfrac{\Delta d}{d}$ | 电容传感器阻抗相对变化量 |

### 三、电桥灵敏度速查表

| $a$ | $\theta$ | $k_{max}$ | 实现方式 |
|-----|----------|-----------|---------|
| 1 | 0° | 0.25 | 四电阻或四电容 |
| 1 | ±90° | 0.5 | 电容+电阻混搭（$R = 1/\omega C$） |
| 1 | ±180° | →∞ | 纯电感和纯电容谐振（实际做不到） |

### 四、各类测量电路对比

| 电路类型 | 输出形式 | 线性度 | 特点 |
|---------|---------|--------|------|
| 交流不平衡电桥 | 交流 | 一般 | 最基本，需相敏检波 |
| 二极管环形检波 | 直流 | 好 | 稳幅反馈，线性输出 |
| 差动脉冲调宽 | 直流 | 好 | 不需解调器，矩形波输出 |
| 变压器电桥 | 交流 | 好 | 差动输出 $U_{SC} = \frac{C_1-C_2}{C_1+C_2}E$ |
| 调频电路 | 频率 | 一般 | $f = \frac{1}{2\pi\sqrt{LC}}$ |
| 运放式线路 | 交流 | 优 | $U_{SC} \propto \delta$，消除非线性 |

### 五、误差类型与解决方法

| 误差类型 | 原因 | 解决方法 |
|---------|------|---------|
| 边缘效应 | 极板边缘电场不均匀 | **加装等位环**（最有效）；增大初始电容 |
| 寄生/分布电容 | 电缆屏蔽线分布电容大 | **驱动电缆技术**；静电屏蔽接地 |
| 温度（结构） | 零件热膨胀 → 间隙变化 | 选低膨胀系数材料；差动对称结构 |
| 温度（介电常数） | $\varepsilon$ 随温度变化 | 材料选择；温度补偿 |
| 漏电阻 | 绝缘不够 → 分路效应 | 选高绝缘材料；提高激励频率 |

### 六、驱动电缆技术要点

| 要求 | 目标 |
|------|------|
| 芯线与屏蔽层等电位 | 消除分布电容 |
| 1:1 放大器输入电容 = 0 | 理想跟随 |
| 1:1 放大器输入阻抗 = ∞ | 无负载效应 |
| 1:1 放大器相移 = 0 | 精确跟踪 |

### 七、差压变送器核心参数

| 参数 | 数值/特性 |
|------|----------|
| 密封液 | 硅油（温度系数小、稳定性高） |
| 膜片结构 | 张紧式（良好线性度） |
| 输出信号 | 4-20 mA DC 标准电流 |
| 精度 | 可达 0.25% |
| 响应时间 | 0.2～15 s |
