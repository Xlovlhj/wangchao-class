## 第一部分：知识梳理

### 第1章 热电式传感器概述

#### 1.1 基本概念

**热电式传感器**是一种将温度变化转换为电量变化的装置。

| 类型 | 转换方式 | 典型代表 |
|------|----------|----------|
| **热电偶** | 温度 → 电势 | K型、S型、B型等 |
| **热电阻** | 温度 → 电阻（金属） | Pt100、Cu50 |
| **热敏电阻** | 温度 → 电阻（半导体） | NTC、PTC、CTR |

> 两种传感器在工业生产中广泛应用，可选用定型显示仪表和记录仪进行显示和记录。

### 第2章 热电偶温度传感器

#### 2.1 热电效应（西拜克效应）

**⭐ 重点：热电效应定义**

将两种不同的导体（或半导体）A、B 组合成闭合回路。若两结点处温度不同，则回路中产生热电动势，有电流流动。这种现象称为**热电效应**或**西拜克效应（Seebeck Effect）**。

- **热端（T）**：测量端，接触被测温度
- **冷端（$T_0$）**：自由端/参比端

**热电偶回路总热电势由两部分组成：**
1. **接触电势** — 两种导体的接触电势
2. **温差电势** — 单一导体的温差电势

#### 2.2 接触电势

$$\large e_{AB}(T) = \frac{kT}{e} \ln\frac{N_A}{N_B}$$

| 符号 | 含义 |
|------|------|
| $k$ | 玻耳兹曼常数 |
| $T$ | 接触面的绝对温度 |
| $e$ | 单位电荷量 |
| $N_A$、$N_B$ | 金属电极 A、B 的自由电子密度 |

> 接触电势的大小与**温度高低**及**导体中的电子密度**有关。

#### 2.3 温差电势

$$e_A(T, T_0) = \int_{T_0}^{T} \sigma_A \,dt$$

| 符号 | 含义 |
|------|------|
| $\sigma_A$ | **汤姆逊系数**，导体 A 两端温差 1℃ 时产生的温差电动势（与材料性质有关） |

#### 2.4 回路总热电势

**⭐ 重点：总热电势公式**

$$E_{AB}(T, T_0) = e_{AB}(T) - e_{AB}(T_0) - [e_A(T,T_0) - e_B(T,T_0)]$$

由于温度不能显著改变自由电子浓度（$N_{AT}=N_{AT_0}$，$N_{BT}=N_{BT_0}$），化简为：

$$E_{AB}(T, T_0) = \frac{k}{e}(T - T_0)\ln\frac{N_A}{N_B} - \int_{T_0}^{T} (\sigma_A - \sigma_B)dt$$

温差电势极小，可忽略，最终：

$$E_{AB}(T, T_0) = f(T) - f(T_0)$$

当 $T_0=0℃$ 时：

$$E_{AB}(T, 0) = f(T) - c = \varphi(T)$$

**⭐ 核心结论：**
- $E$ 与 $T$ 之间有**唯一相应的单值函数关系**，测出 $E$ 即可得到 $T$
- 热电势大小**只与材料有关、与冷热端温度有关**，与导体粗细长短及接触面积**无关**

**产生热电势的充要条件：**
1. 两种**不同的金属材料**构成热电偶
2. 两端存在**温差**

> - 同种材料：$N_A=N_B$, $\sigma_A=\sigma_B$ → $E_{AB}=0$
> - 两端同温：$T=T_0$ → $E_{AB}=0$

### 第3章 热电偶基本定律

**⭐ 重点：四大定律（高频考点）**

#### 3.1 均质导体定律

由一种均质导体组成的闭合回路，不论导体是否存在温度梯度，回路中**不产生电动势**。反之，若有电流，材料一定非均质。

**推论：**
- 热电偶必须采用两种不同材料的导体
- 热电势仅与两接点温度有关，与沿热电极的温度分布无关
- 热电极材料的**均匀性**是衡量热电偶质量的主要技术指标之一

#### 3.2 中间导体定律

在热电偶回路中接入第三种导体 C（中间导体），只要中间导体的**两端温度相同**，回路总电动势**不受影响**。

> **推广：** 接入多种导体后，只要每种导体两端温度相同，对回路总热电势无影响。显示仪表和连接导线的接入可看作中间导体接入。

#### 3.3 标准电极定律

$$E_{AB}(T, T_0) = E_{AC}(T, T_0) + E_{CB}(T, T_0)$$

> 通常选用**高纯铂丝**作为标准电极（物理化学性质稳定、熔点高、易提纯）。

#### 3.4 中间温度定律（连接导体定律）

$$E_{AB}(T, T_0) = E_{AB}(T, T_n) + E_{AB}(T_n, T_0)$$

> 这是冷端补偿的理论基础。

### 第4章 热电偶材料与结构

#### 4.1 热电极材料条件

- 温度测量范围广，测量精确度高，热电动势大
- 热电性能稳定，均匀性和复现性好
- 化学稳定性好，抗氧化性或抗还原性能好

#### 4.2 标准化热电偶

**⭐ 重点：七种标准型热电偶（IEC 标准）**

我国指定 **S、B、E、K、R、J、T** 七种为统一设计型热电偶。

| 类型 | 材料组合 |
|------|----------|
| S 型 | 铂铑-铂 |
| K 型 | **镍铬-镍硅**（最常用） |
| E 型 | 镍铬-考铜 |
| B 型 | 铂铑30-铂铑6 |
| T 型 | 铜-康铜 |

> **分度表**：各种热电偶的热电势与温度对照表，按参考端温度为 0℃ 取值，中间值可用内插法计算。

#### 4.3 工业用热电偶结构

| 部件 | 说明 |
|------|------|
| 热电偶丝 | 核心测温元件 |
| 绝缘套管 | 电气绝缘 |
| 保护套管 | 机械保护（实验室用时可不装以减小热惯性） |
| 接线盒 | 连接外部电路 |

### 第5章 热电偶冷端处理和补偿

**⭐ 重点：五种补偿方法**

#### 5.1 补偿导线法

**功能：**
- 实现**冷端迁移**（将冷端延长到温度稳定处）
- 降低电路成本

**使用注意事项：**
- 只能在要求温度范围（0~100℃）内使用
- 热电偶和补偿导线两接点处保持**温度相同**
- 不同型号热电偶配不同补偿导线
- 补偿导线正负极分别与热电偶正负极相连
- **理论基础**：连接导体定律 + 中间温度定律

#### 5.2 冰浴法（冷端温度恒温法）

将冷端置于**冰水混合物**中，使 $T_0 = 0℃$。仅适用于**实验室精确测量和检定**。

#### 5.3 计算修正法

$$E(T, 0) = E(T, T_1) + E(T_1, 0)$$

1. 用室温计测环境温度 $T_1$
2. 查分度表得 $E(T_1, 0)$
3. 加上测量值 $E(T, T_1)$ 得到 $E(T, 0)$
4. 反查分度表得真实温度 $T$

#### 5.4 冷端补偿电桥法

利用**直流不平衡电桥**产生电势来补偿冷端温度变化引起的热电势变化值。

- $R_1$、$R_2$、$R_3$：锰铜丝绕制（电阻温度系数极小，不随温度变化）
- $R_{Cu}$：铜丝绕制（电阻温度系数大），须与冷端处于**同一温度**

#### 5.5 软件处理法

通过软件算法自动补偿。

### 第6章 热电阻传感器

#### 6.1 基本概念

将温度变化转换为**电阻变化**的传感器。

| 类型 | 材料 | 简称 |
|------|------|------|
| 金属热电阻式 | 铂、铜 | 热电阻 |
| 半导体热电阻式 | 氧化物复合材料 | 热敏电阻 |

**热电阻材料要求：**
- 高温度系数、高电阻率
- 化学、物理性能稳定
- 良好的线性输出特性
- 良好的工艺性

#### 6.2 铂热电阻

**⭐ 重点：铂热电阻特性**

- 主要用于**温度基准、标准的传递**，作为标准电阻温度计
- **百度电阻比** $W(100)$：0~100℃ 内阻值变化的倍数，代表铂丝纯度
  - 基准器：$W(100) \geq 1.3925$
  - 工业用：$W(100) = 1.387 \sim 1.390$

**特性方程：**

当 $-200℃ \leq t \leq 0℃$：
$$R_t = R_0[1 + At + Bt^2 + C(t - 100)t^3]$$

当 $0℃ \leq t \leq 650℃$：
$$R_t = R_0(1 + At + Bt^2)$$

**分度号：Pt10（$R_0=10\Omega$）和 Pt100（$R_0=100\Omega$）**

#### 6.3 铜热电阻

**⭐ 重点：铜热电阻特性**

- 测量范围：$-50 \sim 150℃$
- 优点：温度范围内**线性关系好**，灵敏度比铂电阻高，易提纯、加工，价格便宜
- 缺点：易氧化，电阻率低（体积较大）

**特性方程：**
$$R_t = R_0(1 + \alpha t)$$

关系是**线性的**。

**分度号：Cu50（$R_0=50\Omega$）和 Cu100（$R_0=100\Omega$）**

#### 6.4 热电阻测温电路

**⭐ 重点：三线制与四线制**

| 接线方式 | 原理 | 特点 |
|----------|------|------|
| **两线制** | 两根导线直接连接 | 导线电阻引入 $2r$ 误差，不适用于工业 |
| **三线制** | 对称电桥 + 三根导线 | $R_1=R_2$ 时导线电阻 $r$ 对平衡无影响，消除 $r$ 影响 |
| **四线制** | 恒流源供电 + 电位差计测压 | 导线压降不在测量范围，精度最高 |

> **三线制核心：** 设计电桥满足 $R_1=R_2$，导线电阻 $r$ 项完全消去。**仅在对称电桥平衡状态下有效。**

#### 6.5 热电阻与热电偶对比

| 对比维度 | 热电阻 | 热电偶 |
|----------|--------|--------|
| 输出信号大小 | 大（测 Ω 级增量） | 小（测 mV 级） |
| 是否需要电源 | **需要外接电源** | 不需要（自发电） |
| 感温部分尺寸 | 较大 | 小焊点 |
| 反应速度 | 较慢 | 较快 |
| 测温上限 | 较低 | 较高 |

### 第7章 热敏电阻

#### 7.1 分类

**⭐ 重点：三种类型热敏电阻**

| 类型 | 全称 | 温度系数 | 特性 |
|------|------|:------:|------|
| **NTC** | 负温度系数热敏电阻 | 负 | 测温范围 $-100 \sim +300℃$，最常用 |
| **PTC** | 正温度系数热敏电阻 | 正 | 居里点附近导电率突变 |
| **CTR** | 临界温度系数热敏电阻 | 负（临界） | 特定温度下电阻急剧变化 |

#### 7.2 NTC 热敏电阻特点

- 电阻温度系数大，灵敏度高（约为热电阻的 **10 倍**）
- 结构简单，体积小，可测量**点温度**
- 电阻率高，热惯性小，适宜**动态测量**
- 易于维护和远距离控制
- 制造简单，使用寿命长

> **缺点：** 互换性差，**非线性严重**。

#### 7.3 热敏电阻基本参数

| 参数 | 符号 | 含义 |
|------|------|------|
| 标称电阻值 | $R_{25}$ | 25℃ 时的阻值 |
| 材料常数 | $B$ | $B = \Delta E/2k$，$B$ 越大灵敏度越高 |
| 电阻温度系数 | $\alpha_t$ | $\alpha_t = \frac{1}{R_T}\frac{dR_T}{dT}$ |
| 耗散系数 | $H$ | 温度变化 1℃ 所耗散的功率 |
| 时间常数 | $\tau$ | $\tau = C/H$，从起始到最终变量 63.2% 所需时间 |
| 额定功率 | $P_E$ | 长期连续工作允许的耗散功率 |

> $R_{25}$ 换算公式：$R_{25} = \dfrac{R_t}{1 + \alpha_{25}(t - 25)}$

#### 7.4 NTC 温度特性

$$R_T = R_{T_0} \cdot e^{B_N(\frac{1}{T} - \frac{1}{T_0})}$$

取对数：$\ln R_T = \ln R_{T_0} + B_N(\frac{1}{T} - \frac{1}{T_0})$

> 以 $\ln R_T$、$1/T$ 为坐标是一条**直线**，斜率为 $B_N$。

#### 7.5 PTC 温度特性

$$R_T = R_{T_0} \cdot e^{B_P(T - T_0)}$$

电阻温度系数 $\alpha_{tp}$ 正好等于材料常数 $B_P$ 的值。

#### 7.6 伏安特性

- 起始段为直线（电流很小，温升可忽略）
- 当温度超过环境温度后曲线弯曲
- 存在**电压最大值 $U_m$** 和**电流最大值 $I_m$**
- 超过 $U_m$ 后电流反而减小（曲线斜率由正变负）

## 第二部分：习题精讲

### 习题1：K 型热电偶在工作时冷端温度 $t_0=30℃$，测得热电势 $E_K(t, t_0)=39.17\text{ mV}$。求被测介质的实际温度 $t$。

**📚 前置知识：**
- 中间温度定律：$E(T,0) = E(T,T_0) + E(T_0,0)$
- 分度表的使用：查表得 $E(T_0,0)$ 和反查温度
- K 型热电偶分度表（按参考端 0℃ 取值）

**🔍 详细解答：**

**第一步：** 由分度表查出 $E_K(30℃, 0℃) = 1.20\text{ mV}$

**第二步：** 应用中间温度定律：

$$E_K(t, 0℃) = E_K(t, 30℃) + E_K(30℃, 0℃) = 39.17 + 1.20 = 40.37\text{ mV}$$

**第三步：** 查分度表反查温度：$40.37\text{ mV}$ 对应的温度：

$$t = 977℃$$

> **答案：** 被测介质实际温度为 **977℃**。

**💡 易错点：** 不能用 $t = 30 +$ 指示值简单相加，必须通过**热电势相加后再查表**。

### 习题2：S 分度热电偶测温系统，$t=1000℃$，$t_x=40℃$，冷端温度补偿器平衡温度 20℃。(1) 仪表机械零位应调多少度？(2) 补偿器电源开路时仪表指示？(3) 电源极性接反时仪表指示？

**📚 前置知识：**
- 冷端温度补偿器原理：产生与冷端温度变化对应的补偿电势
- 补偿器平衡温度含义
- S 分度热电偶分度表

**🔍 详细解答：**

**(1)** 热电偶冷端在 40℃，但冷端温度补偿器使其相当于冷端在 20℃。仪表机械零位应调整到 **20℃**，仪表指示 $t = 1000℃$。

**(2)** 补偿器电源开路失去补偿作用时：
$$E_t = E_1 + E_2 = E_S(1000, 40) + E_S(20, 0) = 9.465\text{ mV}$$

查表得：$t = 989℃$

**(3)** 电源极性接反时，补偿器不但不补偿，还抵消部分热电势：
$$E_t = E_1 - U_{cd} + E_2 = E_S(1000, 40) - E_S(40, 20) + E_S(20, 0) = 9.334\text{ mV}$$

查表得：$t = 978℃$

> **答案：** (1) 20℃；(2) **989℃**；(3) **978℃**。

**💡 易错点：** 补偿器电源极性接反时，补偿电势变成**负补偿**（抵消热电势），导致测量值偏低。

### 习题3：镍铬-铜镍热电偶测换热器温度，冷端 30℃，仪表机械零位 0℃，指示值 400℃。认为实际为 430℃ 对不对？正确值为多少？

**📚 前置知识：**
- 仪表刻度以冷端为 0℃ 为基准
- 当冷端温度 ≠ 0℃ 且机械零位在 0℃ 时，指示值 ≠ 真实温度
- 正确做法：$E(t, 0) = E(t, 30) + E(30, 0)$

**🔍 详细解答：**

**分析：** 不对。仪表机械零位在 0℃ 与冷端 30℃ 不一致，仪表刻度以冷端为 0℃ 刻度的，故指示值不是换热器真实温度。

**计算：**

查热电势表：
$$E(400, 0) = 28.943\text{ mV},\quad E(30, 0) = 1.801\text{ mV}$$

实际热电势：
$$E(t, 30) = E(400, 0) = 28.943\text{ mV}$$

$$E(t, 0) = E(t, 30) + E(30, 0) = 28.943 + 1.801 = 30.744\text{ mV}$$

查表得：$t = 422℃$

> **答案：** 不对，正确值为 **422℃**。不能简单用指示温度 + 冷端温度 = 400 + 30 = 430℃。

**💡 易错点：** 这是最常见的考试陷阱——**不能用指示温度与冷端温度直接相加**表示实际温度，必须通过热电势相加再查表。

### 习题4：一支分度号为 Cu100 的热电阻，在 130℃ 时它的电阻 $R_t$ 是多少？要求精确计算和估算。

**📚 前置知识：**
- Cu100 含义：0℃ 时电阻 $R_0 = 100\Omega$
- 铜电阻精确公式：$R_t = R_0(1 + At + Bt^2 + Ct^3)$
- 近似估算：$R_t = R_0(1 + \alpha t)$ 或利用 $R_{100}/R_0$

**🔍 详细解答：**

**精确计算：**

$$R_t = R_0(1 + At + Bt^2 + Ct^3)$$

其中 $R_0 = 100\Omega$，分度系数：
- $A = 4.289 \times 10^{-3} /℃$
- $B = -2.133 \times 10^{-7} /℃^2$
- $C = 1.233 \times 10^{-9} /℃^3$

代入 $t = 130$ 计算（精确值略）。

**近似估算方法一（线性近似）：**

$$R_t = R_0(1 + \alpha t) = 100 \times (1 + 0.00425 \times 130) = 155.25\ \Omega$$

**近似估算方法二（百度电阻比）：**

已知 $R_{100}/R_0 = 1.428$：

$$R_t = \frac{R_{100} - R_0}{100} \cdot t + R_0 = \frac{1.428 \times 100 - 100}{100} \times 130 + 100 = 155.64\ \Omega$$

> **答案：** 精确值通过完整公式计算，线性估算约为 **155.25Ω**，百度电阻比估算约为 **155.64Ω**。

**💡 易错点：** 铜电阻近似计算公式需注意 $\alpha$ 取值（0.00425），铂电阻不能用简单线性近似（非线性较明显）。

### 习题5：热电偶回路产生热电势的条件是什么？

**📚 前置知识：**
- 热电效应定义
- 接触电势和温差电势的成因

**🔍 详细解答：**

热电势存在必须同时满足两个条件：

1. **两种不同的金属材料**构成热电偶（若 $N_A=N_B$，$\sigma_A=\sigma_B$，则 $E_{AB}=0$）
2. **两端存在温差**（若 $T=T_0$，则 $E_{AB}=0$）

> 热电势大小与材料性质和两端温差有关，与导体粗细长短及接触面积无关。

### 常见易错点

1. ❌ 热电势与导体粗细长短有关 → ✅ **无关**，只与材料和温差有关
2. ❌ 同种材料可构成热电偶 → ✅ 必须**两种不同材料**
3. ❌ 指示值 + 冷端温度 = 真实温度 → ✅ 必须热电势相加后再**查表**
4. ❌ 热电阻不需要电源 → ✅ 热电阻**需要外加电源**，热电偶才是自发电
5. ❌ 三线制中导线电阻完全消除 → ✅ 仅在**对称电桥**（$R_1=R_2$）且**平衡状态**下消除
6. ❌ 铜电阻非线性严重 → ✅ 铜电阻**线性关系好**，铂电阻非线性
7. ❌ NTC 线性度好 → ✅ NTC **非线性严重**，这是其最大缺点
8. ❌ 补偿导线正负极可任意接 → ✅ 必须**正极接正极、负极接负极**
