## 第4页：Module 4 — PWM 驱动电机

### 内容

**上半部分（左）：课程知识回顾**

| 脉冲调制类型 | 调制参数 | 抗噪性 |
|:---:|:---:|:---:|
| PAM | 幅度 | ❌ 差 |
| **PWM** | **宽度** | ✅ 好 |
| PPM | 位置 | ✅ 好 |

> 📌 课程结论：PWM 比 PAM 更抗噪声，因为噪声对脉冲边沿位置的影响远小于对幅度的影响。

**上半部分（右）：PWM 核心公式**

$$V_{\text{avg}} = D \cdot V_{cc}, \quad D = \frac{t_{\text{on}}}{T}$$

**下半部分：在机械臂中的应用**

- PWM 波形图（占空比 25% / 50% / 75% 三张对比）
- 信号链：微控制器 → PWM 波 → H 桥功率放大 → 直流电机 → 关节转动
- 实际参数：$f_{\text{PWM}} = 20\text{kHz}$（人耳听不到），$V_{cc} = 24\text{V}$

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现 PAM/PWM/PPM 对比表 | 先回顾课程三种脉冲调制 |
| 2 | 高亮 PWM 行 | 强调"为什么选 PWM" |
| 3 | 弹出抗噪性原理 | "噪声改变幅度容易，改变边沿位置难" |
| 4 | 出现 PWM 公式 $V_{\text{avg}} = D \cdot V_{cc}$ | 核心公式 |
| 5 | 从左到右依次动画波形图 | 25% → 50% → 75%，占空比增大、电机转更快 |
| 6 | 出现信号链框图 | 从微控制器到关节转动的完整链路 |

### 讲稿要点
> "Module 4 讲了三种脉冲调制。PAM 调幅度——噪声一叠加，幅度就变了。PWM 调宽度——噪声很难把脉冲边沿移走。所以在电机驱动里，PWM 是绝对主流。$V_{\text{avg}} = D \cdot V_{cc}$：改变占空比，就改变了等效电压，电机转速随之变化。这就是机械臂每个关节运动的最底层原理。"

## 第5页：Module 6 — 编码器量化与精度链

### 内容

**上半部分：课程知识回顾**

量化过程示意（箭头流程）：

$$\text{连续角度 } [0°, 360°] \xrightarrow{\text{量化 } L=1024} \text{离散值 } \{0, 0.352°, 0.703°, \ldots\}$$

量化关键公式：

$$\Delta = \frac{V_{\max} - V_{\min}}{L}$$

$$\sigma_e^2 = \frac{\Delta^2}{12} \quad \text{（量化噪声功率）}$$

$$\text{SQNR}_{\text{dB}} = 6.02n + 1.76 \quad \text{（$n$ 位量化）}$$

**下半部分：精度传播链（重点动画）**

量化误差如何影响末端定位？

$$\sigma_e^2 = \frac{\Delta^2}{12} \quad\xrightarrow{\text{关节空间}}\quad \Sigma_{\theta} = \begin{bmatrix} \sigma_e^2 & 0 \\ 0 & \sigma_e^2 \end{bmatrix}$$

$$\xrightarrow{\text{雅可比传播}}\quad \Sigma_{\text{末端}} = J \, \Sigma_{\theta} \, J^T$$

- 数值示例：1024 线编码器 → $\Delta = 0.352°$ → 经 0.5m 连杆放大 → 末端误差 ≈ 3.1mm
- 要达到 ±0.1mm 精度 → 需要至少 32768 线编码器（15 位）

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现连续角度条，标注"∞ 种可能" | 模拟量 |
| 2 | 离散化动画：角度条切成 1024 格 | 直观展示量化 |
| 3 | 弹出 $\Delta = 360°/1024$ | 量化步长 |
| 4 | 弹出 $\sigma_e^2 = \Delta^2/12$ | 量化噪声公式推导（均匀分布→方差） |
| 5 | 出现机械臂简图，关节处标注 $\sigma_e$ | 误差源 |
| 6 | **动画传播**：关节误差沿连杆放大到末端 | 误差传播 |
| 7 | 弹出 $\Sigma_{\text{末端}} = J \Sigma_{\theta} J^T$ | 雅可比传播公式 |
| 8 | 反推计算：要达到 0.1mm → 需要多少线 | 工程反推 |

### 讲稿要点
> "Module 6 讲了量化的核心公式 $\sigma_e^2 = \Delta^2/12$。编码器本质上就是一个角度量化器——1024 线编码器的量化步长是 0.352°。这个量化误差不会停留在关节处——它通过运动学雅可比矩阵传播到末端，被连杆长度放大。从 $\Delta^2/12$ 出发，可以反推出要达到 ±0.1mm 末端精度需要多少线的编码器——这就是理论指导硬件选型的例子。"

## 第6页：Module 5 — IMU 采样与抗混叠

### 内容

**上半部分（左）：奈奎斯特采样定理**

$$x[n] = x(nT_s), \quad f_s = \frac{1}{T_s}$$

> **奈奎斯特条件**：$f_s \geq 2f_{\max}$

采样后频谱：

$$X_s(f) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(f - kf_s)$$

**上半部分（右）：混叠示意动画区域**

频域图：基带频谱 $X(f)$ 以 $f_s$ 为周期复制。
- $f_s \geq 2f_{\max}$：各副本不重叠 → ✅ 可完美重建
- $f_s < 2f_{\max}$：副本重叠 → ❌ 混叠→不可逆失真

**下半部分：在机械臂中的应用**

- IMU 信号链：加速度计 → 模拟低通滤波（$f_c = 100\text{Hz}$）→ ADC 采样（$f_s = 200\text{Hz}$）→ 数字信号
- 机械臂运动频率：0-50Hz，$200 > 2 \times 50 = 100$ ✓
- 危险：电机 PWM 开关噪声 ≈ 20kHz，若不加抗混叠滤波器 → 混叠进低频 → 姿态估计漂移

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现连续正弦波 | "这是模拟信号" |
| 2 | 出现采样点（间距 $T_s$），标注 $x[n] = x(nT_s)$ | 采样过程 |
| 3 | 频谱动画：基带频谱 $X(f)$ 在原点 | 原始频谱 |
| 4 | **关键动画**：以 $f_s$ 为周期复制 $X(f)$ | 展示 $X_s(f) = \frac{1}{T_s}\sum X(f - kf_s)$ |
| 5 | 场景 A：$f_s$ 大 → 副本分离 → 绿色 ✓ | 满足奈奎斯特 |
| 6 | 场景 B：$f_s$ 小 → 副本重叠 → 红色 ✗ | 混叠发生 |
| 7 | 出现 IMU 信号链框图 | 实际系统中的抗混叠滤波器位置 |
| 8 | 标注 $f_s=200\text{Hz}, f_{\max}=50\text{Hz}$ | 具体参数 |

### 讲稿要点
> "Module 5 告诉我们：$f_s$ 必须 ≥ $2f_{\max}$。IMU 以 200Hz 采样 50Hz 的运动信号——满足条件。但为什么前面还要加模拟低通滤波器？因为电机的 PWM 开关噪声高达 20kHz，如果不先滤掉，它会被频谱周期延拓'折叠'到低频段——这就是混叠。混叠一旦发生，是不可逆的。所以抗混叠滤波器是在采样前必须做的一道防线。"

## 第8页：Module 3 — 冲激响应与电机系统辨识

### 内容

**上半部分：课程知识回顾——冲激响应与卷积**

- **冲激响应** $h(t)$ = 输入 $\delta(t)$ 时的输出（完全表征线性系统）
- **卷积**：$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau) h(t-\tau) d\tau$
- **频域关系**：$Y(f) = X(f) \cdot H(f)$（卷积 → 乘法！）

> 📌 **正弦保真性**：正弦波是唯一经过线性系统后波形不变的信号 → 适合做测试信号

**下半部分（左）：时域系统辨识**
- 输入：短脉冲电压（近似 $\delta(t)$）
- 测量：转速响应 $h(t)$
- 展示：典型直流电机的 $h(t)$ 曲线（一阶惯性环节 $h(t) = K(1-e^{-t/\tau})$）

**下半部分（右）：频域系统辨识**
- 输入：扫频正弦波 $x(t) = A\sin(2\pi f t)$，$f$ 从 0.1Hz 扫到 500Hz
- 测量：每个频率的增益 $|H(f)|$ 和相移 $\angle H(f)$
- 展示：伯德图（波特图）——$|H(f)|$ 的 -3dB 点 = 带宽，峰值 = 谐振点

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现系统框图：$x(t)$ → [电机?] → $y(t)$ | 未知系统 |
| 2 | 输入 $\delta(t)$，输出 $h(t)$ 曲线 | 时域辨识 |
| 3 | 弹出 $y(t) = x(t) * h(t)$ | 卷积公式 |
| 4 | 傅里叶变换动画 → $Y(f) = X(f) \cdot H(f)$ | 频域乘法 |
| 5 | **关键**：出现"正弦波进去 → 正弦波出来（幅度相位不同）"动图 | 正弦保真性 |
| 6 | 扫频动画：频率从低到高，伯德图逐步画出 | 频域辨识 |
| 7 | 在伯德图上标注：-3dB 带宽、谐振峰 | 系统特征 |

### 讲稿要点
> "Module 3 的核心是：冲激响应 $h(t)$ 完全刻画了线性系统。对于电机，我们可以输入一个短脉冲，测转速响应——这就是系统辨识。课程还讲了'正弦保真性'——正弦波经过线性系统仍是正弦波，只是幅度和相位变了。这个性质太有用了——我们给电机扫频输入正弦波，测量每个频率的增益和相移，就能画出电机的伯德图。图上可以读出带宽和谐振点，然后设计精确的 PID 控制器。"

## 第9页：Module 1 — 傅里叶变换与振动故障诊断

### 内容

**上半部分：课程知识回顾**

傅里叶变换：

$$V(f) = \int_{-\infty}^{\infty} v(t) \, e^{-j2\pi ft} \, dt$$

> 📌 **时域 ⇄ 频域完全等价**——不丢失任何信息

Parseval 定理：

$$P = \frac{1}{T} \int_{-T/2}^{T/2} |v(t)|^2 dt = \sum_{n=-\infty}^{\infty} |c_n|^2$$

**下半部分（核心）：在振动监测中的应用**

- **左图**：正常关节的振动时域信号 + FFT 频谱（标注：基频 $f_0$ + 低次谐波）
- **右图**：故障关节的振动时域信号 + FFT 频谱（标注：啮合频率 $f_{\text{mesh}}$ 处出现异常峰值，轴承特征频率处出现边带）

对比关键指标：
- 正常：$P_{\text{mesh}} / P_{\text{total}} < 15\%$
- 预警：$P_{\text{mesh}} / P_{\text{total}} > 30\%$
- 报警：$P_{\text{mesh}} / P_{\text{total}} > 50\%$

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现时域振动波形（杂乱无章） | "时域看不出问题" |
| 2 | **FFT 变换动画**：时域波形旋转/变化为频域幅度谱 | 视觉化傅里叶变换 |
| 3 | 正常频谱：在基频和谐波处有峰 | 正常模式 |
| 4 | **对比动画**：故障频谱在 $f_{\text{mesh}}$ 处出现红色异常峰 | 异常检测 |
| 5 | 弹出 Parseval 定理公式，标注各谐波功率 | 量化故障程度 |
| 6 | 出现阈值条：绿 → 黄 → 红 | 三级预警 |
| 7 | 回到系统总览图，高亮此模块位置 | 收束 |

### 讲稿要点
> "傅里叶变换告诉我们：时域和频域是完全等价的，但有些信息在频域才看得清。关节振动信号在时域是一团乱麻——看不出问题。但 FFT 之后：正常关节的能量集中在基频和低次谐波；磨损关节的频谱在啮合频率处出现异常峰值。利用 Parseval 定理，量化啮合频率携带的功率占比，就能设定阈值实现非拆卸式故障预警——这相当于给机器人做'心电图'。"

## 第11页：Module 2 — 贝叶斯公式与多传感器融合

### 内容

**上半部分：贝叶斯公式回顾**

$$P(B_i|A) = \frac{P(A|B_i) \cdot P(B_i)}{P(A)} = \frac{P(A|B_i) \cdot P(B_i)}{\sum_j P(A|B_j) P(B_j)}$$

> 📌 **后验** = 似然 × 先验 / 证据

**中间部分：数学推导逻辑链——从贝叶斯到卡尔曼滤波**

| 步骤 | 数学 | 物理含义 |
|:--:|------|------|
| ① | $P(x_t \mid z_{1:t-1}) = \int P(x_t \mid x_{t-1}) \cdot P(x_{t-1} \mid z_{1:t-1}) \, dx_{t-1}$ | **预测**：根据运动模型推测位置（全概率公式） |
| ② | $P(x_t \mid z_{1:t}) = \eta \cdot P(z_t \mid x_t) \cdot P(x_t \mid z_{1:t-1})$ | **更新**：根据传感器观测修正信念（贝叶斯公式） |

**加高斯假设 → 卡尔曼滤波**：

$$\hat{x}_{t|t-1} = F \hat{x}_{t-1} \quad \text{（预测）}$$
$$\hat{x}_t = \hat{x}_{t|t-1} + K_t(z_t - H\hat{x}_{t|t-1}) \quad \text{（更新）}$$

**下半部分：在机械臂中的应用**

- 三个传感器源 → 一个卡尔曼滤波器 → 最优状态估计
  - IMU（200Hz，快但漂移）
  - 编码器（100Hz，准但只测关节）
  - 摄像头（30Hz，全局但慢）
- 可视化：不确定椭圆从大面积逐步收敛到小点

## 第12页：Module 7 — 贝叶斯决策与障碍物分类

### 内容

**上半部分：课程知识回顾——判决理论**

二元假设检验：
- $H_0$：不是目标 vs $H_1$：是目标
- 虚警：$P(e|H_0) = Q\left(\frac{V_T - \mu_0}{\sigma}\right)$
- 漏检：$P(e|H_1) = Q\left(\frac{\mu_1 - V_T}{\sigma}\right)$

MAP 准则（等代价）：

$$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0)}{P(H_1)}$$

**中间部分：代价敏感扩展**

| | 判为"不是目标" | 判为"是目标" |
|---|:---:|:---:|
| 实际不是 | $C_{00}=0$ | $C_{01}=10$（虚警：白抓一次） |
| **实际是** | $\mathbf{C_{10}=1000}$（**漏检：放走目标！**） | $C_{11}=0$ |

$$C_{10} \gg C_{01} \quad\Rightarrow\quad \text{阈值左移，"宁可错抓不可放过"}$$

$$\frac{P(r|H_1)}{P(r|H_0)} \gtrless \frac{P(H_0) \cdot (C_{10} - C_{00})}{P(H_1) \cdot (C_{01} - C_{11})}$$

**下半部分：在机械臂中的应用**

- 摄像头提取物体特征 $r$（颜色直方图、形状矩、面积等）
- $P(r|H_0)$ 和 $P(r|H_1)$ 两个条件分布重叠区域
- **代价敏感阈值** 比 MAP 阈值更靠左 → 宁可虚警多抓一次，也不能漏掉目标

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 两个高斯分布 $P(r|H_0)$ 和 $P(r|H_1)$ 重叠 | 不确定性的来源 |
| 2 | 标注重叠区域 = 可能犯错的区域 | |
| 3 | 垂直线 = MAP 阈值 $V_T$，左右标注"虚警区域"和"漏检区域" | MAP 准则 |
| 4 | 弹出 BER 公式 $Q(\frac{\mu_1-\mu_0}{2\sigma})$ | 等代价总错误率 |
| 5 | **关键动画**：代价矩阵出现 → 阈值向左移动 | 代价敏感 |
| 6 | 标注移动后：虚警区域变大、漏检区域变小 | 代价驱动的决策 |
| 7 | 弹出最小风险贝叶斯决策公式 | 完整公式 |
| 8 | 传送到实际场景：机械臂抓取画面 | 应用 |

### 讲稿要点
> "Module 7 讲了判决理论：给定观测值 $r$，判断是 $H_0$ 还是 $H_1$。在流水线上，$H_0$ = 不是目标物体，$H_1$ = 是目标物体。但这里有个关键问题——两类错误的代价不一样。漏检意味着目标物体溜走了——这是绝对不能接受的。虚警只是多抓了一次——可以接受。所以引入代价矩阵，$C_{10}$ 远大于 $C_{01}$，这会让决策阈值向'宁可错抓不可放过'的方向偏移。最小化期望代价，而不是最小化错误率——这就是代价敏感的贝叶斯决策。"

## 第14页：Module 8 — 交叉熵与深度学习物体识别

### 内容

**上半部分：熵的知识链（逐步推导）**

$$h(x) = -\log_2 p(x) \quad \text{（香农信息量）}$$

$$\downarrow \text{取期望}$$

$$H(X) = -\sum_x p(x) \log_2 p(x) \quad \text{（熵：平均不确定性）}$$

$$\downarrow \text{用 Q 替代 P}$$

$$H(P, Q) = -\sum_x p(x) \log_2 q(x) \quad \text{（交叉熵：P 与 Q 的差异）}$$

$$\downarrow \text{减去 H(P)}$$

$$D_{KL}(P\|Q) = H(P, Q) - H(P) = \sum_x p(x) \log\frac{p(x)}{q(x)} \quad \text{（KL 散度）}$$

> 🔑 **Gibbs 不等式**：$D_{KL}(P\|Q) \geq 0$，当且仅当 $P=Q$ 时取等号

**下半部分：在深度学习物体识别中的应用**

- CNN 网络结构简图：输入图像 → 卷积层 → 全连接层 → Softmax → 输出 $\mathbf{q} = [q_1, q_2, \ldots, q_C]$
- 交叉熵损失函数：

$$L = -\sum_{c=1}^{C} p_c \log q_c$$

- **训练时**：真实标签 $\mathbf{p}$ = one-hot（如 $[1,0,0,0,0]$ = "螺丝"）
- **推理时**：$\mathbf{q}$ = softmax 输出（如 $[0.92, 0.03, 0.02, 0.02, 0.01]$ → 判为"螺丝"）
- 为何有效：最小化 $L$ = 最小化 $D_{KL}(P\|Q)$ → 预测分布逼近真实分布

### 动画脚本

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现 $h(x) = -\log_2 p(x)$（单个事件的信息量） | 起点 |
| 2 | 向下展开：取期望 → $H(X) = -\sum p\log p$ | 熵 |
| 3 | 向下展开：代入预测分布 → $H(P,Q) = -\sum p\log q$ | 交叉熵 |
| 4 | 向下展开：减 $H(P)$ → $D_{KL} = H(P,Q)-H(P)$ | KL 散度 |
| 5 | 四个公式并排展示，用箭头串联 | 完整知识链 |
| 6 | 出现 CNN 网络结构图 | 网络结构 |
| 7 | Softmax 输出 5 个概率条，标注 $\mathbf{q}$ | 预测分布 |
| 8 | **对比动画**：真实 one-hot $\mathbf{p}$ vs 预测 $\mathbf{q}$，交叉熵 = 差异 | 损失函数 |
| 9 | 训练过程动图：损失下降，$\mathbf{q}$ 逼近 $\mathbf{p}$ | 训练收敛 |

### 讲稿要点
> "从香农信息量到交叉熵，是一条非常优美的数学链条。$h(x) = -\log p$ 衡量单个事件的惊讶程度。取期望就是熵——平均不确定性。把真实分布 $p$ 换成预测分布 $q$，就是交叉熵——衡量真实标签和预测标签的差异。再减去 $H(P)$ 就是 KL 散度。当真实分布固定时，最小化交叉熵就等价于最小化 KL 散度——让神经网络的预测分布尽可能逼近真实分布。这就是为什么所有分类网络都用交叉熵做损失函数。在机械臂分拣中，CNN 识别出物体类别后，传给机械臂执行对应的抓取动作。"

## 第15页：Module 9 — 汉明码与遥操作可靠通信

### 内容

**上半部分：课程知识回顾——汉明 (7,4) 码**

编码规则：$\mathbf{t} = [s_1, s_2, s_3, s_4, t_5, t_6, t_7]$

三个校验方程（圆模型）：
- 圆 A：$t_1 \oplus t_2 \oplus t_3 \oplus t_5 = 0$
- 圆 B：$t_1 \oplus t_2 \oplus t_4 \oplus t_6 = 0$
- 圆 C：$t_1 \oplus t_3 \oplus t_4 \oplus t_7 = 0$

**关键参数**：
- 最小汉明距离 $d_{\min} = 3$
- 可纠正 $\lfloor (3-1)/2 \rfloor = 1$ 个比特错误
- 可检测 $3-1 = 2$ 个比特错误
- 码率 $R = 4/7 \approx 57\%$

**下半部分（左）：编码过程示例**

发送控制指令"抓取"（$s=[0,0,1,1]$）：
- 计算校验位 → $\mathbf{t} = [0,0,1,1,0,1,0]$
- 经含噪信道传输 → 接收 $\mathbf{r} = [0,0,1,1,1,1,0]$（第5位翻转）
- 计算伴随式：$\mathbf{s} = \mathbf{r}H^T = [1,0,1]$ → 定位第5位错误 → 翻转 → 正确译码 $[0,0,1,1]$ → 执行"抓取"

**下半部分（右）：应用场景**

| 场景 | 误码率 | 没有纠错码 | 有汉明 (7,4) 码 |
|------|:---:|------|------|
| 工业 WiFi | $10^{-4}$ | 每万条指令错1条 | ✅ 单比特误码可纠正 |
| 水下声学 | $10^{-3}$ | 每千条指令错1条 | ✅ 可纠正单比特错 |
| 太空通信 | $10^{-5}$ | 低但不可接受 | ✅ 增加安全保障 |

> 📌 以 43% 带宽换取单比特纠错能力——对安全性要求极高的场景，这是必要的代价。

| 序号 | 动画 | 说明 |
|:--:|------|------|
| 1 | 出现 4 个信源比特 + 3 个校验位位置（空位） | 编码前 |
| 2 | 三个圆逐一出现，覆盖对应比特，标注异或=0 | 校验方程 |
| 3 | 比特填充动画：4 个数据位 + 自动计算 3 个校验位 | 编码完成 |
| 4 | 传输动画：比特流经过"噪声云" | 信道 |

| 7 | 出现码率 $R=4/7$，标注"以带宽换可靠性" | 代价 |

### 讲稿要点
> "Module 9 的核心是：添加冗余换取可靠性。汉明 (7,4) 码把 4 位控制指令编码为 7 位——多出来的 3 位是校验位。$d_{\min}=3$ 意味着任意两个合法码字至少差 3 位，所以翻转 1 位一定能被发现并纠正。伴随式译码就像侦探破案——根据'哪些圆校验失败了'来定位'哪个比特出错了'。码率 57% 意味着用 43% 的额外带宽换取了单比特纠错能力。在水下机器人、太空机械臂这些不容有失的场景中，这是必要的代价。"

```
  ↓ 预测步（全概率）
  P(x_t|z_{1:t-1}) = ∫ P(x_t|x_{t-1}) P(x_{t-1}|z_{1:t-1}) dx_{t-1}
  ↓ 更新步（贝叶斯）
  P(x_t|z_{1:t}) ∝ P(z_t|x_t) · P(x_t|z_{1:t-1})
  ↓ 得到最优状态
贝叶斯决策（物体分类）:
  P(r|H_1)/P(r|H_0) ≷ P(H_0)(C_{10}-C_{00}) / P(H_1)(C_{01}-C_{11})
  ↓ 代价敏感最优决策
```

## 链 4：熵 → 交叉熵 → KL 散度（智能层核心推导）

```
Step 1: 香农信息量
  h(x) = -log₂ p(x)
  含义：单个事件的"惊讶程度"

Step 2: 熵（期望信息量）
  H(X) = Σ p(x) · h(x) = -Σ p(x) log₂ p(x)
  含义：随机变量的平均不确定性
  范围：0 ≤ H(X) ≤ log₂ I

Step 3: 交叉熵
  H(P,Q) = -Σ p(x) log₂ q(x)
  含义：用分布 Q 来编码分布 P 所需的平均比特数
  关键：H(P,Q) ≥ H(P)，当 P=Q 时取等

Step 4: KL 散度
  D_KL(P||Q) = H(P,Q) - H(P) = Σ p(x) log(p(x)/q(x))
  含义：P 和 Q 之间的"距离"（不对称）
  Gibbs 不等式：D_KL ≥ 0

Step 5: 应用到深度学习
  L = H(P,Q) = -Σ p_c log q_c （交叉熵损失函数）
  训练目标：min L ⇔ min D_KL(P||Q)
  因为 H(P) 固定（真实标签的熵是常数）
  所以最小化交叉熵 = 让预测分布 Q 逼近真实分布 P
```

## 链 5：汉明码纠错（可靠通信）

```
编码:
  s = [s₁,s₂,s₃,s₄] （4 位信源）
  → t = [s₁,s₂,s₃,s₄, t₅,t₆,t₇] （7 位码字）
  校验方程：三圆异或 = 0
  d_min = 3

传输:
  t → [含噪信道] → r = t ⊕ e（e 是错误图样）

译码（伴随式）:
  s = rH^T
  若 s = [0,0,0] → 无误
  若 s ≠ 0 → 查表定位错误位置 → 翻转纠错

性能:
  可纠 ⌊(d_min-1)/2⌋ = 1 个错误
  可检 d_min-1 = 2 个错误
  码率 R = k/n = 4/7 ≈ 57%
```
