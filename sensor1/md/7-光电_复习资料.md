## 第一部分：知识梳理

### 第1章 光电式传感器概述

#### 1.1 基本概念

**光电传感器**是光电检测系统中实现光电转换的关键元件，把光信号（红外、可见及紫外光辐射）转变为电信号。

- **基本原理**：以**光电效应**为基础，把被测量的变化转换成光信号的变化，再借助光电元件将非电信号转换成电信号。
- **可检测量**：直接引起光量变化的非电量（光强、光照度、辐射测温等），以及能转换成光量变化的非电量（应变、位移、振动、速度等）。
- **优点**：精度高、反应快、**非接触**。

#### 1.2 光电效应

**⭐ 重点：光电效应定义与分类**

光电效应是指物体吸收了光能后转换为该物体中某些电子的能量，从而产生的电效应。

光子能量公式：
$$E = h\nu$$

其中 $h = 6.626 \times 10^{-34}$ J·s（普朗克常数），$\nu$ 为光的频率。

> 光的波长越短（频率越高），光子能量越大；波长越长，光子能量越小。

### 第2章 外光电效应

#### 2.1 定义与原理

**⭐ 重点：外光电效应**

在光线作用下，物体内电子**逸出物体表面**向外发射的现象称为外光电效应。向外发射的电子叫做**光电子**。

**爱因斯坦光电效应方程：**
$$h\nu = \frac{1}{2}mv_0^2 + A_0$$

| 符号 | 含义 |
|------|------|
| $h\nu$ | 光子能量 |
| $\frac{1}{2}mv_0^2$ | 逸出电子的动能 |
| $A_0$ | 表面逸出功 |
| $m$ | 电子质量 |
| $v_0$ | 电子逸出速度 |

**核心结论：**
- 一个电子只能接受**一个光子**的能量
- 光子能量必须**大于**物体表面逸出功 $A_0$，电子才能逸出
- **红限频率（波长限）**：每个物体都有一个对应的光频阈值。频率低于红限频率，光强再大也不产生光电子；频率高于红限，即使光线微弱也有光电子射出
- 外光电效应多发生于**金属和金属氧化物**
- 响应时间不超过 $10^{-9}$s
- 入射光频谱成分不变时，产生的光电子与光强**成正比**
- 即使不加初始阳极电压，也会有光电流产生，使光电流为零须加**负的截止电压**

**基于外光电效应的器件：** 光电管、光电倍增管。

### 第3章 内光电效应

#### 3.1 定义与分类

**⭐ 重点：内光电效应**

光照射物体使电阻率 $\rho$ 发生变化或产生光生电动势的现象，多发生于**半导体**内。

| 类型 | 定义 | 典型器件 |
|------|------|----------|
| **光电导效应** | 光子能量 $\geq$ 禁带宽度 → 激发出电子-空穴对 → 载流子浓度增加 → 导电性增加、阻值降低 | 光敏电阻 |
| **光生伏特效应** | 光线作用下使物体产生一定方向电动势 | 光电池 |

### 第4章 光敏电阻

#### 4.1 结构与原理

光敏电阻又称光导管，几乎全部用半导体材料制成（CdS、PbS、InSb 等）。**没有极性**，纯电阻器件，可加直流或交流电压。

工作原理基于**光电导效应**：阻值随光照增强而**减小**。

| 参数 | 定义 | 期望值 |
|------|------|:------:|
| **暗电阻** | 不受光照时的阻值 | 越大越好（兆欧量级） |
| **暗电流** | 暗电阻时流过的电流 | 越小越好 |
| **亮电阻** | 受光照时的阻值 | 越小越好（几千欧以下） |
| **亮电流** | 亮电阻时流过的电流 | 越大越好 |
| **光电流** | 亮电流 − 暗电流 | 越大越好 |

> 暗电阻与亮电阻之比在 $10^2 \sim 10^6$ 之间，灵敏度很高。

**结构特点：**
- 玻璃底板上均匀涂一层半导体光导层
- 两端金属电极（梳状图案以提高灵敏度）
- 覆盖漆膜保护（在敏感波长范围内透射率最大）
- 存在照射光波长限 $\lambda_c$，只有 $\lambda < \lambda_c$ 的光才能使电导率增加

#### 4.2 光敏电阻特性

**⭐ 重点：四大特性**

| 特性 | 说明 |
|------|------|
| **(1) 伏安特性** | 一定电压范围内 $I$-$U$ 为直线；阻值与入射光量有关，与电压电流无关 |
| **(2) 光照特性** | 光电流与光照强度的关系，绝大多数**非线性**（不同材料特性不同） |
| **(3) 光谱特性** | 对不同波长入射光有不同灵敏度，具有**选择作用**；不同材料光谱响应曲线不同 |
| **(4) 优点** | 灵敏度高、光谱响应范围宽、体积小、重量轻、机械强度高、耐冲击振动、抗过载能力强、寿命长 |

> **不足：** 需要外部电源，有电流时会发热。

### 第5章 光电池

#### 5.1 工作原理

光电池是将光能直接转换为电能的光电器件，基于**光生伏特效应**。有光线作用时本身就是电源，**不需要外加电源**。

**硅光电池原理（大面积 PN 结）：**
1. 光子能量 > 禁带宽度 → P 型区每吸收一个光子产生一对电子-空穴
2. 电子-空穴对从表面向内扩散
3. 在 PN 结内电场作用下分离：N 区光生空穴拉向 P 区，P 区光生电子拉向 N 区
4. N 区聚集负电荷，P 区聚集正电荷 → 产生电动势
5. 外电路连接时，电流方向：P 区 → 外电路 → N 区

#### 5.2 光电池特性

**⭐ 重点：四大特性**

| 特性 | 说明 |
|------|------|
| **(1) 光谱特性** | 不同材料光谱响应峰值对应的入射光波长不同（硅 vs 硒） |
| **(2) 光照特性** | **短路电流**在很大范围内与光照强度呈**线性关系**；**开路电压**与光照度是**非线性**，2000 lx 时趋于饱和 → 作测量元件应**当作电流源使用**，不宜作电压源 |
| **(3) 频率特性** | 硅光电池有较好的频率响应 |
| **(4) 温度特性** | 开路电压随温度升高**快速下降**；短路电流随温度升高**缓慢增加** → 作测量元件最好恒温或温度补偿 |

#### 5.3 转换效率及最佳负载匹配

**转换效率：** 最大输出电功率与输入光功率的比值。硅光电池理论值最大 24%，实际 10%~15%。

**最佳负载电阻 $R_j$：** 在某一负载电阻下得到最大输出功率 $P_j = I_j U_j$。

> $R_j$ 随辐射照度增强而稍微减小。每个光电池的最佳负载线不是一条，而是一簇。

### 第6章 光敏二极管与光敏晶体管

#### 6.1 光敏二极管

- PN 结装在管顶部，可直接受光照射
- 电路中处于**反向工作状态**
- 无光照：反向电阻很大，反向电流很小（**暗电流**）→ 截止状态
- 有光照：在 PN 结附近产生光生电子-空穴对，内电场作用下形成**光电流** → 导通状态
- 光照度越大，光电流越大

#### 6.2 光敏晶体管

- 具有两个 PN 结，发射极做得很大以扩大光照面积
- 大多数基极无引出线
- 光照射集电结 → 产生电子-空穴对 → 光生电子拉到集电极，基区留下空穴 → 基极-发射极电压升高 → 大量电子流向集电极
- 集电极电流被放大 **$\beta+1$ 倍**，具有放大作用

#### 6.3 光敏管特性

**⭐ 重点：四大特性**

| 特性 | 说明 |
|------|------|
| **(1) 光谱特性** | 硅峰值波长约 $0.9\mu\text{m}$，锗峰值波长约 $1.5\mu\text{m}$；波长增长或缩短时相对灵敏度都下降 |
| **(2) 伏安特性** | 不同照度下曲线几乎平行，未达饱和值时输出不受偏压影响；光敏晶体管在同样照度下光电流比二极管**大上百倍**（放大作用） |
| **(3) 频率特性** | 光敏二极管频率特性是半导体光电器件中**最好**的（响应时间约 $10\mu\text{s}$）；光敏晶体管频率特性受负载电阻影响，减小负载电阻可提高频率响应 |
| **(4) 温度特性** | 温度对**光电流影响很小**，对**暗电流影响很大** → 需对暗电流进行温度补偿 |

### 第7章 光电耦合器件

#### 7.1 光电耦合器

由发光元件和光电传感器封装在同一外壳内的转换元件。

- **发光器件**：砷化镓发光二极管（正向电压增大 → 正向电流增加 → 光通量增加）
- **接收器件**：光敏二极管、光敏三极管、达林顿光敏管
- **关键要求**：发光元件和接收元件的**波长匹配**

#### 7.2 光电开关

利用感光元件对变化的入射光进行接收、光电转换、放大和控制，获得"开""关"信号。

**⭐ 重点：两种类型**

| 类型 | 光轴关系 | 检测原理 |
|------|----------|----------|
| **透射式** | 发光元件和接收元件光轴**重合** | 不透明物体阻断光路 → 检测 |
| **反射式** | 光轴在同一平面以某角度**相交**（交点即待测物处） | 物体表面反射光被接收 → 检测 |

**特点：** 小型、高速、非接触，与 TTL、MOS 等电路容易结合。

**应用：** 物体检测、产品计数、料位检测、尺寸控制、安全报警、计算机输入接口。

### 第8章 光电传感器应用

#### 8.1 四种基本形式

| 形式 | 说明 |
|------|------|
| 透射式 | 被测物位于光路中，遮挡光路 |
| 反射式 | 被测物反射光线 |
| 遮光式 | 被测物自身遮挡光线 |
| 辐射式 | 被测物自身发光 |

#### 8.2 典型应用

- **光电浊度计**：测量液体浊度
- **无线烟雾报警器**：烟雾遮挡光线触发报警
- **光电脉冲传感器**：通断开关状态，测量线位移、线速度、角位移、角速度（转速）
- **光电转速计**：利用脉冲计数测量转速

### 第9章 光纤传感器

#### 9.1 概述

光纤传感器是 20 世纪 70 年代中期发展的新技术。

**与传统传感器相比的优点：**
- 不受电磁干扰，高绝缘强度
- 体积小、重量轻、可绕曲、非侵入式
- 灵敏度高、耐腐蚀、防爆性好
- **集传感与传输于一体**，能与数字通信系统兼容

#### 9.2 光纤结构

| 组成部分 | 说明 |
|----------|------|
| **纤芯** | 中心圆柱体，光主要在此传输，折射率 $n_1$ |
| **包层** | 围绕纤芯的圆形外层，折射率 $n_2$（$n_1 > n_2$） |
| **保护套** | 多为尼龙材料，增加机械强度 |

> 纤芯和包层通常由不同掺杂的石英玻璃制成。光纤的导光能力取决于纤芯和包层的性质。

#### 9.3 光纤传光原理

**⭐ 重点：基于光的全内反射**

**斯涅耳定理（Snell's Law）：**
$$n_1\sin\theta_i = n_2\sin\theta_r$$

当 $n_1 > n_2$ 时，$\theta_r > \theta_i$。入射角增大到一定程度时产生**全反射**。

**光纤传光过程：**
1. 光线以 $\theta_i$ 角射入光纤端面 → 折射进入光纤
2. 以 $\varphi_i$ 角入射至纤芯与包层界面
3. 当 $\theta_i$ 小于临界角 $\theta_c$ 时，光线在界面上反复全反射
4. 呈锯齿波形在纤芯内向前传播，最后从另一端面射出

**临界入射角（空气中 $n_0=1$）：**
$$\theta_i \leq \theta_c = \arcsin\sqrt{n_1^2 - n_2^2}$$

> 只要满足全反射条件，即使光纤弯曲，光线仍能继续传播。

#### 9.4 数值孔径（NA）

**⭐ 重点：数值孔径是表征光纤集光本领的重要参数**

**定义：**
$$NA = \sin\theta_c = \frac{1}{n_0}\sqrt{n_1^2 - n_2^2}$$

空气中 $n_0=1$：
$$NA = \sqrt{n_1^2 - n_2^2}$$

| 要点 | 说明 |
|------|------|
| 含义 | 只有入射角处于 $2\theta_c$ 光椎角内，光纤才能导光 |
| NA 越大 | 集光能力越强，耦合效率越高 |
| NA 过大 | 造成光信号畸变 |
| 石英光纤典型值 | $0.2 \sim 0.4$ |

#### 9.5 光纤传感器结构原理

传统传感器 vs 光纤传感器：
- 传统：以**机—电测量**为基础，电源/敏感元件/信号处理/传输均用金属导线
- 光纤：以**光学测量**为基础，由光发送器、敏感元件、光接收器、信号处理系统及光纤构成

**调制原理：** 光的强度、偏振态（矢量 A 的方向）、频率和相位等参量之一随被测量变化。通过对光的**强度调制、偏振调制、频率调制或相位调制**进行解调，获得被测量信息。

#### 9.6 光纤传感器分类

**⭐ 重点：功能型 vs 非功能型**

| 类型 | 缩写 | 光纤作用 | 别名 |
|------|:----:|----------|------|
| **功能型** | FF | 光纤本身是敏感元件 | 传感型传感器 |
| **非功能型** | NFF | 光纤仅传输光，端面/中间加装其他敏感元件 | 传光型传感器 |

> 非功能型品种多、制作应用容易；功能型构思巧妙，可解决棘手问题。

**四种调制形式：**

| 调制类型 | 原理 | 典型应用 | 优缺点 |
|----------|------|----------|--------|
| **强度调制** | 被测对象引起折射/吸收/反射等参数变化 → 光强度变化 | 压力、振动、温度、位移、气体 | 结构简单、成本低；受光源波动影响大 |
| **偏振调制** | 光的偏振态变化传递信息（法拉第效应、泡尔效应、光弹效应） | 电流、磁场、电场、电压、压力 | 避免光源强度变化影响，灵敏度高 |
| **频率调制** | 光频率变化（多普勒效应、喇曼散射） | 速度、流速、振动、气体浓度 | 精度高 |
| **相位调制** | 折射率或传播常数变化 → 光相位变化 → 干涉仪检测 | 声、压力、振动、电流、磁场、光纤陀螺 | 灵敏度最高；需特殊光纤，成本高 |

#### 9.7 光纤传感器主要元件

| 元件 | 类型 | 特点 |
|------|------|------|
| **光纤** | 阶跃型/梯度型多模及单模 | 传感器用光纤 NA：$0.2 \sim 0.4$；传输损耗 $<10$ dB/km；放宽色散要求；要求高强度 |
| **光源** | 白炽灯 | 价廉、使用方便；稳定性差、寿命短 |
| | 气体激光器（氦氖） | 相干性好、单模、窄线宽、噪声小 |
| | 固体激光器 | 体积小、坚固耐用、高功率 |
| | 半导体激光器（LED/LD） | 体积小巧、寿命长（$10^6\sim10^7$h）、可靠性高 |
| **检测器** | PIN 光电二极管 | 常用 |
| | 雪崩式光电二极管（APD） | 本身具有增益，但有过剩噪声 |
| | 光电倍增管 | 倍增过程可很好控制，无过剩噪声 |

#### 9.8 光纤传感器应用

| 传感器类型 | 原理 |
|------------|------|
| **光纤加速度传感器** | 简谐振子结构，质量块 M 对光纤拉伸 → 光程差改变 → 干涉效应 → 测加速度 |
| **光纤温度传感器** | 半导体光吸收器对光的吸收随温度变化；可做单端式探头（反射式，体积小） |
| **光纤压力传感器** | 弹性元件受压变形 → 膜片反射式（Y 形光纤束 + 感压膜片） |
| **光纤漩涡流量传感器** | 多模光纤垂直装入管道，流体涡流使光纤振动，频率与流速有关 |

## 第二部分：习题精讲

### 习题1：试计算 $n_1 = 1.46$，$n_2 = 1.45$ 的阶跃折射率光纤的数值孔径值。如果外部媒质为空气（$n_0 = 1$），问该种光纤的最大入射角是多少？

**📚 前置知识：**
- 数值孔径定义：$NA = \sin\theta_c = \dfrac{1}{n_0}\sqrt{n_1^2 - n_2^2}$
- 光纤全内反射条件
- 空气中 $n_0=1$

**🔍 详细解答：**

根据光纤数值孔径 $NA$ 定义（空气中 $n_0=1$）：

$$NA = \sin\theta_{i0} = \sqrt{n_1^2 - n_2^2} = \sqrt{1.46^2 - 1.45^2}$$

$$= \sqrt{2.1316 - 2.1025} = \sqrt{0.0291} = 0.1706$$

最大入射角：

$$\theta_{i0} = \arcsin(0.1706) = 9.8^\circ$$

> **答案：** 数值孔径 $NA = 0.1706$，最大入射角为 **$9.8^\circ$**。入射光线必须与光纤轴线夹角小于 $9.8^\circ$ 才能传输通过。

**💡 易错点：** 公式记混为 $NA = n_1/n_2$ 或 $\sqrt{n_2^2 - n_1^2}$。正确答案是 $\sqrt{n_1^2 - n_2^2}$（$n_1 > n_2$）。

### 习题2：简述外光电效应和内光电效应的区别，并各举两种典型器件。

**📚 前置知识：**
- 外光电效应：电子逸出物体表面
- 内光电效应：电阻率变化或产生光生电动势（电子不逸出）
- 爱因斯坦光电效应方程

**🔍 详细解答：**

| 对比维度 | 外光电效应 | 内光电效应 |
|----------|-----------|-----------|
| 电子状态 | 电子**逸出物体表面** | 电子**不逸出**，在内部产生效应 |
| 发生材料 | 金属和金属氧化物 | 半导体 |
| 核心条件 | $h\nu > A_0$（逸出功） | $h\nu \geq$ 禁带宽度 |
| 红限频率 | 有（低于红限，光强再大也不发射） | 有（波长限 $\lambda_c$） |
| 子类 | — | 光电导效应 + 光生伏特效应 |
| 典型器件 | 光电管、光电倍增管 | 光敏电阻（光电导）、光电池（光生伏特） |

**💡 易错点：** 区分"逸出表面"（外光电）和"电阻率变化/产生电动势"（内光电）。

### 习题3：光电池作为测量元件时，为什么应把它当作电流源使用而不宜用作电压源？

**📚 前置知识：**
- 短路电流与光照度的线性关系
- 开路电压与光照度的非线性关系（2000 lx 时趋于饱和）

**🔍 详细解答：**

根据光电池的光照特性：
- **短路电流**（$R_L$ 很小时）：在很大范围内与光照强度呈**线性关系**
- **开路电压**（$R_L$ 无限大时）：与光照度关系是**非线性**的，且照度 2000 lx 时就**趋于饱和**

因此，将光电池作为测量元件时，应使其工作在接近短路状态（即当作**电流源**），以获得与光照强度成线性的输出。若作为电压源，非线性会带来严重测量误差。

**💡 易错点：** 记住"短路电流线性、开路电压非线性且饱和"，这是常考点。

### 习题4：比较光敏二极管和光敏晶体管的特点与区别。

**📚 前置知识：**
- 光敏二极管：反向偏置，PN 结受光产生光电流
- 光敏晶体管：两个 PN 结，具有放大作用

**🔍 详细解答：**

| 对比维度 | 光敏二极管 | 光敏晶体管 |
|----------|:--------:|:---------:|
| 结构 | 一个 PN 结 | 两个 PN 结，发射极大 |
| 工作状态 | **反向偏置** | 集电极加正压 |
| 放大倍数 | 无放大 | 放大 $\beta+1$ 倍 |
| 光电流大小 | 较小 | 比二极管**大上百倍** |
| 频率特性 | 半导体光电器件中**最好**（$\sim10\mu\text{s}$） | 受负载电阻影响 |
| 响应速度 | 快 | 较慢 |

### 习题5：功能型（FF）光纤传感器和非功能型（NFF）光纤传感器有何区别？

**📚 前置知识：**
- FF：光纤本身是敏感元件
- NFF：光纤仅传光，其他元件传感

**🔍 详细解答：**

| 对比维度 | 功能型（FF） | 非功能型（NFF） |
|----------|:----------:|:----------:|
| 光纤作用 | 既是传光元件又是**敏感元件** | 仅起**传输光**的作用 |
| 敏感元件 | 光纤本身 | 光纤端面或中间加装其他敏感元件 |
| 别名 | 传感型传感器 | 传光型传感器 |
| 制作难度 | 较高 | 较容易 |
| 品种数量 | 较少 | 较多 |
| 特点 | 构思巧妙，解决棘手问题 | 实用性强，应用广泛 |

### 核心公式汇总

| 公式 | 含义 |
|------|------|
| $E = h\nu$ | 光子能量 |
| $h\nu = \frac{1}{2}mv_0^2 + A_0$ | 爱因斯坦光电效应方程 |
| $n_1\sin\theta_i = n_2\sin\theta_r$ | 斯涅耳定理 |
| $NA = \dfrac{1}{n_0}\sqrt{n_1^2 - n_2^2}$ | 数值孔径 |
| $NA = \sqrt{n_1^2 - n_2^2}$（空气） | 数值孔径（$n_0=1$） |
| $\theta_c = \arcsin\sqrt{n_1^2 - n_2^2}$ | 临界入射角（空气） |

### 光电效应分类总表

```
光电效应
├── 外光电效应（电子逸出表面）
│   ├── 器件：光电管、光电倍增管
│   └── 条件：hν > A₀（红限频率）
│
└── 内光电效应（电子不逸出）
    ├── 光电导效应
    │   └── 器件：光敏电阻
    └── 光生伏特效应
        └── 器件：光电池
```

| 器件 | 暗电阻 | 亮电阻 | 工作状态 | 需外加电源 | 放大能力 |

### 常见易错点

1. ❌ 光电池需要外加电源 → ✅ 光电池是**自发电**器件，不需要外加电源
2. ❌ 开路电压与光照度呈线性关系 → ✅ **短路电流**线性，开路电压**非线性**且会饱和
3. ❌ $NA = \sqrt{n_2^2 - n_1^2}$ → ✅ $NA = \sqrt{n_1^2 - n_2^2}$（$n_1 > n_2$）
4. ❌ 低于红限频率但光强足够也能产生光电子 → ✅ 频率低于红限，**光强再大也不产生**光电子
5. ❌ 光敏电阻有极性 → ✅ 光敏电阻**没有极性**，纯电阻器件
6. ❌ 光敏晶体管无放大作用 → ✅ 集电极电流被放大 **$\beta+1$ 倍**
7. ❌ NFF 中光纤本身是敏感元件 → ✅ **FF（功能型）**才以光纤本身为敏感元件
8. ❌ 温度对光敏管光电流影响很大 → ✅ 温度对**暗电流**影响大，对光电流影响小
