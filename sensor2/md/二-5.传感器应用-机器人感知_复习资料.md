#### 1.1 激光雷达 SLAM 流程

**⭐ 重点：激光 SLAM 五步流程**

| 步骤 | 内容 | 说明 |
|:----:|------|------|
| ① 点云输入 | 三维激光雷达采集原始点云数据 | 输入数据 |
| ② 运动估计 | 帧间匹配估计传感器位姿变化，构建局部地图 | 前端 |

#### 1.2 基于激光雷达的物体检测

##### （1）VoxelNet

**⭐ 重点：端到端体素化 + 3D 卷积范式**

VoxelNet 开创了**体素化 + 3D 卷积**的端到端检测范式。

**三层网络结构：**

| 层 | 名称 | 功能 |
|:--:|------|------|
| ① | **特征提取层**（橙色） | 体素转换 → 分组与随机采样 → VFE（多层感知机+最大池化编码） |
| ② | **中间卷积层**（黄色） | 3D 卷积 + BN + ReLU，增大感受野，获取全局信息 |
| ③ | **RPN 层**（紫色） | 基于 Anchor 找到检测框和类别 |

**特征提取层三步骤：**
- **体素转换（Voxelization）**：将点云空间划分为规则三维体素网格（D×H×W）
- **分组与随机采样**：对每个体素内的点随机采样固定数量，保证输入一致性
- **多层体素特征编码（VFE）**：通过 MLP 和最大池化，将体素内点云特征编码为固定长度向量

##### （2）PointNet++

**⭐ 重点：分层点集特征学习**

PointNet 是深度学习应用于点云领域的**开创性方法**，使用具有**置换不变性**的对称函数（最大池化）解决点云无序性问题。PointNet++ 核心改进：在局部区域**重复性迭代使用 PointNet**。

**集合抽象层（Set Abstraction）三步骤：**

| 步骤 | 操作 | 说明 |
|:----:|------|------|
| ① 采样 | FPS（最远点采样）选出中心点 | 降低点云密度 |
| ② 分组 | 以中心点为圆心，半径内找邻近点 | 形成局部点集 |
| ③ PointNet | 对每个局部点集使用 PointNet | 提取局部特征 |

**下游任务：**
- **分类任务**：使用全局特征 + 全连接层
- **分割任务**：反卷积 + 跳跃连接 → 逐点分类

##### （3）后续发展

改进算法：SECOND、PIXOR、Point-RCNN 等。最新方向：**基于视图的方法与原始点云方法融合**（如 SIENet、Voxel R-CNN），用低分辨率 Voxel 提取上下文特征 + 原始点云结合。

#### 1.3 基于激光雷达的语义分割

**⭐ 重点：五类方法对比**

**定义：** 为点云中每个点分配语义标签（车辆/行人/道路/建筑物/树木），让机器人"看懂"环境。

| 方法类型 | 核心思路 | 代表算法 | 优势 | 不足 |
|----------|----------|----------|------|------|
| **传统方法** | 手工特征（法向量、曲率）+ SVM/RF + CRF 优化 | — | 轻量、易解释 | 鲁棒性差、泛化弱 |
| **基于点的方法** | 直接处理点云，学习局部/全局特征 | PointNet++、KPConv、PointCNN、PointAtrousNet | 保留精细空间信息 | 计算量大 |
| **基于图像的方法** | 投影为 Range 图像 → 2D FCN 分割 → 反投影回 3D | RangeNet++ | 速度快、复用 2D 成熟算法 | 投影丢失深度信息 |
| **基于体素的方法** | 点云→体素量化 → 3D 卷积提取特征 | VoxelNet 扩展、FCPN | 兼顾精度与效率 | 分辨率难平衡、空体素浪费 |
| **基于图的方法** | 点云建模为图（节点=点/超点，边=邻接关系）→ GCN | SPG、GACNet | 捕捉全局上下文关系 | 图构建复杂、推理慢 |

**各方法核心算法详解：**

| 算法 | 核心创新 |
|------|------|
| **PointNet** | 对称函数（最大池化）解决点云无序性 |
| **PointNet++** | 分层特征学习（采样→分组→特征提取循环）构建多尺度特征 |
| **PointCNN** | χ 算子对 K 近邻点按空间距离排序，实现点云卷积 |
| **KPConv** | 局部区域定义核心点（类比卷积核），提升几何表征能力 |
| **PointAtrousNet** | 空洞卷积（PAC），不增加参数扩大感受野 |
| **SPG（超点图）** | 点云聚类为超点 → PointNet 编码节点 → 图卷积 → 输出标签 |
| **GACNet** | 图注意力机制，动态为邻接节点分配权重 |

**基于图像的方法流程：**
1. **点云→Range 图像**：球面投影生成二维图像
2. **2D 全卷积分割**：编码器-解码器结构（残差块 + 上采样）
3. **2D→3D 反投影**：分割标签映射回原始点云
4. **3D 后处理**：聚类、条件随机场（CRF）平滑修正

### 第2章 机器人触觉感知

#### 2.1 力触觉传感器分类

**⭐ 重点：按位置分类**

| 位置 | 安装处 | 作用 |
|------|--------|------|
| **关节** | 关节执行器 | 实时检测力矩，碰撞检测和精细控制 |
| **腕部** | 末端与执行器连接处 | 测量多维力和力矩，协作机器人常用 |
| **指尖** | 夹爪手指 | 直接测量夹持力，物体识别、抓取稳定性控制、滑移检测 |
| **底座** | 底座 | 整体受力监测，适合重载任务 |
| **仿人皮肤** | 机器人表面 | 阵列式设计，大面积触觉感知 |

**⭐ 重点：按原理分类**

| 类型 | 原理 | 典型材料 | 特点 |
|------|------|------|------|
| **电阻式** | 外力→材料形变→电阻变化 | 金属应变片、半导体应变片 | 技术成熟、成本低；受温度影响大 |
| **电容式** | 外力→极板间距/面积变化→电容变化 | 金属膜片、硅 | 灵敏度高、功耗低、温度稳定；适合微小力 |
| **压电式** | 压电效应——受力产生电荷 | 压电石英、压电陶瓷、高分子压电材料 | 响应速度快、动态性能好；适合动态力和冲击力 |
| **光学式** | 光强/波长/相位/偏振变化感知力 | 光纤（FBG）、弹性导波结构 | 抗电磁干扰、绝缘性好；适合复杂工业环境 |
| **摩擦电式** | 摩擦起电效应——接触分离产生电信号 | 摩擦电纳米材料 | 自供电、结构简单；能量采集与传感一体化 |
| **基于视觉** | 相机捕捉柔性表面形变图像→反推接触力 | GelSight、GelSlim、Digit | **空间分辨率极高**，能重建接触纹理细节 |

#### 2.2 力/力矩传感器原理

**电阻式：** 压阻效应 & 应变效应。外力→弹性体形变→应变片拉伸/压缩→电阻变化→**惠斯通电桥**检测。

**电容式：** 极板间距/有效面积/介电常数变化→电容值变化→**差动梳电容**检测（灵敏度高，可解耦二维力分量）。

**压电式：** 压电效应，外力→表面电荷→测量电荷信号。响应快，适合冲击力/高频动态力。

**光学式（FBG）：** 光纤光栅在外力/应变下光栅周期变化→反射光中心波长偏移→精确测量应变/力。

**摩擦电式：** 两种不同材料接触分离→表面电荷转移→电势差。可同时检测接触力/振动+收集环境能量。

**视觉式（如 GelSight）：** 透明硅胶接触面 + 内置摄像头 + 光照系统。物体挤压硅胶→形变图案→图像处理算法（光流法/三维重建）→接触力分布+物体纹理。

#### 2.3 触觉传感器感知过程

1. **带标记点的弹性体**：硅胶表面嵌入规则排列的标记点（黑点/圆点）
2. **无接触状态**：标记点规则网格排列 → 基准触觉图像模板
3. **接触物体后**：标记点随形变位移 → 对比前后位置变化 → 计算力分布/大小/方向 → 重建接触面三维视图

#### 2.4 力传感器性能指标

| 类型 | 指标 | 含义 |
|------|------|------|
| **静态** | 灵敏度 | 输出变化量/输入力变化量 |
| | 线性度 | 实际输出与理想直线偏离程度 |
| | 迟滞性 | 加减载过程同一力下输出差异 |
| | 重复性 | 相同条件多次测量的输出一致性 |
| **动态** | 时间常数 | 阶跃输入下输出达稳态 63.2% 所需时间 |
| | 响应时间 | 从阶跃输入到输出保持规定误差范围内的时间 |
| | 超调量 | 阶跃响应中超出稳态值的最大偏差百分比 |

#### 2.5 人-环境交互力建模与测量

**⭐ 重点：两种梁理论**

| 理论 | 核心假设 | 截面特性 | 适用场景 |
|------|----------|----------|----------|
| **欧拉-伯努利梁** | 忽略剪切变形，截面始终垂直中性轴，$\partial w/\partial x = 0$ | 弯曲后截面与轴线垂直，无剪切变形 | 细长梁（长径比 > 10），弹性悬臂梁 |
| **铁木辛柯梁** | 考虑横向剪切变形，$\partial w/\partial x \neq 0$ | 弯曲后截面倾斜，存在明显剪切变形 | 短粗梁（长径比 < 10），高精度传感器 |

**力测量方法：**

| 类型 | 核心电路/结构 |
|------|------------|
| 电阻式 | **惠斯通电桥**：四电阻桥式电路，对微小电阻变化极敏感，可抑制温度漂移等共模干扰 |
| 电容式 | **差动梳电容**：差动式结构，电容值反向变化，可消除共模干扰，解耦二维力分量 |

#### 2.6 多维力/力矩感知

六维力传感器同时测量**三维力（$F_x, F_y, F_z$）**和**三维力矩（$M_x, M_y, M_z$）**，用于机器人手术、精密装配、人机协作。

#### 2.7 机器人触觉感知方法

**核心感知方式：**
- **触觉图像**：视觉触觉传感器（GelSight）采集的二维接触图像
- **时间序列信号**：阵列式/压阻式传感器采集的力信号序列

**关键感知任务：**
| 任务 | 说明 |
|------|------|
| 物体姿态估计 | 根据接触区域形状/位置/角度推断三维姿态 |
| 接触点分布分析 | 确定接触位置/大小/压力分布，判断抓取稳定性 |
| 滑移趋势检测 | 通过触觉图像或力信号变化判断是否滑动 |

**目标识别三步骤：**
1. **多模态数据采集**：FBG 光纤光栅 + IMU 同步采集应变/加速度/角速度等
2. **特征提取与标准化**：对不同物体的力/形变信号进行模式特征提取
3. **机器学习分类**：SVM、CNN 等分类模型学习"触觉指纹"

### 第3章 机器人多模态融合感知

#### 3.1 传感器基础

**传感器定义：** 将**非电量转换为电量**的装置，类似人类感觉器官。

**传感器组成：** 敏感元件（感知被测量变化）+ 转换元件（将感知变化转换为电信号）+ 信号调理电路 + 辅助电源。

**传感器分类（机器人方向）：**

| 大类 | 位置/功能 | 举例 |
|------|----------|------|
| **内部传感器** | 检测机器人自身状态 | 编码器、IMU、关节力矩传感器 |
| **外部传感器** | 感知外部环境 | 相机、激光雷达、触觉传感器 |

#### 3.2 多传感器标定

**离线标定方法：** 手动选取标定点→拟合标定板平面→结合相机内参反投影→求解外参。

**在线标定方法（深度学习）：** 双分支特征提取（图像分支+点云分支）→ 特征拼接融合 → 特征匹配 → 外参估计（旋转矩阵 + 平移向量）。

**LiDAR-IMU 联合标定流程：** 初始化 → 里程计更新（去畸变）→ 数据关联 → 批次优化 → 可观测性评估，闭环迭代求解外参和时间参数。

#### 3.3 视觉与力触觉融合的机器人目标抓取

**⭐ 重点：抓取流程**

| 步骤 | 内容 |
|:----:|------|
| ① 三维数据获取 | 接触式/非接触式扫描仪 |
| ② 数据表征 | 多视角图像、RGB-D、三维点云、三维网格、体素 |
| ③ 目标分割 | 语义 2D 图像分割 / 语义 3D 点云分割 |
| ④ 特征提取 | 局部特征 / 全局特征 |
| ⑤ 目标检测 | 2D / 3D 目标检测 |
| ⑥ 位姿估计 | 初始估计 → 验证优化 |
| ⑦ 抓取执行 | 软体机械手 / 刚体机械手 |

**触觉数据采集七步：** 搭建环境→目标定位→姿态规划→执行抓取→提升稳定→引入滑移/扰动→生成触觉数据。

**视觉+触觉融合优势：**
- **多模态互补**：视觉提供全局定位和识别，触觉提供接触层面精细反馈
- **动态感知**：抓取前后触觉图像差分捕捉细微形变，滑移判断更精准
- **端到端预测**：直接从多模态输入预测抓取结果

#### 3.4 多传感器融合的机器人自主定位与导航

**卡尔曼滤波（适用于线性系统）：**

| 方程 | 作用 |
|------|------|
| 状态方程 $x_k = F_{k-1}x_{k-1} + B_k v_k + \omega_k$ | 描述系统状态随时间变化 |
| 观测方程 $z_k = G_k x_k + n_k$ | 描述传感器测量与系统状态关系 |
| 预测步骤 | 基于上一时刻最优估计预测当前状态和协方差 |
| 卡尔曼增益计算 | 权衡预测值不确定性和观测值不确定性 |
| 更新步骤 | 利用观测值修正预测 → 最优状态估计 |

**扩展卡尔曼滤波（EKF，适用于非线性系统）：**
- 用**雅可比矩阵**将非线性函数线性化
- $f(\cdot)$：非线性状态转移函数 → $F_{k-1}$（雅可比矩阵）
- $g(\cdot)$：非线性观测函数 → $G_k$（雅可比矩阵）

**⭐ 重点：多传感器融合定位方法**

| 融合类型 | 方法分类 |
|----------|----------|
| **视觉-惯性（VIO）** | (1) 基于滤波：状态建模为概率分布，递推更新；(2) 基于优化：建模为最大后验概率问题 |
| **激光-惯性（LIO）** | (1) **松耦合**：各自独立估计位姿，融合中心组合；(2) **紧耦合**：IMU 预积分+激光原始数据在同一优化问题中 |
| **视觉-激光融合** | (1) 松耦合：各自计算中间结果后融合；(2) 紧耦合：对视觉里程计漂移建模→去畸变→匹配注册 |

**⭐ 单一传感器定位方法对比：**

| 方法 | 原理 | 特点 |
|------|------|------|
| **视觉导航定位** | 车载相机采集图像完成定位 | 成本低、易实现、适用性强 |
| **光反射导航** | 激光/红外测距（基于光反射原理） | 高分辨率、定位精确 |
| **超声波导航** | 计算发射-接收时间差 × 传播速度 | 有效的距离感知 |
| **航机推算** | 里程计 + IMU 检测累积位移和旋转 | 简单实用、成本低、更新频率高 |
| **空间信标定位** | UWB / 蓝牙 iBeacon / RFID 标签 | 定位精度不随时间累积误差而降低 |

> **多传感器融合优势：** 相机提供纹理、IMU 提供高频运动估计、激光雷达提供精确几何信息，三者紧耦合优化可抑制误差、提升鲁棒性，激光地图匹配修正累积误差实现长期稳定定位。

### 习题1：简述激光雷达 SLAM 的五个基本步骤。

**📚 前置知识：**
- SLAM 前后端概念
- 回环检测与全局优化的作用

**🔍 详细解答：**

| 步骤 | 内容 | 阶段 |
|:----:|------|:---:|
| ① 点云输入 | 三维激光雷达采集原始点云数据 | 输入 |

### 习题2：对比 VoxelNet 和 PointNet++ 在三维目标检测中的方法差异。

**📚 前置知识：**
- VoxelNet：体素化 + 3D 卷积
- PointNet++：直接处理点云 + 分层特征学习

**🔍 详细解答：**

| 对比维度 | VoxelNet | PointNet++ |
|----------|:------:|:---------:|
| 处理方式 | 点云→**体素化**→3D 卷积 | **直接处理**原始点云 |
| 核心结构 | VFE 特征编码 + 3D 卷积中间层 + RPN | 集合抽象层（采样→分组→PointNet）堆叠 |
| 特征提取 | 体素级特征+全局感受野 | 分层局部特征→全局特征向量 |
| 优势 | 端到端检测，结合 2D RPN | 保留精细空间信息，解决点云无序性 |
| 下游任务 | 检测框+类别 | 分类+分割 |

### 习题6：对比卡尔曼滤波和扩展卡尔曼滤波的适用场景与核心差异。

**📚 前置知识：**
- KF：线性系统
- EKF：非线性系统，雅可比矩阵线性化

**🔍 详细解答：**

| 维度 | 卡尔曼滤波（KF） | 扩展卡尔曼滤波（EKF） |
|------|:-------------:|:------------------:|
| 适用系统 | **线性** | **非线性** |
| 状态转移 | $F_{k-1}x_{k-1}$（线性矩阵乘法） | $f(\hat{x}_{k-1})$（非线性函数+雅可比矩阵 $F_{k-1}$） |
| 观测模型 | $G_k x_k$（线性矩阵乘法） | $g(\check{x}_k)$（非线性函数+雅可比矩阵 $G_k$） |
| 线性化 | 无需（本身线性） | **一阶泰勒展开**（雅可比矩阵） |
| 误差 | 无线性化误差 | 有线性化误差（忽略高阶项） |

### 常见易错点

1. ❌ PointNet 有局部特征提取 → ✅ PointNet 只提取**全局特征**，**PointNet++** 才引入分层局部特征
2. ❌ 回环检测属于后端优化 → ✅ 回环检测属于**前端**，为后端优化提供约束
3. ❌ 压电式传感器适合静态力测量 → ✅ 压电式适合**动态力和冲击力**，静态力会泄漏
4. ❌ KF 和 EKF 都适用于非线性系统 → ✅ KF 仅适用于**线性系统**，EKF 通过雅可比矩阵线性化处理非线性
5. ❌ 铁木辛柯梁忽略剪切变形 → ✅ **欧拉-伯努利梁**忽略剪切变形，铁木辛柯梁**考虑**剪切变形
6. ❌ VoxelNet 直接处理原始点云 → ✅ VoxelNet 先将点云**体素化**再处理，PointNet++ 才是直接处理原始点云
7. ❌ 触觉传感器只能测量力 → ✅ 视觉触觉传感器（GelSight）可**重建接触面纹理和三维形貌**
8. ❌ 基于图像的方法保留完整深度信息 → ✅ 投影过程**会丢失深度信息**，需要反投影+后处理修正
