## 1. 基带中心点检测

### 1.1 PCM 传输与噪声

PPT 第 3 页：PCM 信号的传输会受到**噪声**的影响。PCM 信号检测包含两个步骤：

1. **降维**：将每个接收到的电压脉冲（即符号）简化为**单个数值**
2. **判决**：将该数值与参考电压比较，确定发送的是哪个符号

```

┌──────────────────────────────────────────────────────┐
│ 接收信号 + 噪声 → [采样] → [比较器] → 判决结果   │
│                      ↑            ↑                │
│                  采样时钟    参考电压 V_ref        │
└──────────────────────────────────────────────────────┘
```

---

### 1.2 中心点检测

PPT 第 4 页核心概念：

> **中心点检测（Center Point Detection）**：在符号周期的**中点附近**采样"瞬时信号 + 噪声"的电压值。

为什么在中心点采样？
- 符号中点的信号最稳定（远离脉冲边沿的过渡区）
- 受符号间干扰（ISI）影响最小
- 这里 SNR 最大

---

### 1.3 噪声的统计模型

检测时存在的噪声通常为**高斯噪声**或**近似高斯**（回忆 Module 3：高斯噪声通过线性系统后仍是高斯的）。

因此，接收信号的在中心点采样的条件 PDF 也是高斯的。

---

### 1.4 检测错误概率

PPT 第 5-7 页：以二元信号（0 和 1）为例。

设：
- 发送 `0` 时，接收电压 $r \sim \mathcal{N}(\mu_0, \sigma^2)$
- 发送 `1` 时，接收电压 $r \sim \mathcal{N}(\mu_1, \sigma^2)$
- 判决阈值 $V_T$

```
         f(r|0)                    f(r|1)
        /      \                  /      \
       /        \                /        \
      /          \    ╲        ╱          \
     /            \    ╲      ╱            \
    /              \    ╲    ╱              \
───+──────┬─────────+────+──+─────────┬──────+───→ r
         μ0              V_T              μ1
                       ↑
                  判决阈值
         ←── 判为 0 ──│── 判为 1 ──→
```

#### 两类错误

| 错误类型 | 含义 | 概率 |
|------|------|------|
| **漏检（Miss）** | 发 `1`，判为 `0` | $P(e\|1) = P(r < V_T \| 1\text{ sent})$ |
| **虚警（False Alarm）** | 发 `0`，判为 `1` | $P(e\|0) = P(r > V_T \| 0\text{ sent})$ |

用 Q 函数表示：

$$P(e|0) = Q\left(\frac{V_T - \mu_0}{\sigma}\right)$$

$$P(e|1) = Q\left(\frac{\mu_1 - V_T}{\sigma}\right)$$

其中 $Q(x) = \frac{1}{\sqrt{2\pi}} \int_x^{\infty} e^{-t^2/2} dt$ 是标准正态分布的**右尾函数**。

#### 总误码率（BER）

若 `0` 和 `1` 等概率发送（$P(0) = P(1) = 1/2$），且取最优阈值 $V_T = (\mu_0 + \mu_1)/2$：

$$\text{BER} = \frac{1}{2}P(e|0) + \frac{1}{2}P(e|1) = Q\left(\frac{\mu_1 - \mu_0}{2\sigma}\right)$$

> 🔑 **BER 只取决于信号间距与噪声标准差的比值。**

---

### 1.5 单极性 NRZ 信号

PPT 第 8 页：单极性（Unipolar）NRZ：

- 发 `0`：$0\text{ V}$
- 发 `1`：$A\text{ V}$

$$\mu_0 = 0, \quad \mu_1 = A, \quad V_T = A/2$$

$$\text{BER}_{\text{unipolar}} = Q\left(\frac{A}{2\sigma}\right)$$

---

### 1.6 双极性 NRZ 信号

PPT 第 9 页：双极性（Polar）NRZ：

- 发 `0`：$-A\text{ V}$
- 发 `1`：$+A\text{ V}$

$$\mu_0 = -A, \quad \mu_1 = +A, \quad V_T = 0$$

$$\text{BER}_{\text{polar}} = Q\left(\frac{A}{\sigma}\right)$$

---

### 1.7 双极性 vs 单极性比较

PPT 第 10 页和第 24 页：

| 项目 | 单极性 | 双极性 |
|------|:--:|:--:|
| 信号间距 | $A$ | $2A$ |
| 判决阈值 | $A/2$ | $0$（与信号幅度无关！） |
| BER | $Q(A/2\sigma)$ | $Q(A/\sigma)$ |
| DC 分量 | 有 | 无（等概率时） |
| 功率效率 | **差** | **好** |

> 🔑 双极性信号有显著的 BER 优势——在相同峰值电压下，信号间距是单极性的**两倍**。单极性信号浪费了一半的发射功率在无信息的 DC 分量上。

---

### 1.8 BER 与 SNR 的关系

对双极性 NRZ，信号功率 $P_s = A^2$，噪声功率 $P_n = \sigma^2$，SNR $= A^2/\sigma^2$：

$$\text{BER}_{\text{polar}} = Q\left(\sqrt{\frac{A^2}{\sigma^2}}\right) = Q\left(\sqrt{\text{SNR}}\right)$$

## 2. 长距离传输

### 2.1 为什么需要中继？

PPT 第 13 页：

- 所有信号传输介质（电缆、波导、光纤）都会不同程度地**衰减**信号
- 对于长距离通信，衰减可能导致接收端信号低于接收机灵敏度
- 解决方法：沿收发路径**定期**放大信号
- 放大器设备：**中继器（Repeater）**
- 相邻中继器之间：**段（Hop）**

```
发送端 → [Hop1] → [中继1] → [Hop2] → [中继2] → ... → [HopN] → 接收端
```

---

### 2.2 放大中继器（Amplifying Repeater）

PPT 第 14-15 页：放大中继器简单地放大信号——**信号和噪声一起被放大**。

```
输入: s(t) + n(t) → [放大器 ×G] → 输出: G·s(t) + G·n(t)
```

**问题**：噪声在每个中继器中**累积**。

经过 $K$ 跳后：
- 信号功率：$P_s$（假设每跳衰减被放大器补偿）
- 噪声功率：$K \cdot P_n$（噪声线性累加！）

第 $K$ 跳后的 SNR：

$$\text{SNR}_K = \frac{P_s}{K \cdot P_n} = \frac{\text{SNR}_1}{K}$$

**SNR 随跳数增加而线性恶化！**

---

### 2.3 再生中继器（Regenerative Repeater）

PPT 第 16-17 页：再生中继器不仅放大信号，还进行**检测和再生**：

```
输入: s(t) + n(t) → [检测/判决] → [重新生成干净脉冲] → 输出: s'(t)
```

**关键优势**：只要每跳的判决正确，噪声**不会累积**——每跳都输出一个"干净"的信号。

每跳的 BER 为 $P_e$，$K$ 跳后的总 BER：

- **放大中继**：每跳噪声累加，等效 BER 随 $K$ 急剧恶化
- **再生中继**：总 BER $\approx K \cdot P_e$（对 $P_e \ll 1$，各跳错误近似独立）

> 🔑 **再生中继是数字通信的核心优势之一**——只要每跳的 SNR 足够高（保证低的 $P_e$），信号可以传输任意远距离而不会累积噪声！

## 3. 线路编码

### 3.1 什么是线路编码？

PPT 第 20 页：

> **线路编码（Line Coding）**：选择特定的一对脉冲来表示符号 `1` 和 `0` 的过程。

不仅仅是简单的单极性/双极性矩形脉冲——还有很多其他选择。

---

### 3.2 线路编码的选择准则

PPT 第 20 页列出了选择线路编码时考虑的因素：

1. **DC 电平的存在与否**（便于变压器耦合）
2. **功率谱密度**——特别是 **0 Hz 处的值**
3. **频谱占用**（带宽效率）
4. **BER 性能**（相对抗噪声能力）
5. **时钟恢复的便利性**（符号同步需要足够多的跳变）
6. **是否内置差错检测能力**
7. 其他因素

---

### 3.3 常见线路编码方案

PPT 第 21-23 页展示了多种常见线路编码：

| 编码类型 | 描述 | DC 分量 | 特点 |
|------|------|:--:|------|
| **Unipolar NRZ** | `1`=高电平，`0`=零电平 | 有 | 简单，功率效率低 |
| **Polar NRZ** | `1`=+A，`0`=-A | 无（等概率） | 功率效率好 |
| **Unipolar RZ** | `1`=半周期高电平，`0`=零电平 | 有 | 含时钟分量 |
| **Bipolar RZ** | `1`=交替正负脉冲，`0`=零电平 | 无 | 含时钟，有检错能力 |
| **Manchester** | `1`=高→低跳变，`0`=低→高跳变 | 无 | 强时钟分量，带宽 ×2 |

#### NRZ vs RZ

- **NRZ（Non-Return-to-Zero）**：脉冲占满整个符号周期
- **RZ（Return-to-Zero）**：脉冲在符号周期内回到零电平 → 含有丰富的时钟频率分量，便于接收端提取同步时钟

#### Manchester 编码

每个比特中间必有**跳变**：
- `1`：从高到低（下降沿）
- `0`：从低到高（上升沿）

优点：始终有跳变 → 时钟恢复极容易
缺点：带宽是 NRZ 的 **2 倍**

---

### 3.4 双极性 vs 单极性再强调

PPT 第 24 页重申：

- **双极性信号带宽与等效单极性信号相同**
- **双极性信号有显著的功率（或 BER）优势**——因为单极性中的平均（DC）电平不携带任何信息，白白浪费功率

## 4. 判决理论

### 4.1 先验概率与后验概率

PPT 第 26-27 页的重要区分：

| 概率类型 | 拉丁文 | 含义 |
|------|------|------|
| **先验概率（A Priori）** | "由因推果" | 在观察任何证据**之前**，对事件发生概率的判断 |
| **后验概率（A Posteriori）** | "由果推因" | 在观察证据**之后**，对事件概率的更新判断 |

在通信中：
- 通信事件的**因** = 发送的符号
- 通信事件的**果** = 检测到的电压

- **先验概率** $P(s_i)$：发送各符号的概率（通信中通常**事先已知**，如等概率）
- **条件概率** $P(r|s_i)$：发送 $s_i$ 时收到 $r$ 的概率（由信道噪声模型决定）
- **后验概率** $P(s_i|r)$：收到 $r$ 的条件下，发的是 $s_i$ 的概率（需要大量观测后才能确定）

---

### 4.2 贝叶斯判决准则

PPT 第 28 页：基于贝叶斯定理做判决：

$$P(s_i|r) = \frac{P(r|s_i) \cdot P(s_i)}{P(r)}$$

**最大后验概率（MAP）准则**：选择使后验概率 $P(s_i|r)$ 最大的 $s_i$。

由于 $P(r)$ 对所有 $s_i$ 相同，MAP 等价于：

$$\text{选择 } i \text{ 满足 } P(r|s_i) \cdot P(s_i) \text{ 最大}$$

当先验等概率 $P(s_i) = 1/M$ 时，MAP 退化为：

$$\text{选择 } i \text{ 满足 } P(r|s_i) \text{ 最大}$$

即**最大似然（ML）准则**。

---

### 4.3 期望条件判决代价

PPT 第 29 页：引入**代价（Cost）**概念来度量不同错误类型的严重程度。

设 $C_{ij}$ = 发送 $s_j$ 但判为 $s_i$ 的代价。

- $C_{ii} = 0$（正确判决无代价）
- $C_{ij} \geq 0$（错误判决可能有不同代价）

**条件代价**（给定发送 $s_j$）：

$$\bar{C}_j = \sum_{i} C_{ij} \cdot P(\text{判为 } s_i | s_j \text{ 发送})$$

---

### 4.4 最优判决规则

PPT 第 30-32 页推导**最小错误概率准则**下的最优判决门限。

对于等概率二元检测（$P(0) = P(1) = 1/2$），且 $C_{01} = C_{10} = 1$（两类错误代价相同）：

**最优门限**在两条条件 PDF 的**交点**处：

$$f(r|0) = f(r|1)$$

对于高斯 PDF：

$$\frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(r - \mu_0)^2}{2\sigma^2}\right) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(r - \mu_1)^2}{2\sigma^2}\right)$$

$$\Rightarrow (r - \mu_0)^2 = (r - \mu_1)^2$$

$$\Rightarrow r = \frac{\mu_0 + \mu_1}{2} = V_T$$

这正是我们之前使用的中间点门限！

> 🔑 最优判决门限是 $\frac{\mu_0 + \mu_1}{2}$——直观上合理，数学上也得到严格证明。

---

### 4.5 接收机类型比较

PPT 第 33 页：

| 接收机类型 | 准则 | 需要的信息 |
|------|------|------|
| **MAP** | 最小错误概率 | 先验概率 + 条件 PDF |
| **ML** | 最大化似然函数 | 条件 PDF（不需要先验） |
| **最小代价（Bayes）** | 最小期望代价 | 各类错误代价 + 先验 + 条件 PDF |

---

### 4.6 OOK 信号的最优判决门限

PPT 第 34 页：对于**包络检波的 OOK 信号**（如光纤通信），噪声模型不再是高斯，而是**Rice/Rayleigh** 分布。最优门限需要根据信号和噪声的统计特性重新计算。

> 📌 这提醒我们：最优门限依赖于具体的噪声分布——高斯假设下的 $(\mu_0 + \mu_1)/2$ 并不总是最优。

---

### 4.7 平均无条件判决代价

PPT 第 35-36 页：对所有可能的发送符号取期望，得到**平均代价**：

$$\bar{C} = \sum_j P(s_j) \cdot \bar{C}_j = \sum_i \sum_j C_{ij} \cdot P(\text{判为 } s_i, \text{发送 } s_j)$$

贝叶斯准则选择使 $\bar{C}$ 最小的判决规则——这是在**最一般意义下的最优接收机**。

---

## 5. 课程总结

PPT 第 38 页的总结涵盖：

- **中心点检测**：在符号周期中点采样信号+噪声，通过比较器进行判决
- **误码率 BER**：由信号间距与噪声标准差的比值决定（$Q$ 函数）
- **双极性信号**比单极性有更好的 BER 性能（信号间距加倍）
- **长距离传输**通过中继器实现：放大中继器会累积噪声，**再生中继器**可以"刷新"信号
- **线路编码**的选择要考虑 DC 分量、频谱特性、时钟恢复、检错能力等因素
- **判决理论**：MAP/ML/贝叶斯准则为最优接收机设计提供了数学框架

## 习题一：双极性 NRZ 的 BER 计算

> **对应 PPT 第 11 页 Exercise**

---

### 前置知识

**Q1：Q 函数是什么？**

$$Q(x) = \frac{1}{\sqrt{2\pi}} \int_x^{\infty} e^{-t^2/2} dt = P(Z > x), \quad Z \sim \mathcal{N}(0, 1)$$

常用值：
- $Q(0) = 0.5$
- $Q(1) \approx 0.1587$
- $Q(2) \approx 0.0228$
- $Q(3) \approx 1.35 \times 10^{-3}$
- $Q(4) \approx 3.17 \times 10^{-5}$
- $Q(5) \approx 2.87 \times 10^{-7}$
- $Q(6) \approx 9.87 \times 10^{-10}$
- $Q(7) \approx 1.28 \times 10^{-12}$

**Q2：双极性 NRZ 的 BER 公式？**

$$\text{BER} = Q\left(\sqrt{\frac{2E_b}{N_0}}\right)$$

或等价地：

$$\text{BER} = Q\left(\sqrt{\text{SNR}}\right)$$

其中 SNR 是检测器输入端的信号功率与噪声功率之比。

**Q3：dB 与线性比的换算？**

$$\text{SNR}_{\text{linear}} = 10^{\text{SNR}_{\text{dB}} / 10}$$

$$\text{SNR}_{\text{dB}} = 10 \log_{10}(\text{SNR}_{\text{linear}})$$

---

### 习题讲解

**题目**：一个 100 kbaud、等概率、二进制、双极性、矩形脉冲信号系统，假设理想中心点判决。检测器输入端测得的 SNR 为 12.0 dB。求 BER。

**解答**：

**(1) SNR 从 dB 转为线性**：

$$\text{SNR}_{\text{linear}} = 10^{12/10} = 10^{1.2} \approx 15.85$$

**(2) 双极性 BER 公式**：

$$\text{BER} = Q\left(\sqrt{\text{SNR}_{\text{linear}}}\right) = Q\left(\sqrt{15.85}\right) = Q(3.98)$$

**(3) 查 Q 函数表**：

$Q(3.98) \approx Q(4.0) \approx 3.17 \times 10^{-5}$

更精确：$Q(3.98) \approx 3.4 \times 10^{-5}$

$$\text{BER} \approx 3.4 \times 10^{-5}$$

**(4) 解读**：

- 在 SNR = 12 dB 时，每传输约 30000 个比特会出现约 1 个误码
- 100 kbaud 速率下，约每 **0.3 秒**出现 1 个误码

> 📌 如果改为单极性 NRZ（同样 SNR = 15.85），则 BER = $Q(\sqrt{15.85}/2) = Q(1.99) \approx 2.3 \times 10^{-2}$——差了近**700 倍**！这正是双极性信号功率效率优势的体现。

## 习题二：15 跳中继 — 放大 vs 再生

> **对应 PPT 第 18 页 Exercise**

---

### 前置知识

**Q1：放大中继器为何累积噪声？**

每跳：
$$r_k(t) = s(t) + n_k(t)$$

放大后输出：$G \cdot s(t) + G \cdot n_k(t)$

第 2 跳：$r_2(t) = G \cdot s(t) + G \cdot n_1(t) + n_2(t)$

放大后：$G^2 s(t) + G^2 n_1(t) + G \cdot n_2(t)$

等效：$s(t) + n_1(t) + n_2(t)/G + n_3(t)/G^2 + \ldots$

假设每跳增益补偿衰减 → 各 $n_k$ 的功率相等 → 总噪声功率 $= K \cdot P_n$。

**Q2：再生中继器为何几乎不累积噪声？**

每跳独立判决 → 如果判决正确，输出是**干净**的再生脉冲，噪声被完全消除。

总误码率：

$$P_{\text{total}} \approx 1 - (1 - P_e)^K \approx K \cdot P_e \quad (\text{当 } P_e \ll 1)$$

**Q3：放大中继的总 BER 如何计算？**

$K$ 跳后 SNR：$\text{SNR}_K = \text{SNR}_1 / K$

$$\text{BER}_K = Q\left(\sqrt{\text{SNR}_1 / K}\right)$$

---

### 习题讲解

**题目**：15 段链路，每段与上一题相同（等概率、二进制、双极性、矩形脉冲，SNR = 12.0 dB）。求中继器实现为 (a) 线性放大器 (b) 数字再生器 时的 BER。

**解答**：

已知：$\text{SNR}_1 = 15.85$（线性），$P_{e1} \approx 3.4 \times 10^{-5}$

**(a) 线性放大器（15 跳）**：

$$\text{SNR}_{15} = \frac{15.85}{15} = 1.057 \approx 0.24\text{ dB}$$

$$\text{BER}_{15} = Q\left(\sqrt{1.057}\right) = Q(1.028) \approx 0.152$$

> 😱 BER 高达 **15.2%**——链路基本不可用！

**(b) 数字再生器（15 跳）**：

$$\text{BER}_{15} \approx 15 \times 3.4 \times 10^{-5} = 5.1 \times 10^{-4}$$

> ✅ BER 仅约 **0.05%**——基本可用！

**对比**：

| 中继方式 | 15 跳总 BER | 评价 |
|------|:--:|------|
| 线性放大器 | $\sim 1.5 \times 10^{-1}$ | ❌ 不可用 |
| 数字再生器 | $\sim 5.1 \times 10^{-4}$ | ✅ 可用 |

$$ \text{性能比} = \frac{0.152}{5.1 \times 10^{-4}} \approx 300 \text{ 倍！}$$

> 🔑 这是数字通信相对于模拟通信最具说服力的优势——再生中继使噪声**不会逐跳累积**，实现理论上无限远的可靠传输。这正是"数字革命"的技术根基。

## 习题三：线路编码的频谱与时钟恢复

> **对应 PPT 第 20-24 页综合内容**

---

### 前置知识

**Q1：NRZ 信号的 PSD 有什么特点？**

NRZ 矩形脉冲的 PSD（随机二进制序列）：

$$S(f) = \frac{A^2 T_b}{4} \cdot \text{sinc}^2(f T_b) + \frac{A^2}{4} \delta(f)$$

- 在 $f = 0$ 处有冲激分量（DC）
- 在 $f = \pm 1/T_b$ 处（比特率）PSD **为零**——没有离散时钟分量！
- **NRZ 信号不包含时钟频率分量**，接收端时钟恢复困难

**Q2：RZ 信号的 PSD 有什么特点？**

RZ（占空比 50%）的 PSD 在 $f = \pm 1/T_b$ 处有**离散线谱**——时钟恢复容易。

**Q3：Manchester 码的频谱特征？**

Manchester 码的 PSD 主瓣中心在 $f = 1/T_b$，0 Hz 处为零（无 DC 分量），$f = 0$ 和 $f = \pm 2/T_b$ 处均为零。

---

### 习题讲解

**典型题**：比较三种线路编码（单极性 NRZ、双极性 NRZ、Manchester）在以下方面的表现：(1) DC 分量、(2) 时钟恢复、(3) 带宽、(4) BER。

**解答**：

| 特性 | 单极性 NRZ | 双极性 NRZ | Manchester |
|------|:--:|:--:|:--:|
| **DC 分量** | 有（$A/2$） | 无 | 无 |
| **时钟分量（$f=1/T_b$）** | 无 | 无 | **有** |
| **带宽（主瓣）** | $0 \sim 1/T_b$ | $0 \sim 1/T_b$ | $0 \sim 2/T_b$（×2） |
| **BER（相同 SNR）** | $Q(\sqrt{\text{SNR}}/2)$ | $Q(\sqrt{\text{SNR}})$ | 同双极性 |
| **变压器耦合** | ❌（DC 分量） | ✅ | ✅ |
| **电路复杂度** | 低 | 低 | 中 |

**各编码的典型应用**：

- **单极性 NRZ**：简单系统中使用，但在现代通信中较少见（功率效率差 + DC 问题）
- **双极性 NRZ**：RS-232、短距离数据通信
- **Manchester**：以太网（10BASE-T）、RFID——时钟恢复极为重要
- **Bipolar（AMI）**：T1/E1 数字电话中继线——有差错检测能力

## 习题四：最优判决门限计算

> **对应 PPT 第 30-34 页内容**

---

### 前置知识

**Q1：MAP 判决门限的推导（高斯噪声）？**

对于等概率二元检测，高斯噪声，最优门限满足 $f(r|0) = f(r|1)$：

$$\frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(r-\mu_0)^2}{2\sigma^2}} = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(r-\mu_1)^2}{2\sigma^2}}$$

$$(r - \mu_0)^2 = (r - \mu_1)^2$$

$$V_T = \frac{\mu_0 + \mu_1}{2}$$

**Q2：如果不是等概率呢？**

若 $P(0) \neq P(1)$，MAP 准则下最优门限不再在中间点。取对数比较：

$$\ln P(r|0) + \ln P(0) \quad \text{vs} \quad \ln P(r|1) + \ln P(1)$$

解得：

$$V_T = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\mu_1 - \mu_0} \ln\frac{P(0)}{P(1)}$$

- 若 $P(0) > P(1)$，$V_T$ 偏向 $\mu_1$ → 更倾向判为 `0`
- 若 $P(0) < P(1)$，$V_T$ 偏向 $\mu_0$ → 更倾向判为 `1`

---

### 习题讲解

**典型题1**：双极性信号 $\pm 1\text{ V}$，噪声 $\sigma = 0.3\text{ V}$，$P(0) = 0.3$，$P(1) = 0.7$。求 MAP 最优判决门限。

**解答**：

$$\mu_0 = -1, \quad \mu_1 = +1, \quad \sigma = 0.3$$

$$V_T = \frac{-1 + 1}{2} + \frac{0.3^2}{1 - (-1)} \ln\frac{0.3}{0.7}$$

$$= 0 + \frac{0.09}{2} \cdot \ln(0.4286)$$

$$= 0 + 0.045 \cdot (-0.8473)$$

$$= -0.038\text{ V}$$

> 📌 最优门限 $\approx -0.038\text{ V} \neq 0$！因为 `1` 出现概率更高 → 门限略偏向 `0` 一侧 → 更倾向于判 `1`。这与直觉一致：如果某符号出现概率大，我们就"偏向"它。

---

**典型题2**：如果错误代价不对称（$C_{01} = 1$，$C_{10} = 10$），即"将 `1` 误判为 `0`"的代价是"将 `0` 误判为 `1`"的 10 倍。其他条件同上，求最优门限。

**解答**：

引入代价后，MAP 准则变为最小代价准则。似然比与门限比较：

$$\frac{f(r|1)}{f(r|0)} \quad \overset{\text{判为 }1}{\underset{\text{判为 }0}{\gtrless}} \quad \frac{C_{10} - C_{00}}{C_{01} - C_{11}} \cdot \frac{P(0)}{P(1)}$$

代入 $C_{10} = 10$（判 0 实为 1），$C_{01} = 1$（判 1 实为 0），$C_{00} = C_{11} = 0$：

$$V_T = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\mu_1 - \mu_0} \ln\left(\frac{C_{10}}{C_{01}} \cdot \frac{P(0)}{P(1)}\right)$$

$$= 0 + 0.045 \cdot \ln\left(10 \times \frac{0.3}{0.7}\right)$$

$$= 0.045 \cdot \ln(4.286)$$

$$= 0.045 \cdot 1.455 = 0.0655\text{ V}$$

> 📌 门限 $\approx +0.066\text{ V}$，偏向 `0` 一侧 → 减少代价最高的错误（漏检 `1`）。

## 习题五：综合 — BER、功率、带宽的权衡

> **对应 PPT 第 33-37 页的综合应用**

---

### 前置知识

总结本课程中的几个关键权衡关系：

1. **带宽 vs SQNR**（Module 6）：$n$ 每增加 1 位，SQNR +6 dB，带宽 +$f_s$
2. **带宽 vs BER**：增大信号功率 → 减小 BER；增大带宽（如 RZ）→ 改善时钟恢复但增加带宽占用
3. **带宽 vs 抗噪声**（Module 4）：FM 以大量带宽换取抗噪声性能
4. **再生 vs 复杂度**：再生中继更可靠但比放大中继复杂

---

### 习题讲解

**典型题**：设计一个数字基带传输系统，要求 BER ≤ $10^{-6}$，数据率 1 Mbit/s。

(1) 若使用双极性 NRZ，需要的最小 SNR（dB）是多少？  
(2) 此时的最小传输带宽是多少？  
(3) 若 SNR 只有 10 dB，有什么办法达到目标 BER？

**解答**：

**(1) 所需 SNR**：

$$\text{BER} = Q\left(\sqrt{\text{SNR}}\right) \leq 10^{-6}$$

查 Q 表：$Q(4.75) \approx 10^{-6}$

$$\sqrt{\text{SNR}} \geq 4.75 \Rightarrow \text{SNR} \geq 22.56$$

$$\text{SNR}_{\text{dB}} = 10\log_{10}(22.56) \approx 13.5\text{ dB}$$

**(2) 最小带宽**（NRZ 矩形脉冲）：

$$B_{\min} = \frac{R_b}{2} = \frac{1\text{ Mbit/s}}{2} = 500\text{ kHz}$$

（这是理想奈奎斯特带宽，实际需要更多。）

**(3) SNR 只有 10 dB 时**：

方案 A：**增加发射功率**（如果法规允许）——需增加 3.5 dB = 约 2.24 倍。

方案 B：**使用信道编码（纠错码）**——加入冗余比特，在相同 SNR 下降低有效 BER。例如，使用卷积码 + Viterbi 译码可获得数 dB 的编码增益，用 10 dB 实现 $10^{-6}$ BER。

方案 C：**降低数据率**——如果应用允许，降低比特率可以减小带宽 → 噪声带宽减小 → 等效 SNR 提高。

方案 D：**改善接收机**——使用匹配滤波器（而非简单中心点检测）可获得额外增益。

> 🔑 实际系统设计中，**不可能同时优化所有指标**。必须根据应用需求（成本、功耗、带宽、延迟等）进行权衡。

## 习题六：先验/后验概率 — 贝叶斯方法在通信中的应用

> **对应 PPT 第 26-28 页内容**

---

### 前置知识

**Q1：先验 vs 后验的通信实例？**

- **先验概率**：已知发送端以 $P(0) = P(1) = 0.5$ 发送符号
- **似然函数**：$f(r|0)$ 和 $f(r|1)$（由噪声分布决定）
- **后验概率**：收到 $r = 0.3\text{ V}$ 后，$P(0|0.3)$ vs $P(1|0.3)$——哪个符号更可能？

**Q2：贝叶斯定理在判决中的角色？**

$$P(s_i|r) = \frac{f(r|s_i) P(s_i)}{f(r)}$$

贝叶斯定理将"已知发送符号时收到 $r$ 的概率"转化为"已知收到 $r$ 时发送符号的概率"——这正是判决所需要的。

---

### 习题讲解

**典型题**：双极性信号 $\pm 1\text{ V}$，高斯噪声 $\sigma = 0.4\text{ V}$，$P(1) = P(0) = 0.5$。收到 $r = 0.3\text{ V}$（在符号中心点采样）。

(1) 计算先验概率 $P(0)$ 和 $P(1)$  
(2) 计算似然 $f(r|0)$ 和 $f(r|1)$  
(3) 计算后验概率 $P(0|r)$ 和 $P(1|r)$  
(4) 按照 MAP 准则，应该判为什么？

**解答**：

**(1) 先验**：

$$P(0) = P(1) = 0.5$$

**(2) 似然**：

$$f(r|s_i) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(r - \mu_i)^2}{2\sigma^2}\right)$$

$$f(0.3|0) = \frac{1}{\sqrt{2\pi} \times 0.4} \exp\left(-\frac{(0.3 - (-1))^2}{2 \times 0.4^2}\right)$$

$$= 0.997 \times \exp\left(-\frac{1.69}{0.32}\right) = 0.997 \times e^{-5.281} \approx 0.0051$$

$$f(0.3|1) = 0.997 \times \exp\left(-\frac{(0.3 - 1)^2}{0.32}\right)$$

$$= 0.997 \times \exp\left(-\frac{0.49}{0.32}\right) = 0.997 \times e^{-1.531} \approx 0.216$$

**(3) 后验**（未归一化的分子）：

$$P(0|r) \propto f(r|0) \cdot P(0) \propto 0.0051 \times 0.5 = 0.00255$$

$$P(1|r) \propto f(r|1) \cdot P(1) \propto 0.216 \times 0.5 = 0.108$$

归一化：

$$P(0|0.3) = \frac{0.00255}{0.00255 + 0.108} \approx 2.3\%$$

$$P(1|0.3) = \frac{0.108}{0.00255 + 0.108} \approx 97.7\%$$

**(4) MAP 判决**：

后验 $P(1|r) \gg P(0|r)$ → **判为 `1`**。

直观理解：0.3V 更接近 $+1\text{V}$（距离 0.7V）而非 $-1\text{V}$（距离 1.3V），所以大概率发的是 `1`。

> 🔑 这个过程就是最优接收机的核心逻辑——每一步都有清晰的数学依据，从接收到判决没有"黑箱"。

## 📋 核心公式速查表

| 概念 | 公式 | 说明 |
|------|------|------|
| Q 函数 | $Q(x) = \frac{1}{\sqrt{2\pi}}\int_x^{\infty} e^{-t^2/2}dt$ | 标准正态右尾函数 |
| BER（单极性） | $\text{BER} = Q\left(\frac{A}{2\sigma}\right)$ | $V_T = A/2$ |
| BER（双极性） | $\text{BER} = Q\left(\frac{A}{\sigma}\right) = Q(\sqrt{\text{SNR}})$ | $V_T = 0$ |
| 最优门限（等概率） | $V_T = \frac{\mu_0 + \mu_1}{2}$ | 两条 PDF 交点 |
| 最优门限（不等概率） | $V_T = \frac{\mu_0 + \mu_1}{2} + \frac{\sigma^2}{\Delta\mu}\ln\frac{P(0)}{P(1)}$ | MAP 准则 |
| $K$ 跳放大中继 SNR | $\text{SNR}_K = \text{SNR}_1 / K$ | 噪声线性累积 |
| $K$ 跳再生中继 BER | $\text{BER}_K \approx K \cdot \text{BER}_1$ | 对 $\text{BER}_1 \ll 1$ |
| MAP 判决 | $\text{选择 } i \text{ 使 } P(r\|s_i)P(s_i) \text{ 最大}$ | 最小错误概率 |
| ML 判决 | $\text{选择 } i \text{ 使 } P(r\|s_i) \text{ 最大}$ | 等先验时同 MAP |
| NRZ 最小带宽 | $B_{\min} = R_b/2$ | 奈奎斯特 |
| BER vs SNR（dB） | $\text{SNR}_{\text{dB}} = 10\log_{10}(\text{SNR})$ | 转换 |
